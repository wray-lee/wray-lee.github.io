概念

二维

  • 线性可分：二分类中存在一条直线将两种样本分开
  • 线性不可分：二分类中不存在一条直线将两种样本分开
严格定义
普通定义

一个训练样本集${(X ~ i ~,y ~ i ~),……,(X ~ N ~,Y ~ N ~)}$，在$i=1\sim N$线性可分，是指存在（$\omega_1$,$\omega_2$,$b$）,使得对$i = 1 \sim N$有
$$
(1)若 ~ y_i = +1, 则 ~ \omega_1 x_{i1} + \omega_2x_{i2} + b > 0 \
(2)若 ~ y_i = -1, 则 ~ \omega_1 x_{i1} + \omega_2x_{i2} + b < 0
$$

向量定义

$$
X_i =
\begin{pmatrix}
x_{i1} \
x_{i2}
\end{pmatrix}^T

\qquad

\omega=
\begin{pmatrix}
\omega_1\
\omega_2
\end{pmatrix}^T

\
(1)若 ~ y_i = +1, 则 ~ \omega^T X_i + b > 0 \
(2)若 ~ y_i = -1, 则 ~ \omega^T X_i + b < 0
$$

线性可分

最优

  1. 该直线分开了两类
  2. 该直线最大化间隔（margin）
  3. 该直线处于间隔的中间，到所有的支持向量距离相等

目的：

​ $最小化\dfrac{1}{2} | \omega | ^2 (| \omega | 为范数)$

二次规划

  1. 目标函数是二次项
  2. 限制条件是一次项$y_i = \omega ^T x_i + b \geq 1, (i=1\sim N)$ [$\geq1$为归一化结果，可以通过参数缩放调整]

满足则为凸优化问题则无解或存在唯一最小极值

选择函数间隔等于 1 是一种规范化手段，目的是为了让问题具有唯一解。如果没有这个规范化条件，$\omega$ 和 $b$ 可以按任意比例缩放（例如，$2\omega, 2b$ 会得到相同的超平面，但函数间隔会变成原来的两倍），这会导致优化目标不明确。通过要求 $y_i (\omega^T x_i + b) \geq 1$，我们固定了函数间隔的尺度，从而使得优化问题有意义。

具体来说：

  • 如果我们不固定函数间隔为 1，而是设为某个常数 $k$，那么 $\omega$ 和 $b$ 会相应地缩放为 $\frac{\omega}{k}$ 和 $\frac{b}{k}$，但几何间隔 $\frac{k}{|\omega|}$ 保持不变。
  • 因此，选择 $k = 1$ 是一种方便的规范化方式，不会影响最终的几何间隔。

线性不可分

添加松弛变量(slack variable) $\delta_i$

$$
最小化： \
\dfrac{1}{2} | \omega |^2 + C ~ \Sigma^N_{i=1} \delta_i ~ 或 ~ \dfrac{1}{2} | \omega |^2 + C ~ \Sigma^N _{i = 1} \delta_i^2 \

限制条件： \
(1) ~ \delta_i \geq 0 \
(2) ~ y_i = \omega^T x_i + b \geq 1 - \delta_i ~ , (i = 1 \sim N) \
$$

核函数

$$
K(X_1,X_2) = \varphi(X_1)^T \varphi(X_2)
$$

充要条件

$$

  1. ~ K(X_1,X_2) = K(X_2,X_1) \quad (交换性) \
  2. ~ \forall C_i (i = 1 \sim N), \forall N有 \sum\nolimits^N_{i = 1} \sum\nolimits^N_{i = 1} C_i C_j K(X_i X_j) \quad (半正定性) \
    $$

例外：

高斯核函数： $K(X_1 , X_2) = e^{-\frac{ | x_1 - x_2 | ^2}{2 \sigma ^2}}$

原问题和对偶问题

  • 原问题：
    $$
    最小化： f(\omega) \
    限制条件： \
    g_i(\omega) \leq 0 \quad [i = 1\sim K] \
    h_i(\omega) = 0 \quad [i = 1 \sim M]
    $$

  • 对偶问题：

$$
定义(拉格朗日函数)： L(\omega, \alpha, \beta) = f(\omega) + \sum^K_{i = 1} \alpha_i g_i(\omega) + \sum^K_{i = 1} \beta_i h_i(\omega) \
=f(\omega + \alpha^T) g(\omega) +\beta h(\omega) \
\
其中 ~ \alpha = [\alpha_1, \alpha_2, …, \alpha_K]^T \
\beta = [\beta_1, \beta_2, …, \beta_K]^T \
不等式约束条件(边界)：g(\omega) = [g_1(\omega), g_2(\omega), …, g_K(\omega)]^T \
等式约束条件(归一化)：h(\omega) = [h_1(\omega), h_2(\omega), …, h_M(\omega)]^T \
$$

$$
最大化：\theta(\alpha, \beta) = inf ~ L(\omega, \alpha, \beta), 所有定义域内的\omega \
限制条件：\alpha_i \geq 0, i = 1 \sim K
$$

定理：

对偶差距$f(\omega^)-\theta(\alpha^, \beta^*)$

$$
f(\omega^) \geq \theta(\alpha^, \beta^*) \
\

证明： \
\theta(\alpha^, \beta^) = inf ~ L(\omega, \alpha^, \beta^) \
\leq L(\omega^, \alpha^, \beta^) \
=f(\omega^) + \alpha^{T} g(\omega^) + \beta^{T}h(\omega^) \
\leq f(\omega^)
\
\
已知： ~ g(\omega^) \leq 0; \quad h(\omega^) = 0; \quad \alpha(\omega^) \geq 0
$$

  1. 原问题的目标函数是凸函数，限制条件是线性函数时

$$
f(\omega^) = \theta(\alpha^, \beta^*)
$$

对偶差距为0
