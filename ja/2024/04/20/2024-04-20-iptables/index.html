iptables增删查改

四表五链

四表

  • filter 默认表

    • INPUT
    • FORWARD
    • OUTPUT

  • nat 用于nat时修改包

    • PREROUTING
    • POSTROUTING
    • OUTPUT

  • mangle 用于修改包

    • INPUT
    • FORWARD
    • OUTPUT
    • PREROUTING
    • POSTROUTING

  • raw 用于高级功能（网络过滤等）

五链

  • INPUT链 ：处理输入数据包。
  • OUTPUT链 ：处理输出数据包。
  • FORWARD链 ：处理转发数据包。
  • PREROUTING链 ：用于目标地址转换(DNAT)。 在路由前更改传入的包
  • POSTOUTING链 ：用于源地址转换(SNAT) 在数据包即将离开时更改数据包

动作

  • ACCEPT ：接收数据包。
  • DROP ：丢弃数据包。
  • REDIRECT ：重定向、映射、透明代理。
  • SNAT ：源地址转换。
  • DNAT ：目标地址转换。
  • MASQUERADE ：IP伪装(NAT)，用于ADSL。
  • LOG ：日志记录。

添加

增加filter表

  • 添加到末尾

iptables -A INPUT -p tcp -m tcp --dport 21 -j ACCEPT

  • 添加到指定位置

iptables -I INPUT 3 -p tcp -m tcp --dport 20 -j ACCEPT

添加nat表

iptables -t nat -A POSTROUTING -s 192.168.10.0/24 -j MASQUERADE

删除

查看

  • 查看filter表

iptables -L -n --line-number （不用-t 指定默认filter）

  • 查看nat表

iptables -t nat -vnL POSTROUTING --line-number

修改

iptables -R INPUT 3 -j DROP replace

端口转发

-A PREROUTING -p tcp --dport 8022 -j REDIRECT --to-port 22
