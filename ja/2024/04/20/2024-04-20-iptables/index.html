iptablesの追加・削除・確認・変更

4つのテーブルと5つのチェーン

4つのテーブル

  • filter デフォルトテーブル

    • INPUT
    • FORWARD
    • OUTPUT

  • nat NAT時にパケットを変更するために使用

    • PREROUTING
    • POSTROUTING
    • OUTPUT

  • mangle パケットの変更に使用

    • INPUT
    • FORWARD
    • OUTPUT
    • PREROUTING
    • POSTROUTING

  • raw 高度な機能（ネットワークフィルタリングなど）に使用

5つのチェーン

  • INPUTチェーン：入力パケットを処理する。
  • OUTPUTチェーン：出力パケットを処理する。
  • FORWARDチェーン：転送パケットを処理する。
  • PREROUTINGチェーン：宛先アドレス変換（DNAT）に使用。 ルーティング前に入力パケットを変更する
  • POSTOUTINGチェーン：送信元アドレス変換（SNAT） パケットが離れる直前にパケットを変更する

アクション

  • ACCEPT：パケットを受け入れる。
  • DROP：パケットを破棄する。
  • REDIRECT：リダイレクト、マッピング、透過プロキシ。
  • SNAT：送信元アドレス変換。
  • DNAT：宛先アドレス変換。
  • MASQUERADE：IPマスカレード（NAT）、ADSLで使用。
  • LOG：ログ記録。

追加

filterテーブルの追加

  • 末尾に追加

iptables -A INPUT -p tcp -m tcp --dport 21 -j ACCEPT

  • 指定位置に追加

iptables -I INPUT 3 -p tcp -m tcp --dport 20 -j ACCEPT

natテーブルの追加

iptables -t nat -A POSTROUTING -s 192.168.10.0/24 -j MASQUERADE

削除

確認

  • filterテーブルを確認

iptables -L -n --line-number （-t を指定しない場合、デフォルトはfilter）

  • natテーブルを確認

iptables -t nat -vnL POSTROUTING --line-number

変更

iptables -R INPUT 3 -j DROP replace

ポート転送

-A PREROUTING -p tcp --dport 8022 -j REDIRECT --to-port 22
