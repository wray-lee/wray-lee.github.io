Curl詳細解説

curl -kfsSL

  • -k/--insecure SSL サイトへの証明書なしの接続を許可する
  • -f/--fail 接続失敗時に http エラーを表示しない。サーバーエラー時に、エラー原因を表す html ページが返されるのを防ぎ、代わりに curl コマンドがエラーコード 22 を返してエラーを通知する（html が返るとデバッグしにくいのを避ける）
  • -s/--silent サイレントモード。何も出力しない。エラーと進捗情報を出力しない。
  • -S/--show-error エラーを表示する。エラー情報のみを出力するよう指定し、通常は-sと一緒に使用する。
  • -L/--location HTTP リクエストがサーバーのリダイレクトに従うようにする。curl はデフォルトではリダイレクトに従わない。

curl -fsSL は、curl コマンドでファイルをダウンロードする際に、進捗とエラー情報を表示せず、ダウンロードに失敗した場合は直ちに停止し、自動的にリダイレクトに従うことを意味する。これは通常、ファイルをダウンロードするための静かで安全かつ安定した方法である。

区別

  • -l/--list-only ftp ディレクトリ下のファイル名を一覧表示する
  • -F パラメータは、サーバーへバイナリファイルをアップロードするために使用する。

その他のコマンド

-o パラメータはサーバーの応答をファイルとして保存し、wget コマンドと同等である。

curl -o example.html https://www.example.com

-O パラメータはサーバー応答をファイルとして保存し、URL の最後の部分をファイル名とする。（名前を付ける必要はない）

curl -O https://www.example.com/foo/bar.html

--limit-rate は HTTP リクエストと応答の帯域幅を制限し、遅いネットワーク速度の環境をシミュレートするために使用する。

curl --limit-rate 200k https://google.com

curl の使い方ガイド

著者： 阮一峰

日付： 2019年9月5日

はじめに

curl はよく使われるコマンドラインツールで、Web サーバーにリクエストを送るために使用する。その名前は、クライアント（client）の URL ツールという意味である。

その機能は非常に強力で、コマンドライン引数は数十種類に及ぶ。習熟すれば、Postman のような GUI ツールを完全に置き換えることができる。

本記事では、その主なコマンドライン引数を日常の参考として紹介し、参照しやすくする。内容は主に『curl cookbook』から翻訳したものである。紙面を節約するため、以下の例には実行時の出力は含まれていない。初心者は、以前に書いた『curl 初心者チュートリアル』を先に参照するとよい。

-d パラメータを使用すると、HTTP リクエストに自動的にContent-Type : application/x-www-form-urlencodedヘッダーが追加される。また、リクエストは自動的に POST メソッドに変換されるため、-X POSTを省略できる。

–data-urlencode

--data-urlencode パラメータは-dと同等で、POST リクエストのデータ本体を送信するが、違いは送信するデータを自動的に URL エンコードすることである。
