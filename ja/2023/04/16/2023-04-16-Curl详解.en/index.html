Curl Detailed Explanation

curl -kfsSL

  • -k/--insecure Allow connecting to SSL sites without certificates
  • -f/--fail Do not display http errors when connection fails. On server error, prevent an HTML page indicating the error cause from being returned, and instead have the curl command return error code 22 to indicate the error (avoid returning HTML, which is inconvenient for debugging)
  • -s/--silent Silent mode. Output nothing. Will not output errors and progress information.
  • -S/--show-error Show errors. Specifies to output only error information, usually used together with -s.
  • -L/--location Makes HTTP requests follow server redirects. curl does not follow redirects by default.

curl -fsSL means that when using the curl command to download files, it does not display progress or error information, stops immediately if the download fails, and automatically follows redirects. This is usually a quiet, safe, and stable way to download files.

Differences

  • -l/--list-only List the file names in the ftp directory
  • -F parameter is used to upload binary files to the server.

Other Options

-o parameter saves the server response as a file, equivalent to the wget command.

curl -o example.html https://www.example.com

-O parameter saves the server response as a file, and uses the last part of the URL as the filename. (No need to name it)

curl -O https://www.example.com/foo/bar.html

--limit-rate is used to limit the bandwidth of HTTP requests and responses, simulating a slow network environment.

curl --limit-rate 200k https://google.com

Introduction

curl is a commonly used command-line tool used to request Web servers. Its name means the client (client) URL tool.

Its functionality is very powerful, with as many as dozens of command-line parameters. If you are proficient, it can completely replace GUI tools like Postman.

This article introduces its main command-line parameters, as a daily reference for easy lookup. The content is mainly translated from 《curl cookbook》。为了节约篇幅，下面的例子不包括运行时的输出，初学者可以先看我以前写的《curl Beginner’s Tutorial》。

When used without any parameters, curl sends a GET request.

-A

-A parameter specifies the client’s User-Agent header, i.e. User-Agent. curl’s default User-Agent string is curl/[version].

The above command changes User-Agent to the Chrome browser.

The above command removes the User-Agent header.

You can also directly specify the header via the -H parameter to change User-Agent.

-b

-b parameter is used to send Cookies to the server.

The above command generates a header Cookie: foo=bar, sending a Cookie named foo with value bar to the server.

The above command sends two Cookies.

The above command reads the local file cookies.txt, which contains Cookies set by the server (see the -c parameter), and sends them to the server.

-c

-c parameter writes the Cookies set by the server to a file.

The above command writes the Cookies set by the server’s HTTP response to the text file cookies.txt.

-d

-d parameter is used to send the data body of a POST request.

After using the -d parameter, the HTTP request automatically adds the header Content-Type : application/x-www-form-urlencoded. It also automatically converts the request to the POST method, so -X POST can be omitted.

-d parameter can read data from a local text file and send it to the server.

The above command reads the contents of the data.txt file and sends it to the server as the data body.

--data-urlencode parameter is equivalent to -d, sending the data body of a POST request, with the difference that it automatically URL-encodes the sent data.

-e

-e parameter is used to set the HTTP header Referer, indicating the origin of the request.

The above command sets the Referer header to https://google.com?q=example.

-H parameter can achieve the same effect by directly adding the header Referer.

-F

-F parameter is used to upload binary files to the server.

The above command adds the header Content-Type: multipart/form-data to the HTTP request, then uploads the file photo.png as the file field.

-F parameter can specify the MIME type.

The above command specifies the MIME type as image/png; otherwise curl will set the MIME type to application/octet-stream.

-F parameter can also specify the filename.

-G

-G parameter is used to construct the URL query string.

The above command sends a GET request, and the actual requested URL is https://google.com/search?q=kitties&count=20. If --G is omitted, a POST request will be sent.

If the data needs URL encoding, you can combine it with the --data--urlencode parameter.

-H

-H parameter adds HTTP request headers.

The above command adds the HTTP header Accept-Language: en-US.

The above command adds two HTTP headers.

The above command adds the HTTP request header Content-Type: application/json, then uses the -d parameter to send JSON data.

-i

-i parameter prints the HTTP headers of the server response.

After receiving the server response, the above command first outputs the response headers, then a blank line, then the webpage source code.

-I

-I parameter sends a HEAD request to the server, and then prints the HTTP headers returned by the server.

The above command outputs the server’s response to the HEAD request.

--head parameter is equivalent to -I.

-k

-k parameter specifies skipping SSL verification.

The above command will not check whether the server’s SSL certificate is correct.

-L

-L parameter makes HTTP requests follow server redirects. curl does not follow redirects by default.

–limit-rate

--limit-rate is used to limit the bandwidth of HTTP requests and responses, simulating a slow network environment.

The above command limits the bandwidth to 200K bytes per second.

-o

-o parameter saves the server response as a file, equivalent to the wget command.

The above command saves www.example.com as example.html.

-O

-O parameter saves the server response as a file and uses the last part of the URL as the filename.

The above command saves the server response as a file, with the filename bar.html.

-s

-s parameter will not output error and progress information.

Once an error occurs, the above command will not display error information. If no error occurs, it will display the running result normally.

-S

-S parameter specifies outputting only error information, usually used together with -s.

The above command has no output unless an error occurs.

-u

-u parameter is used to set the username and password for server authentication.

The above command sets the username to bob, the password to 12345, and then converts them into the HTTP header Authorization: Basic Ym9iOjEyMzQ1.
