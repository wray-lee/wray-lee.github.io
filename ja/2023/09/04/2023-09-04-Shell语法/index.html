ファイル記述子

0 標準入力

1 標準出力、画面を指す

2 標準エラー出力（log が属する）

演算子

< 入力リダイレクト command < file ファイルから読み込む

<< 入力追加リダイレクト command << EOF 後続の入力をEOFまで読み込む （コマンドに終了条件を追加するために使用できる）

| パイプ、左側の文の出力を右側の文の入力とする

|| OR OR、左側の文の実行が失敗した場合にのみ右側の文を実行する

& AND、左側の文は実行の成否にかかわらず右側の文を実行し、AND でつないだすべての文を実行する。 末尾に置くとプログラムをバックグラウンドで実行させる

&& AND AND、左側の文の実行が失敗すると右側の文は実行せず、成功すれば右側の文を実行する

! 条件式の否定

>& ファイル操作記号, 例:2>&1 , 2>1はエラー出力を 1 という名前のファイルにリダイレクトする。&は後続の1がファイル記述子であることを定義するため

​ 用法：echo "hello" > a.log 2>&1 1 は a.log にリダイレクトされ、2 は a.log にリダイレクトされる。これは 2 を 1 にリダイレクトすることに等しく、目的は log に通常出力とエラー出力を記録すること

​ 省略してecho "hello" >&log または echo "hello" &>logと書ける

2&>1 >log は無効な入力であり、error が 1 ファイルに書き込まれる原因になる

-a 条件式の並列（AND）

-o 条件式の OR

$ 後ろに変数名を続けると全体で 1 つの変数を表す

echo -e エスケープ文字を認識できる

権限

Linux のセキュリティシステムは SELinux（Security-Enhanced Linux）であり、ファイル権限を管理できる

ls -lZht

unconfined_u:object_r:user_home_t:s0 はファイルとディレクトリのセキュリティコンテキストである。これには、ファイルまたはディレクトリが属するユーザー、ロール、オブジェクトクラス、およびセキュリティレベルに関する情報が含まれる。

  1. unconfined_u：そのファイルまたはディレクトリが属する SELinux ユーザーを表す。unconfined_u は特別なユーザー識別子であり、制限されていないユーザー、すなわち厳格な SELinux ポリシーの制限を受けていないユーザーを表す。
  2. object_r：そのファイルまたはディレクトリが属する SELinux オブジェクトロールを表す。オブジェクトロールは、SELinux ポリシーにおいてそのオブジェクトの操作を許可するロールの集合を定義する。
  3. user_home_t：そのファイルまたはディレクトリの SELinux オブジェクトタイプを表す。オブジェクトタイプは、ファイルまたはディレクトリの用途と許可される操作を定義する。user_home_t は一般的なオブジェクトタイプであり、ユーザーのホームディレクトリを表すために使用される。
  4. s0：そのファイルまたはディレクトリの SELinux セキュリティレベルを表す。セキュリティレベルはオブジェクトのアクセス権限を制御し、アクセスルールに従って制限するために使用される。

例:

systemd_unit_file_t は SELinux のオブジェクトタイプの 1 つであり、systemd ユニットファイルのセキュリティコンテキストを表すために使用される。
