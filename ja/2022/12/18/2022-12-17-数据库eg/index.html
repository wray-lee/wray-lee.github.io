查表

use mysql;

select Host,User,Password,Select_priv,Grant_priv from user;

更改密码

update user set password=password<'123456'> where user='root';

flush privileges;

删除空用户

delete from user where user='';

flush privileges;

看user表

desc user;

查看db表

desc db

查看host表

与DB表结合使用在一个较好层次上控制特定主机对数据库的访问权限，这可能比单独使用DB好些。这个表不受GRANT和REVOKE语句的影响。

desc host;

创建test用户，随后删除

grant all privileges on *.* to test@localhost identified by 'test' with grant option;

select User,Password from user;

*.*意味着“所有数据库、所有表”。with grant option表示它具有grant权限。用grant语句创建权限是不需要再手工刷新授权表的，因为它已经自动刷新了。

删除

删除权限

revoke all on *.* from test@localhost;

删除用户

delete from user where user='test';
