Linux三銃士

sed

-i 写入文件

-i.bak 写入文件并备份

出力

複数行を1行に結合

空行を削除

自動出力を抑制

sed はマッチ/置換を行うたびに処理対象行を出力します。-n を指定すると、マッチした行だけを出力します。

grep

-E 指定为正则表达式

awk

パターンとアクションから構成され、1つのパターンには必ず1つのアクションが必要です。

組み込み変数

$0 各行

NR 行番号

$NF 最後の列

複数パターンに1つのアクション

awk 'length ($0) > 1 {} /^w/ {print $NF}'

awk 'length ($0) > 1 && /^w/ {print $NF}'

区切り文字を指定

awk -F '[分隔符]'

print

複数の print で改行しない

awk '{printf "%s %s %s\n", $1, $6, $7}'

awk 'BEGIN{ORS=""}{print $1, $6, $7, "\n"}'

\n の理由は、awk には出力バッファがあり、\n に遭遇したときだけ内容を出力するためです。

grep の代替

awk '/ZvpKA/ || /dkXfJ/ {printf "%s %s %s\n", $1, $6, $7}'

よく使う用法

まず不可視文字を削除する必要があります

sed -i '1s/^\xef\xbb\xbf//' /var/log/nginx/drive.log

$1 の重複を除外する

スクリプトから awk を読み込んで実行

awk [选项参数] -f [.awk] var=value file(s)

組み込み関数

  • BEGIN パターン：awk が入力行を1行でも読み込む前に、BEGIN で指定されたアクションを即座に実行することを指します。BEGIN{}
  • END パターン：awk が正式に終了する前に、END で指定されたアクションを実行することを指します。END{}

awk の文字列系組み込み関数

注意してください。awk で文字インデックスを扱う関数では、インデックス位置はすべて1から数え始めます。他の言語で0から始まるのとは異なります。

基本関数

  • sprintf(format, expression1, ...)：フォーマットされた文字列を返します。参考：sprintf

    • a=sprintf("%s\n","abc")

  • length()：文字列の文字数、配列要素数、または数値を文字列に変換した後の文字数を返します

  • strtonum(str)：文字列を10進数値に変換します

    • str が 0 で始まる場合、8進数として認識します
    • str が 0x または 0X で始まる場合、16進数として認識します

  • tolower(str)：小文字に変換

  • toupper(str)：大文字に変換

  • index(str,substr)：str から substr（部分文字列）を検索し、見つかったインデックス位置を返します（インデックスは1から開始）。見つからなければ0を返します

awk substr()
  • substr(string,start[,length])：string から部分文字列を切り出します

start は切り出しの開始インデックス位置です（インデックス位置は0ではなく1から始まります）。length は切り出す部分文字列の長さを表します。length を省略した場合、start から残りのすべての文字を切り出します。

start の値が1より小さい場合、1 として扱います。start が文字列の長さより大きい場合、空文字列を返します。

length が0以下の場合、空文字列を返します。

awk split() と patsplit()
  • split(string, array [, fieldsep [, seps ] ])：文字列を分割して配列 array に保存します。配列のインデックスは1から保存されます。分割して得られた要素数を返します

ここで fieldsep は区切り文字を指定し、正規表現方式にすることもできます。この引数を指定しない場合、デフォルトで FS を区切り文字として使用し、FS のデフォルト値はスペースです。

seps は配列で、分割時の各区切り文字を保存します。

split は処理を開始するとき、まず配列を空にします。したがって、split の string 引数を空に設定すると、配列を空にするために使用できます。

区切り文字が文字列にマッチできない場合、文字列全体が1つの配列要素として配列 array に保存されます。

  • patsplit(string, array [, fieldpat [, seps ] ])：正規表現 fieldpat で文字列 string をマッチし、マッチに成功したすべての部分を配列 array に保存します。配列のインデックスは1から保存されます。戻り値は array の要素数、つまり何回マッチに成功したかです

fieldpat を省略した場合、デフォルトで定義済み変数 FPAT の値を使用します。

awk match()
  • match(string,reg[,arr])：reg を使用して string をマッチし、マッチに成功したインデックス位置を返します（1から数えます）。マッチに失敗した場合は0を返します。arr 引数を指定した場合、arr[0] にはマッチに成功した文字列が保存され、arr[1]、arr[2]、… には各グループでキャプチャされた内容が保存されます

match のマッチ時には、同時に2つの定義済み変数 RSTART と RLENGTH が設定されます。

  • マッチに成功した場合：
    • RSTART にはマッチに成功したインデックス位置が代入されます（1から数えます）
    • RLENGTH にはマッチに成功した文字長が代入されます
  • マッチに失敗した場合：
    • RSTART には0が代入されます
    • RLENGTH には-1が代入されます

awk sub() と gsub()
  • sub(regexp, replacement [, target])
  • gsub(regexp, replacement [, target])：sub() のグローバルモード

sub() は文字列 target から正規表現マッチを行い、replacement を使用して最初にマッチに成功した部分を置換し、置換後は target に保存し直します。置換に成功した回数、つまり0または1を返します。

target は、置換に成功した結果を保存するために、代入可能な変数名、$N、または配列要素名でなければなりません。文字列リテラルにはできません。データを保存できないためです。

target を省略した場合、デフォルトで $0 を使用します。

注意すべき点として、target を省略した場合、または target が $N である場合、置換に成功した後、OFS を使用して $0 が再計算されます。

replacement 引数では、特別な記号 & を使用して、マッチに成功した部分を参照できます。注意してください。sub() と gsub() は replacement 内で後方参照 \N を使用できません。

replacement 内で & を純粋な文字として使用したい場合は、エスケープするだけです。

2本のバックスラッシュ：
awk は正規表現の処理を開始するとき、まずすべての awk コードを走査してから awk の内部形式にコンパイルします。走査中にバックスラッシュエスケープを解析し、\\ を1本のバックスラッシュに変えます。実際に実行が始まると、sub() がさらに解析するため、このとき \& が & をエスケープすることを表します。
コードを走査する段階は字句解析段階と呼ばれ、実行解析段階はランタイム解析段階と呼ばれます。

awk gensub()

gawk がサポートする gensub() は、sub() と gsub() を完全に置き換えられます。

  • gensub(regexp, replacement, how [, target])：

sub() と gsub() を代替できます。

how は何番目のマッチを置換するかを指定します。たとえば1を指定すると、最初のマッチだけを置換することを表します。さらに、g または G で始まる文字列を指定することもでき、グローバル置換を表します。

gensub() は置換後に得られた結果を返し、target は変化しません。マッチに失敗した場合は target を返します。これは sub()、gsub() とは異なります。sub()、gsub() が返すのは置換に成功した回数です。

gensub() の replacement 部分では \N を使用してグループマッチの結果を参照できますが、sub()、gsub() では後方参照を使用できません。さらに、gensub() では replacement 部分で & または \0 を使用して、マッチした結果全体を表すこともできます。

awk asort() と asorti()
  • asort(src,[dest [,how]])
  • asorti(src,[dest [,how]])

asort は配列 src の値をソートし、ソート後の値のインデックスを1、2、3、4…の連番に変更します。src 内の要素数を返し、それをソート後のインデックスの最大値とみなすことができます。

asorti は配列 src のインデックスをソートし、ソート後のインデックス値のインデックスを1、2、3、4…の連番に変更します。src 内の要素数を返し、それをソート後のインデックスの最大値とみなすことができます。

dest を指定した場合、元の配列 src を dest にバックアップし、その後 dest をソートします。src は変更されません。

how 引数はソート時の方式を指定するために使用します。その値の指定方法は PROCINFO["sorted_in"] と同じです。定義済みのソート関数でも、ユーザー定義のソート関数でもかまいません。参考：配列の走査順序を指定する。

netstat -anp | grep 9993 | awk -F ' ' '{len=split($7,arr,"/");for(i=1;i<len;i++){$7=arr[i];print $7} | xargs kill }'
