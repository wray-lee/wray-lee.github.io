Network address

The network number is reserved, and all remaining bits are 0; this is the first assigned address (reserved).

Subnet mask

The network number and subnet number are all 1s, and the remaining host number bits are all 0s.

DTE cable is the opposite.

Cast

  • UniCast: The most common communication method, one-to-one connection communication.

  • BroadCast: By sending packets to the broadcast address 255.255.255.255, the router/switch sends packets to query all devices in the area, causing CPU interrupts (ARP, finding IP).

  • MultiCast:

    • Devices in the group listen on a multicast address (224.0.0.0/4); users send packets to the multicast address, and a designated device responds. In this case, the listening IP is equivalent to a channel (mDNS (all service devices listen on the multicast IP and subsequently provide services via unicast))
    • Devices in the group listen on a multicast address (224.0.0.0/4); users send packets to the multicast address to join the group, and the content server continuously pushes to this multicast address (IPTV (directly distributing content within the channel))
    • Through an RP (Rendezvous Point) server listening on a multicast address, packets sent by users are distributed to servers in the group.
    • NDP, which replaces ARP under IPV6: a device initially listens on a multicast address of ff02::1:ff (bound MAC: 33:33:ipv6后缀), informing the router of the bound device. When a user looks up the MAC for an IPv6 address, they access the multicast address + multicast MAC, and the device then returns the real NIC MAC of the IPv6 address.

  • AnyCast: Servers in different geographical locations share one IP. When a user accesses the IP, BGP path selection automatically chooses the optimal-distance server to access.
