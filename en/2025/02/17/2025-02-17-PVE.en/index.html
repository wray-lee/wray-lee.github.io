Nas

kernel panic

  • Change network device e1000 to virio

  • Set Async IO for the Synology system disk to threads.

  • Modify the /etc/default/grub file, find the GRUB_CMDLINE_LINUX_DEFAULT item, then add the noxsave instruction at the end.

    Then execute update-grub to update the bootloader.

Disable integrated graphics

SataPortMap 060102 The 1st controller has 6 ports, the 2nd has 1, and the 3rd has 2.

DiskIdxMap From left to right, every two digits are the disk sequence number of one controller (the position from which disks start to be recognized) 000607 The first controller starts at 0, the second starts at 6, and the third starts at 7.

If 0506, then the 6 disks of the first controller will not be recognized (disk sequence numbers start from 00)
