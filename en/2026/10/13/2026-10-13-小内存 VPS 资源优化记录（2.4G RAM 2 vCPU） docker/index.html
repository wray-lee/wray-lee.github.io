Small-Memory VPS Resource Optimization Log (2.4G RAM / 2 vCPU)

Instance: RackNerd VPS (Ubuntu 22.04), 2026-10-13

Before and After Optimization

Metric Before After
Load (load average) 4.5–5 0.4–0.5
Available memory (MemAvailable) ~515 MB ~880 MB
openclaw restart time ~15 minutes ~2 minutes
openclaw RSS 1.0–1.24 GB (triggered memory pressure warnings) ~0.9 GB
zerotier CPU ~50% single core <1%
eth0 包速率 ~25,000 pps ~80 pps

1. ZeroTier：多 IPv6 地址导致路径探测风暴（CPU 杀手）

现象：zerotier-one 常驻 ~50% CPU，eth0 每秒几万个 71/166 字节的 UDP 包，zt 接口本身几乎没流量。

原因：eth0 配了 20 个 IPv6（/etc/network/interfaces 静态配置），ZeroTier 默认在每个本地地址 × 3 个端口上绑定，
并与对端（也是多地址 IPv6 家宽）的所有地址/端口组合做打洞和保活，组合爆炸。
它还绑定了 docker 网桥、netbird wt0、warp，出现 ZT 套 netbird 的双重隧道。

修复：/var/lib/zerotier-one/local.conf

Troubleshooting method: top -H -p $(pidof zerotier-one) inspect threads, /proc/net/dev two samples to calculate pps,
tcpdump -ni eth0 -c 20000 -q collect port distribution stats.

2. OpenClaw

2.1 Skip doctor on every startup (restart 15 min → 2 min)

The official image entrypoint /app/docker-entrypoint.mjs unconditionally runs
openclaw doctor --fix --non-interactive before starting the gateway in the foreground (no environment variable can disable it), taking over ten minutes on weak machines.

/root/openclaw/docker-compose.yml:

Cost: must run doctor manually after updating the image, already scripted as /root/openclaw/doctor.sh:

2.2 Disable unused plugins (loaded 16 → 7, startup ~30 s faster)

Plugin Purpose Reason for disabling
anthropic / xai / ollama Model providers from the corresponding vendors Only use a custom openai-completions provider
canvas A2UI dashboard component in Control UI Only use Telegram/Slack
cua-computer Direct desktop control (Computer Use) Container has no desktop
device-pair / geolocation / talk-voice Device pairing / geolocation / voice Unused
github Public repo link preview in Control UI Unused

Kept: browser, file-transfer, linux-node, memory-core, openai, slack, telegram.
When needed, restore via plugins enable <id>. Config backup: data/openclaw.json.pre-memopt.

2.3 Limit memory growth

RSS far exceeds the V8 heap (~1GB vs ~290MB); the majority is native memory: worker threads, SQLite, plugins.
Further reduction requires disabling features (e.g., browser, memory-core).

3. System Level

3.1 Disable fwupd (-141 MB)

Firmware update service, useless on a VPS yet resident at 141MB:

3.2 zram compressed swap

Disk swap zram
Location Disk file Memory (compressed)
Paging latency Milliseconds; VPS disk IO is shared and throttled Microseconds
Space Occupies disk zstd compresses to roughly 1/3; a full 1GB actually occupies ~300–400MB of memory
Cost IO slows other services Small amount of CPU
  • Disk swap (8G file + 1.2G partition) kept as a fallback.
  • Old pages already on disk swap will not migrate on their own; after being read back, they will naturally enter zram when swapped out again;
    Do not run swapoff /swap just to migrate, as it would read hundreds of MB back into memory at once.

4. Measurement: fgc (free-games-claimer) memory peak

Restart fgc to trigger login checks for all sites, sampling every ~3 seconds:

Phase fgc usage System available memory
Idle 25–56 MB ~730 MB
During check (~70 seconds, launching Chromium site by site) Peak ~520 MB Minimum ~520 MB
End Falls back ~730 MB

Conclusion: short-term peak ~500MB; a 2.4G machine can handle it, not worth migrating specifically for it.

5. Current memory budget

Component Resident
openclaw ~900 MB
sub2api + postgres + redis ~95 MB
ArchiSteamFarm ~65 MB
workbuddy2api / line_backend / whisper ~55 MB
fgc ~50 MB (daily short-term ~500 MB)
dockerd / netbird / zerotier etc. ~100 MB

6. Should we switch machines in the future

Memory prices rising in 2026 (Hetzner CAX +31%, Netcup +40%, many out of stock); after optimization this machine suffices, make do for now.
If on Black Friday (11/27) there is an 8GB plan with same renewal price (≤ $60–90/year), migrate the whole machine.
Note: cheap ARM (Ampere Altra) single-core is weaker than new EPYC/Ryzen, and openclaw (mostly Node single-threaded) will not be faster;
ARM’s advantage is more cores and larger memory at the same price.
