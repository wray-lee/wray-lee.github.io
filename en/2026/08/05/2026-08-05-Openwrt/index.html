Hardware Acceleration

firewall

wed

Check cat /sys/kernel/debug/mt76/mt7915/wed_mode

Scheduled Reboot

* * * * * sleep 70 && touch /etc/banner && reboot

sleep 70 Avoid repeated reboots due to identical timestamp verification after reboot

touch /etc/banner Clear login records, and at the same time touch to avoid the router not doing NTP in time causing time verification; set the router time to the time at reboot, touch file makes the time after reboot (before NTP) the last modification time of the file

Caused by uhttpd

No Network After Reboot

On some specific CPU architectures (such as some MediaTek, Realtek solutions, or old x86 NICs), OpenWrt’s open-source drivers are not perfect. During a system soft reboot, it fails to successfully send a reset instruction to the NIC chip

2.5G Interface Failure (rtl822x)

Interface deadlock caused by unstable driver, needs to be reloaded

ipv6 nat

Interface Reboot

Commonly used when zetotier and other intranet penetration/tunneling are unreachable (slow WAN port startup)

/etc/hotplug.d/iface/99-zerotier

Interface Traffic Splitting

MWAN3

Disable all hardware acceleration, firewall & wed

Because of public network traversal, for IPv6 it is best not to use load balancing when not using NAT6

  1. Register Interfaces: Register all interfaces you want to split traffic across

  2. Add Members: Create MWAN interfaces, set metric (priority), weight (traffic ratio)

  3. Set Policies: Bundle the required members (that need to be split together) into one policy. For public network allocation, a separate policy needs to be set here

  4. Set Rules: Destination address 0.0.0.0/0, i.e., split all external network IPs. For public network allocation, source address filtering needs to be set here.

Rules ultimately determine the effect. If you need to test, create a policy bound to a single interface and create a rule moved to the top

Test interface: mwan3 use {interface} curl api.ipify.org

Manual Configuration

Preserve External Access

Create a routing table (if registering a name, it needs to be written to a file)

echo "101 pppoe" >> /etc/iproute2/rt_tables

/etc/nftables.d/99-pppoe-mark.nft

/etc/hotplug.d/iface/99-pppoe-policy-route

Public Network Access

Configure inbound for the router’s own services in traffic rules

Configure forwarding for services within the subnet in port forwarding

For subnet public IPv6 to be accessed externally, configure traffic rules

Assign Public IPv6 to Subnet (only needed in /64 PD case)

/64 is the smallest physical broadcast domain (subnet), i.e., /64 should be treated as network nodes communicating directly (responding to NDP, same link on-link), so an NDP proxy is needed

/60 /56 and larger ranges can be routed by default and can be forwarded

Forwarding state next-hop and endpoint state on-link

Enable DHCP server on wan6: enable the specified main interface, change RA, DHCP, and NDP all to relay

LAN v6 configuration: change RA, DHCP, and NDP all to relay

If using only one public IPv6, enable IPv6 masquerading (NAT66) in advanced settings under firewall WAN

Configuration Lost After Running for a While

TTL boot, press f and Enter to enter fix mode
