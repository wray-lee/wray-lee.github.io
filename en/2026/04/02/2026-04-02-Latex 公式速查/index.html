Latex Formula Quick Reference

This article records some commonly used Latex characters corresponding to mathematical formulas, for quickly finding the needed characters.

All character formulas used in Latex need to be placed between \( and \), $ and $, \begin{math} and \end{math}.

For relatively large mathematical formulas, such as formulas that need a separate paragraph, you need to use \[ and \] or \begin{displaymath} and \end{displaymath} to write the formula.

Inline and Display

$$
Inline (limits): \sum\limits^n_{i = 1} \
Display (nolimits):\sum\nolimits^n_{i = 1} \
$$

Formula Numbering

Manual numbering method. The manual numbering method can be used in this formula $$x^n+y^n=z^n$$, add \eqno{(1)} for numbering. The 1 here is the formula number; try entering it yourself and you’ll see.

Automatic numbering requires using equation

Spaces

In Latex formulas, use ~, \quad and \qquad to represent spaces.

Line Breaks

Use \\ for line breaks.

$\alpha,\beta, \gamma,\lambda,\xi,\pi,\mu,\Phi,\Omega$

For uppercase characters, just capitalize the first character.

Superscripts and Subscripts

Use ^ for superscripts and _ for subscripts.

If you need to add multiple characters after a superscript or subscript, use curly braces to put the multiple characters together.

$a^{x+y}+L_{dexi} = doubi$

Square Roots

The input command is: \sqrt; for an n-th root, it is correspondingly: \sqrt[n]; if you only need the symbol, use \surd.

$\sqrt{a^2}-\sqrt[5]{a}=\surd{a}$

Horizontal Lines

Use \overline and \underline to draw horizontal lines above and below an expression.

Horizontal lines are also overlines and underlines.

Overbraces

Use \overbrace and \underbrace to add curly braces above and below an expression.

Vectors

Vectors can use \vec; if you want to define from left to right, use \overleftarrow.

Fractions

Fractions use \frac followed by two curly braces; the first is the top, the second is the bottom.

Binomial Coefficients

Binomial coefficients can use { 第一项 \choose 第二项 } or { 第一项 \atop 第二项 }.

Note that the first term and the parenthesis need a space, and the second term and the parenthesis need a space.

Operations

Integral symbol \int

Summation operator \sum

Product operator \prod

Parentheses

Round parentheses and square brackets can be entered directly; curly braces \{

The size of parentheses can use \big, \Big, \bigg and \Bigg to represent different sizes; different parentheses and | can be added after them.

Dots

When entering ellipses, dots are often needed. \ldots uses alignment below, \cdots is centered, \vdots is vertical, \ddots is diagonal.
