    Constraint Types

    1. Primary key constraint (primary key): ensures the field is non-null and unique; a table can have only one primary key; the primary key is the unique identifier of the fields in the table
    2. Not null constraint (not null): ensures the field is not null
    3. Unique constraint (unique): ensures the field is unique, but it can be null
    4. Foreign key constraint (foreign key): a primary key or unique key of another table that exists in a table becomes the foreign key of this table
    5. Default constraint (default): ensures the field has a default value

    Create, delete, query, update

    • Create: insert into 表名(键1,键2……) values(值1,值2……)

    Multiple groups of fields insert into 表名(key1,key2……) values(value1,value2)(value3,value4)

    • Update: update 表名 set 键名='值' where 条件(列值)
    • Delete:

    Physical deletion: delete from 表名 where 条件

    Logical deletion

    • Query:

    select *(列名) from 表名

    select 列 from 表 where 条件

    select 列 from 表 by 某列 ASC(升序)/DESC（降序）

    	`select GROUP_CONTACT(列) from 表 where`	Display query results in row form

	`select 列 from 表 order by 数字`		The number of keys displayed; if greater than existing, an error occurs; if less, it displays normally

	`select 列 from 表 limit 5 `	Limit display to the first 5 rows

    `select 列 from 表 limit 5(偏移量)，10(显示行数) `	Limit display to rows 6-15

	`select 数字（其他任意内容）,数字（其他任意内容）…… `	will output the input content according to the display position; **the number of columns echoed by the database is fixed, and only when the display position is satisfied will there be an echo**

    SQL Injection

    Injection location

    Injection location: GET, POST, HEAD header

    Strings are enclosed in single quotes; numbers do not have single quotes

    Single quotes can be commented out with #

    union

    The union keyword performs a union query, combining two SELECT statements into one statement and displaying them as one result.

    In a union query, the two SELECTs must have the same number of fields (union requires the queried tables to have the same number of columns and field types).

    union all directly merges all data together

    union deduplicates the merged data
