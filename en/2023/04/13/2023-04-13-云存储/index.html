Windows

Install alist and winfsp, sshfs, rclone

rclone Capacity Size Display

If it is only for displaying the total size, you can manually set the total size via --vfs-disk-space-total-size when rClone mounts, and use --vfs-used-is-size to make rClone actively calculate the used space. However, this is only for convenient display. If the WebDAV server does not actively implement the attribute required by rClone about, then when mounting you cannot know information such as used space or total file count. If you want to work with rClone’s Union backend, there is still no way to select a remote based on remaining space or used space.
