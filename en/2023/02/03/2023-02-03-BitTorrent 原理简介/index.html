    Introduction to BitTorrent Principles

    By January 12, 2017 P2P P2PBTTCPUDPTrackerDHT

    Introduction

    Previously, I used Murder software’s BT upload/download method in a production environment to achieve rapid distribution of large files.
    This is an application of BT software. Recently, I took another look at the analysis and implementation of the BT protocol, and now I am re-familiarizing myself with the principles of the BT protocol.

    Brief Overview of BitTorrent Principles

    Although current mainstream BT software is mostly similar, each piece of software often has its own characteristics.

    Of course, none of these can play a decisive role. As mentioned earlier, BT download speed depends on other users’ upload speed, so the more users the better, and users are obtained through Peer, DHT, Tracker.

    Peer: It only works after obtaining a valid user; that user will tell you the user information it has obtained.
    ——
    DHT: Stores user information in a distributed manner. After obtaining a user, it will obtain more user information through that user. The disadvantage is that it needs to be built up (by downloading popular resources).

    There is not much we can do about Peer and DHT, but most software supports custom Trackers. So if your BT software supports custom Trackers, you can try this project that aggregates popular Trackers from across the internet:

    • Official website: trackerslist.com
    • Project homepage: github.com/XIU2/TrackersListCollection
    • Related article: zhuanlan.zhihu.com/p/85135793

    This raises a question: *What is a Tracker?*

    Tracker is an almost indispensable role in BT downloads.

    Tracker: Records information about users downloading the same resource and provides it to you, helping you establish connections with other users.
    *The advantages and disadvantages of the above three are complementary; none can replace another, and using them together works best!*

    Using Trackers can help you obtain more users; as the number of users increases, the download speed will increase accordingly.

    The more people use these Trackers, the more users there are, and the faster everyone’s download speed will be!
