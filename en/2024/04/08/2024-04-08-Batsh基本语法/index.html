Batsh Basic Syntax

Comments

  1. Single-line comment rem blabla
    @REM blabla
    :: blabla
  2. End-of-line or single-line comment %blabla%

Adding > nul after a command can hide the command output.

Syntax

Header

Usually @echo off is entered at the beginning

echo is an echo command, equivalent to cout, but it displays itself
Using @echo off can prevent echo from being displayed
@ makes the echo of this command not displayed either

Delay Command

timeout -t <font color=Gainsboro>*time* </font>

Equivalent to sleep()

Directory Structure

%~dp0 is the current directory where the file is located

Dir Function

DIR *.* /B >list.txt Extracts all file names in the current directory to list.txt

Can be used directly for iteration

dir Used with for

for /f "delims= ,token= " in ('dir /a-d /b') do{}

delims is used to split elements under a directory:
{“Row 1 Column 1 Row 1 Column 2 Row 1 Column 3”, // first element

“Row 2 Column 1 Row 2 Column 2 Row 2 Column 3”, // second element

“Row 3 Column 1 Row 3 Column 2 Row 3 Column 3”} // third element

->

Row 1 Column 1
Row 2 Column 1
Row 3 Column 1

token is used to take the part after delims splitting

for /f "tokens=2 delims= " %%i in (a.txt) do echo %%i

Execution result:

Row 1 Column 2
Row 2 Column 2
Row 3 Column 2

Identifier

/R %%i is used to traverse the current directory

Operators
  • %%~

Services

sc is only used for services

net can be used for services as well as most scenarios involving network, users, and logon

sc cannot be executed in the command line, but can be executed normally in a bat script

net does not have this problem

sc is only used for services, and the output is detailed

Privilege Escalation

  • Run shortcuts as administrator
  • runas command
  • Start-Process command in PowerShell
  • VBS calls ShellExecute of the Shell.Application object
