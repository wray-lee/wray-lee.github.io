// Set as a protected operating system file, and hide it
attrib d:\n.txt +s +h

// Unset as a protected operating system file, and unhide it
attrib d:\n.txt -s -h

       [drive:][path][filename] [/S [/D] [/L]]
  +  Sets an attribute.
  -  Clears an attribute.
  R  Read-only file attribute.
  A  Archive file attribute.
  S  System file attribute.
  H  Hidden file attribute.
  I  Not content indexed file attribute.
  [drive:][path][filename]
      Specifies files that attrib is to process.
  /S  Processes matching files in the current folder and all subfolders.
  /D  Processes folders as well.
  /L  Processes the attributes of symlinks and symlink targets.
