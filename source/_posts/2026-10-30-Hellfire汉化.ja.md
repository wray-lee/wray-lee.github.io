# Hellfire 中国語言語パックのメモ

## 問題

Hellfire はインストール後も英語インターフェースで、設定でも中国語を選択できない。以前 AUR の Firefox に入れた中国語パックは役に立たなかった。理由はバージョンが合わないことにある。Linux 上の hellfire は 160.0 で、そのパックは 157 用で、157.* しか認識しない。しかもそれは Firefox 自身の profile に入っており、hellfire はまったく読み込まない。

## Linux 上での解決方法

hellfire の profile は `~/.mozilla/firefox/p9luzrhy.default-default` にある。どれを使うかは、各 profile 内の `compatibility.ini` にある `LastVersion` を見ればよく、バージョンが 160.0 のものがそれだ。

1. 公式正式版の 160.0 言語パックはまだ公開されておらず、ダウンロードしたのは beta 版: `https://ftp.mozilla.org/pub/firefox/releases/160.0b2/linux-x86_64/xpi/zh-CN.xpi`。パック内の `manifest.json` にある `strict_max_version` は `160.*` で、ちょうどカバーしている。
2. ブラウザを閉じ、`<profile>/extensions/langpack-zh-CN@firefox.mozilla.org.xpi` にコピーする。ファイル名は一字一句同じでなければならない。
3. `user.js` に次の2行を追加する:
   ```js
   user_pref("intl.locale.requested", "zh-CN,en-US");
   user_pref("extensions.autoDisableScopes", 0);
   ```
4. 再起動する。言語パックが認識されると、設定の言語一覧が表示され、中国語も有効になる。

2行目は、手動で入れたパックが自動的に無効化されるのを防ぐだけなので、有効になった後は削除してよい。そうしないと、今後手動で入れた拡張機能がすべて自動的に有効化されてしまう。

分かっていないこと: 最初に設定でなぜこれ以上言語を検索できなかったのか。Mozilla の API を調べたところ、160.0 に対して 103 言語を返せるので、サーバーにパックがないわけではない。言語一覧にキャッシュがあり、再起動後にキャッシュされたロケールが zh-CN になったことで初めて更新されたのだと推測しているが、これは単なる推測だ。

## Windows 上での状況

Windows 上の hellfire は 158.0.1 で、`C:\Tools\Firefox` にインストールされており、profile は `%APPDATA%\Mozilla\Hellfire\Profiles\64elc7uz.default-default-1` にある。そこにはすでに `extensions\langpack-zh-CN@firefox.mozilla.org.xpi` があり、158 の言語パックである(`strict_max_version` は `158.*`)。`prefs.js` 内の `intl.locale.requested` も `zh-CN,en-US` である。Linux 上でのやり方と同じことで、バージョンが一致する zh-CN パックを hellfire 自身の profile に置く。

注意: profile ディレクトリは `Mozilla\Hellfire` であり、`Mozilla\Firefox` ではない。このマシンには `Mozilla\Firefox` というディレクトリもない。したがって、以前「Firefox をインストールしてからアンインストールする」が効いたからといって、2つのブラウザが同じ profile を共有していると単純に理解してはいけない。より可能性が高いのは、その手順によってバージョンが一致する 158 パックが hellfire の profile に入ったということだ。具体的にどう入ったのかは調べられなかった。

Windows 上で今後同じことに遭遇したら、Firefox をインストールし直す必要はなく、直接:

1. `about:support` でバージョンを確認する。
2. 対応するバージョンのパックをダウンロードする: `https://ftp.mozilla.org/pub/firefox/releases/<版本>/win64/xpi/zh-CN.xpi`。正式版が出ていなければ beta のバージョン番号を使う。言語パック自体はクロスプラットフォームで、win64 と linux-x86_64 ディレクトリの内容は同じだ。
3. `about:addons` → 歯車 → ファイルからアドオンをインストール、この `.xpi` を選択する。
4. `about:preferences` で中国語を選択し、再起動する。

「ファイルからインストール」がブロックされる場合は、Linux でのやり方と同じく、手動で profile の `extensions\` にコピーする。

## 覚えておくこと

- 言語パックのバージョンはブラウザのバージョンと一致していなければならない。ブラウザのメジャーバージョンが更新されると、古いパックは無効になるので、再ダウンロードが必要だ。
- バージョンが完全には一致しない場合、インターフェースの一部が中国語、一部が英語になる。以前 Mercury で翻訳が不完全だったのも、おそらくこれが原因だ。新しいバージョンで追加された文字列が古いパックには含まれていない。
- beta パックを使う場合、一部の文字列が正式版と多少異なる可能性がある。正式版が公開されたら置き換える。
