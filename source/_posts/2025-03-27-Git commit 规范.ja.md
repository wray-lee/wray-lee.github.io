# Git commit 規約

- feat： 新規/修正機能（feature）。
- fix： バグ修正（bug fix）。
- docs： ドキュメント（documentation）。
- style： フォーマット（コードの動作に影響しない変更 white-space、formatting、missing semi colons、etc）。
- refactor： リファクタリング（新機能の追加でもバグ修正でもないコード変更）。
- perf： パフォーマンス改善（A code change that improves performance）。
- test： テスト追加（when adding missing tests）。
- chore： ビルドプロセスまたは補助ツールの変更（maintain）。
- revert： 以前の commit を打ち消す/元に戻す 例：revert： type（scope）： subject（元に戻すバージョン：xxxx）。
