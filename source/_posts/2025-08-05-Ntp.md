# Ntp

```bash
# /etc/systemd/timesyncd.conf
[Time]
NTP=time.windows.com pool.ntp.org 3.arch.pool.ntp.org 2.arch.pool.ntp.org 1.arch.pool.ntp.org 0.arch.pool.ntp.org   
FallbackNTP=pool.ntp.org time.windows.com 3.arch.pool.ntp.org 2.arch.pool.ntp.org 1.arch.pool.ntp.org 0.arch.pool.ntp.org 
```



```bash
timedatectl set-ntp true
systemctl restart systemd-timesyncd
hwclock --systohc
```
