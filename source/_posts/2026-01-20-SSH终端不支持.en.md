# SSH terminal not supported

`tput: unknown terminal "xterm-kitty"`

## Solution

`infocmp` Export the local configuration, pass it through a pipe to `ssh`, and then have `tic` on the remote server compile it and store it in `~/.terminfo` under the server user directory.



```bash
infocmp -a xterm-kitty | ssh user@remote_server tic -x -o \~/.terminfo /dev/stdin
```
