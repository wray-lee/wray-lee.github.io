`* * * * * sleep 70 && touch /etc/banner && reboot`

`touch /etc/banner` Clear login records, and at the same time touch to avoid the router not doing NTP in time causing time verification; set the router time to the time at reboot, `touch` file makes the time after reboot (before NTP) the last modification time of the file

## Interface Traffic Splitting

### MWAN3

Disable all hardware acceleration, firewall & wed

> Because of public network traversal, for IPv6 it is best not to use load balancing when not using NAT6

1. **Register Interfaces:** Register all interfaces you want to split traffic across

2. **Add Members:** Create MWAN interfaces, set metric (priority), weight (traffic ratio)
3. **Set Policies:** Bundle the required members (that need to be split together) into one policy. For public network allocation, a separate policy needs to be set here
4. **Set Rules:** Destination address `0.0.0.0/0`, i.e., split all external network IPs. For public network allocation, source address filtering needs to be set here.

Rules ultimately determine the effect. If you need to test, create a policy bound to a single interface and create a rule moved to the top



> Test interface: mwan3 use {interface} curl api.ipify.org

###  Manual Configuration

#### Preserve External Access

Create a routing table (if registering a name, it needs to be written to a file)

`echo "101 pppoe" >> /etc/iproute2/rt_tables`

`/etc/nftables.d/99-pppoe-mark.nft`

```bash
table inet fw4 {
    chain mangle_prerouting_custom {
        type filter hook prerouting priority mangle; policy accept;
        
        # 将来自 pppoe-wan 的所有新连接，在连接状态(connmark)上打上 0x300 标记
        iifname "pppoe-wan" ct state new ct mark set 0x300
        
        # 状态继承：将连接标记(connmark)强行赋予当前流经的数据包(fwmark)
        ct mark != 0x0 meta mark set ct mark
    }

    # 挂载点2：本机回程拦截 (OUTPUT)
    chain mangle_output_custom {
        type route hook output priority mangle; policy accept;
        
        # 本机发起的响应流量，同样继承该连接的标记
        ct mark != 0x0 meta mark set ct mark
    }
}
```

`/etc/hotplug.d/iface/99-pppoe-policy-route`

```bash
#!/bin/sh

# 1. 过滤非 pppoe-wan 上线事件
[ "$ACTION" = "ifup" ] || exit 0
[ "$INTERFACE" = "pppoe-wan" ] || exit 0

# 2. 清理旧的 fwmark 策略（彻底清空，防止堆积）
while ip rule del fwmark 0x300 table pppoe 2>/dev/null; do :; done
ip route flush table pppoe 2>/dev/null

# 3. 注入 fwmark 策略路由
# 逻辑：所有携带 0x300 标记的包，强制查表 pppoe，从 pppoe-wan 出站
ip rule add fwmark 0x300 table pppoe
ip route add default dev pppoe-wan table pppoe
```

#### Block IP

Directly binding an interface will cause other tunneling interfaces to malfunction

```bash
# /etc/config/network
config rule
    option src '10.17.1.200'
    option lookup 'main'
    option suppress_prefixlength '0'   # 核心：如果主表匹配到的是 0.0.0.0/0（外网），则判定无效并跳过
    option priority '10'

# 1. 对应你的命令：ip rule add from 10.17.1.199 table 20
config rule
    option src '10.17.1.200'
    option lookup '20'
    option priority '20'

# 2. 对应你的命令：ip route add default dev pppoe-wan table 20
config route
    option interface 'pppoe-wan'       # ⚠️注意：这里必须填你在 OpenWrt 里的【逻辑接口名】
    option target '0.0.0.0'
    option netmask '0.0.0.0'
    option table '20'
```

## ipv6 Multi-WAN Configuration

### v4

`* * * * * /root/failover.sh`

```bash
#!/bin/sh

# 1. 填入你的乐天 DS-Lite 接口名称
IFACE_RAK="dslite"

# 2. 测试连通性的目标 IP（Google DNS）
TEST_IP="8.8.8.8"

# 强制使用乐天接口发送 3 个探测包
ping -c 3 -W 2 -I $IFACE_RAK $TEST_IP >/dev/null 2>&1

if [ $? -eq 0 ]; then
    # 【乐天存活】：恢复/保持乐天的默认路由（跃点 10）
    # 如果路由已存在，命令会静默失败，对系统零消耗
    ip route add default dev $IFACE_RAK metric 10 2>/dev/null
else
    # 【乐天断网】：拔掉乐天的默认路由
    # 此时系统的底层路由表只剩下跃点为 20 的公寓网，流量瞬间切换
    ip route del default dev $IFACE_RAK metric 10 2>/dev/null
fi
```

### v6

`* * * * * /root/failover_v6.sh`

```bash
#!/bin/sh

# ================= 配置区 =================
IFACE_RAK="wan6"                 # 乐天光 IPv6 接口名（或者是 pppoe-wan / dslite，根据实际获取到240开头的接口填）
TEST_IP="2001:4860:4860::8888"   # Google 公共 DNS IPv6 节点
# ==========================================

# 1. 动态抓取乐天光当前的 IPv6 网关
GW=$(ip -6 route show default dev "$IFACE_RAK" | awk '/via/ {print $3; exit}')

# 如果连网关都拿不到，说明物理层彻底断开，直接切除路由，回落到公寓网
if [ -z "$GW" ]; then
    ip -6 route del default dev "$IFACE_RAK" 2>/dev/null
    exit 0
fi

# 2. 核心锚点：建立一条只属于探针的静态主机路由，防止删除默认路由后无法探测外网
ip -6 route add "$TEST_IP" via "$GW" dev "$IFACE_RAK" metric 1 2>/dev/null

# 3. 强制通过固定宿主路径向外发射 3 个探测包
ping6 -c 3 -W 2 "$TEST_IP" >/dev/null 2>&1

if [ $? -eq 0 ]; then
    # 【乐天光 IPv6 正常】：将其默认路由以高优先级（metric 10）强行注入（如果已存在则静默跳过）
    ip -6 route add default via "$GW" dev "$IFACE_RAK" metric 10 2>/dev/null
else
    # 【乐天光 IPv6 断流】：精准切除乐天光的默认路由
    # 此时主路由表只剩下公寓网的默认路由（metric 20），流量瞬间无缝转移
    ip -6 route del default via "$GW" dev "$IFACE_RAK" 2>/dev/null
fi
```





## Public Network Access

Configure inbound for the router's own services in traffic rules

Configure forwarding for services within the subnet in port forwarding



For subnet public IPv6 to be accessed externally, configure traffic rules

### Assign Public IPv6 to Subnet (only needed in /64 PD case)

> `/64` is the smallest physical broadcast domain (subnet), i.e., /64 should be treated as network nodes communicating directly (responding to NDP, same link on-link), so an NDP proxy is needed
>
> `/60 /56` and larger ranges can be routed by default and can be forwarded
>
> Forwarding state next-hop and endpoint state on-link

Enable DHCP server on wan6: enable the specified main interface, change RA, DHCP, and NDP all to relay

LAN v6 configuration: change RA, DHCP, and NDP all to relay

> If using only one public IPv6, enable IPv6 masquerading (NAT66) in advanced settings under firewall WAN
