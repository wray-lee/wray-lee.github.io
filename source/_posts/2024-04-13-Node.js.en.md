## path module

`dir = __dirname + '/tmp' ` On Windows the slashes in the returned directory path are not consistent

This can be solved by concatenating with resolve

```javascript
path = require('path')
path.resolve(__dirname, './tmp')
path.resolve(绝对路径， 相对路径)
```
