# Create test user, then delete

`grant all privileges on *.* to test@localhost identified by 'test' with grant option;`

`select User,Password from user;`

`*.*` means “all databases, all tables”. `with grant option` indicates that it has grant privileges. Using the grant statement to create privileges does not require manually refreshing the grant tables, because it has already been refreshed automatically.
