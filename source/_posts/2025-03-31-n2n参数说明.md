# n2n参数说明

```bash
# edge
-c <community>
-l <supernodeIP:port>
-a <edgeIP>
-k <key>
-d <interfaceName>
-r 允许数据包转发 
-S1 使用udp经supernode中转
-S2 使用tcp经supernode中转
-z1 lzo1x压缩数据包
-z2 zstd压缩数据包

# supernode
-p <port>
-c <community list file path>
-F <federation name>
```
