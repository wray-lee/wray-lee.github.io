## IP Address

Because MAC addresses have no hierarchical structure and are inconvenient for addressing, the IP protocol was developed.

`00000000	|	00000000	|	00000000	|	00000000`

### Three classes of IP addresses

> A, B, and C are the three classes of public network addresses.

#### Class A

Starts with: 0        First 8 bits of the network number (1.0.0.0~126.255.255.255)

#### Class B

Starts with: 10    First 16 bits of the network number (128.0.0.0~191.255.255.255)

#### Class C

Starts with: 110   First 24 bits of the network number (192.0.0.0~223.255.255.255)

#### Class D

Multicast

#### Class E

Reserved

### Network address

The network number is reserved, and the rest are all 0; it is the first allocated address (reserved).

### Subnet mask

The network number and subnet number are all 1, and the remaining host number is all 0.

IP count

`(BIN)2^n,可用ip (BIN)2^n-2					n=主机号位数`=

`(DEC)2^(32-cidr)	2^(32-cidr)-2										  n=cidr`

ANDing with the IP address yields the network address (host number all 0s)

eg:10.0.0.0

Broadcast address (host number all 1s) (the last address in the allocation, reserved)

eg:10.0.0.255

Every `2^8` increment in the IP carries one place, and the last IP address can be calculated.

For a given IP range, the network address is counted, so the final IP needs -1.
