# Waydroid

安装：

```\
waydroid init -s GAPPS -F
```



启动：

```bash
sudo systemctl enable waydroid-container.service --now
waydroid session start && waydroid show-full-ui
```



升级

```bash
waydroid upgrade
```



关闭:

```bash
waydroid session stop
```





键盘映射:

[keymapper](https://github.com/keymapperorg/KeyMapper)

## Arm转义

使用 casualsnek 的[脚本](https://github.com/casualsnek/waydroid_script)安装翻译层。

为提高翻译性能，推荐在 AMD CPU 上使用 `libndk`，在英特尔 CPU 上使用 `libhoudini`。然而部分应用仅支持一种翻译层，因此当某个游戏不工作或性能极差时，您可能需要把两个翻译层都试一遍。

*安装 libndk arm 翻译层*

```
python3 main.py install libndk 
```

*安装 libhoudini arm 翻译层*

```
python3 main.py install libhoudini
```
