# Crontab

```
*    *    *    *    *
-    -    -    -    -
|    |    |    |    |
|    |    |    |    +----- 星期中星期几 (0 - 6) (星期天 为0)
|    |    |    +---------- 月份 (1 - 12) 
|    |    +--------------- 一个月中的第几天 (1 - 31)
|    +-------------------- 小时 (0 - 23)
+------------------------- 分钟 (0 - 59)
```

- Here, f1 represents minutes, f2 represents hours, f3 represents the day of the month, f4 represents the month, and f5 represents the day of the week. program represents the program to be executed.
- When f1 is *, it means the program must be executed every minute; when f2 is *, it means the program must be executed every hour; and so on.
- When f1 is a-b, it means execution should occur from minute a to minute b; when f2 is a-b, it means execution should occur from hour a to hour b; and so on.
- When f1 is */n, it means execute once every n minutes; when f2 is */n, it means execute once every n hours; and so on.
- When f1 is a, b, c,..., it means execute at minute a, b, c,...; when f2 is a, b, c,..., it means execute at hour a, b, c...; and so on.

| Special symbol | Meaning |
| ----------- | ------------------------------------------------------------ |
| * (asterisk) | Represents any time. For example, the first "*" means execute once every minute within an hour. |
| , (comma) | Represents discontinuous times. For example, "0 8,12,16 * * * command" means execute the command once at 8:00, 12:00, and 16:00 every day. |
| - (hyphen) | Represents a continuous time range. For example, "0 5 * * 1-6 command" means execute the command at 5:00 AM from Monday to Saturday. |
| / (forward slash) | Represents how often to execute. For example, "*/10 * * * * command" means execute the command once every 10 minutes. |



---

When using `/` for each configuration, you need to set the leading position of each configuration to zero to avoid multiple repeated commands at the top of the hour.
