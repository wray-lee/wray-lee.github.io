# 系统优化

## non-root

### ColorOS

#### 查询

````bash
adb shell
# 查询包名
pm list packages # 列出全部包
am monitor # 开启监听，手机上打开app后返回包名（输入q enter退出，C-c会卡shell）

# 查询被禁用的包
pm list packages -d
# 查询包具体信息
dumpsys package {包名}

# pid
pidof com.example.myapp

# log
logcat -c && logcat > /sdcard/log.txt
logcat --pid=12345 # 指定pid
logcat *:E


````

> V: Verbose (最低级别)
> D: Debug
> I: Info
> W: Warning
> E: Error
> F: Fatal
> S: Silent (最高级别，会屏蔽所有日志)

#### 优化

```bash
adb shell
# 去除软件包安全检查
pm disable com.coloros.phonemanager 
# 禁用安全事件
pm disable com.coloros.securityguard 
# 禁用安全键盘
pm disable com.oplus.securitykeyboard
# 禁用搜狗输入法
pm disable com.sohu.inputmethod.sogouoem
# 禁用系统更新助手
pm disable com.oplus.sauhelper
# 语音助手
pm disable com.heytap.speechassist
# 家庭守护
pm disable com.coloros.digitalwellbeing
# 快应用
pm disable com.nearme.instant.platform
# 自带浏览器
pm disable com.heytap.browser
# 软件商店
pm disable com.heytap.market
# 杂志锁屏
pm disable com.haokan.pictorials
# oplus短信
pm disable com.android.mms
```
