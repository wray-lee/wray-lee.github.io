## Linux

### 实现开机自动挂载在WebDAV

普通挂载后，重启就会发现通过 WebDAV 挂载的磁盘没有了，也就意味着你每次重启 Linux 系统，都需要重新挂载，这时候需要更改几个设置来实现开机自动挂载。

**第一步、编辑davfs2.conf配置文件，将use_locks的1改为0**

```shell
vim /etc/davfs2/davfs2.conf 
```

![image-20211012153936525](https://cdn.lincloud.pro/blog/images/202110121401.jpg)

**第二步、修改secrets文件，添加账号信息**

```shell
vim /etc/davfs2/secrets
```

在底部添加账号信息，如

```shell
https://pan.cloud.com/dav user password
```

**第三步、添加开机挂载命令**

```shell
vim /etc/rc.local
```

----

##### arch

在写启动脚本之前，需要写一个service：

1. 首先切换用户到root，然后进入/etc/systemd/system目录

2. 创建一个.service文件，名称顺便取，本例中为**AutoExec.service**

3. 设置权限：

   ```
   chmod 644 AutoExec.service
   ```

4. 添加以下内容到AutoExec.service

```
[Unit]
Description=AutoExec
[Service]
ExecStart=/root/AutoExec.sh
[Install]
WantedBy=multi-user.target
```

1. 上面的ExecStart=/root/AutoExec.sh表明开机会执行/root/AutoExec.sh，那么命令写在这里面就行了，
   当然，文件是可以任意指定的，改为/etc/rc.local之类的都没问题。
2. 连接到multi-user.target.wants：
   ln -s AutoExec.service multi-user.target.wants/
   （注：这一步是为了让这个服务开机自启动，效果和systemctl enable AutoExec.service是等价的）
3. 创建/root/AutoExec.sh，向里面写入想要开机启动的命令，

并设置权限：

```
chmod 744 /root/AutoExec.sh
```



（文件路径和文件名可随便改，但一定要添加可执行权限）

以上就设置完了，**systemctl start AutoExec.service**，就能看到**AutoExec.sh**里的命令执行了，当然，每次开机也是自动执行的。

#### /etc/fstab

### Using fstab

To define how the webdav resource should be mounted into the filesystem, [append](https://wiki.archlinux.org/title/Append) a [fstab](https://wiki.archlinux.org/title/Fstab) entry under the following format:

```
/etc/fstab
https://webdav.example/path /mnt/webdav davfs rw,user,uid=username,noauto 0 0
```

where *username* is the owner of the mounted file system. It may be a numeric ID or a user name and only *root* can mount a uid different from the mounting user. `_netdev` mount option could be used to automount network drives.

---

末尾添加挂载命令，和挂在U盘一样

```shell
mount -t davfs https://pan.cloud.com/dav /cloud
```

重启即可自动挂载。

**最后一步、测试**

输入` df -h` 查看是否成功

## Windows

安装alist和winfsp，sshfs，rclone

### rclone容量大小显示

如果只是为了显示总大小的话，可以在 rClone 挂载时通过 `--vfs-disk-space-total-size` 手动设置总大小，并用 `--vfs-used-is-size` 让 rClone 主动计算已用空间大小，但是也只是方便显示而已，WebDAV 服务端不主动实现 rClone about 所需的 attribute, 那么挂载的时候无法得知已占用的空间或者总文件数之类的信息，如果想要配合 rClone 的 Union backend 还是没有办法按照剩余空间或者已占用空间选择 remote.

### 编写脚本

添加环境变量后编写vbs脚本以便于创建进程

```vbscript
' start_alist.vbs
Dim ws
Set ws = Wscript.CreateObject("Wscript.Shell")
ws.run "alist server",vbhide
```



```vbscript
' stop_alist.vbs
Dim ws
Set ws = Wscript.CreateObject("Wscript.Shell")
ws.run "taskkill /f /im alist.exe",0
Wscript.quit
```



``` vbscript
' mount.vbs
dim alist
set alist = Wscript.CreateObject("Wscript.Shell")
alist.run "rclone mount alist:/  G: --cache-dir D:\OneDriveTemp --vfs-cache-mode writes",vhide
```



```vbscript
' unmount.vbs
dim alist
set alist = Wscript.CreateObject("Wscript.Shell")
alist.run "taskkill /f /im rclone.exe",vhide
```
