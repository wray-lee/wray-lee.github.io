## File Descriptors

`0`	Standard input

`1`	Standard output, pointing to the screen

`2`	Standard error output (logs belong to it)

## Operators

```none
>`	输出重定向，右移，实际上是`1>` `将左边语句的输出覆盖写入到右边文件内，相当于`** | tee some_text.txt
>>`	输出追加重定向，右右移，将左边语句的输出添加到右边文件末尾，相当于`** | tee -a some_text.txt
```

`<`	Input redirection	`command < file`	Read from a file

`<<`	Input append redirection	`command << EOF`	Read subsequent input until `EOF`	(can be used to add an exit condition to a command)

```bash
cat << EOF > tmp
1
2
3
EOF

#则tmp中为
1
2
3
```

`|`	Pipe, uses the output of the left statement as the input of the right statement

`||`	OR OR, only if the left statement fails is the right statement executed

`&`	AND, regardless of whether the left statement fails, the right statement will be executed, and all statements joined by it will be executed.	When placed at the end, it makes the program execute in the background

`&&`	AND AND, if the left statement fails, the right statement will not be executed; if it succeeds, the right statement is executed

`!` 	Negation of a conditional expression

`>&`	File operation symbol,	eg:`2>&1`	, `2>1` will redirect error output to a file named 1, `&` is to define that the following `1` is a file descriptor

## Permissions

The Linux security system is SELinux (Security-Enhanced Linux), which can manage file permissions

### ls -lZht

```bash
-rw-r--r--.  1 user group unconfined_u:object_r:user_home_t:s0 4096 Sep 27 10:30 file.txt
```

`unconfined_u:object_r:user_home_t:s0` is the security context of files and directories. It contains information about the user, role, object class, and security level to which the file or directory belongs.

1. `unconfined_u`: Indicates the SELinux user to which the file or directory belongs. `unconfined_u` is a special user identifier, indicating an unrestricted user, that is, one not subject to strict SELinux policy restrictions.
2. `object_r`: Indicates the SELinux object role to which the file or directory belongs. The object role defines the set of roles in the SELinux policy that are allowed to operate on the object.
3. `user_home_t`: Indicates the SELinux object type of the file or directory. The object type defines the purpose of the file or directory and the permitted operations. `user_home_t` is a common object type used to represent a user's home directory.
4. `s0`: Indicates the SELinux security level of the file or directory. The security level is used to control access permissions to the object and is restricted according to access rules.

eg:

`systemd_unit_file_t` is an object type in SELinux, used to represent the security context of systemd unit files.

#### Changing SELinux file permissions with chcon

1. Change the security context of a file:

```bash
chcon unconfined_u:object_r:user_home_t:s0 file.txt
```
2. Recursively change the security context of a directory and all its subdirectories and files:

```bash
chcon -R unconfined_u:object_r:user_home_t:s0 directory/
```
3. Change the security context of a symbolic link:

```bash
chcon -h unconfined_u:object_r:user_home_t:s0 symlink
```
4. Set the target security context type:

```bash
chcon -t httpd_sys_content_t index.html
```

##### Difference from chown

`chown` is used to change basic file `所有者:组` permissions, which are permissions of the underlying file system

`chcon` changes file permissions on SELinux
