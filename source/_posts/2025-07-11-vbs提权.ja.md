# vbs権限昇格

```vb
If WScript.Arguments.Named.Exists("elevate") = False Then
  CreateObject("Shell.Application").ShellExecute "wscript.exe", """" & WScript.ScriptFullName & """ /elevate", "", "runas", 1
  WScript.Quit
End If

' 此时会更改路径，需要重新获取工作路径

Dim fso
Set fso = CreateObject("Scripting.FileSystemObject")

Dim scriptPath
scriptPath = fso.GetParentFolderName(WScript.ScriptFullName)

Dim clash
Set clash = Wscript.CreateObject("Wscript.Shell")
clash.CurrentDirectory = scriptPath


clash.run "clash.exe -d ./config", 0, False
Wscript.quit
```

## 構文

### 文字列

#### 宣言

VBの文字列は`"{content}"`、つまり二重引用符を使用して宣言する必要があります。通常の二重引用符を表現するには`"""`とし、外側の二重引用符で宣言し、内側の1つが実際の表現となります。

#### 連結

文字列は`&`を使用して連結します。

"hello world"を表現するには、次のようになります。

```vb
""hello world""

""hello" & " " & "world""
```
