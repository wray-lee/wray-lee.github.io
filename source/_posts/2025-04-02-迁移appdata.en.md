# Migrating appdata

**Right-click the `%userprofile%/appdata/roaming` folder and select the Location option to migrate**



**Perform mklink in Local AppData (`%userprofile%/appdata/Local`)**

First copy the folder to the target location, then

`new-Item -Path C:\Users\Wray\AppData\Local\Microsoft\Edge -ItemType SymbolicLink -Value E:\AppData\Local\Microsoft\Edge`



## (Use with caution) Change the registry path

Win R -> regedit



`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\Shell Folders`



`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders`



Change AppData and Local AppData



**And change the items related to `%userprofile%\AppData\Local` in `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Explorer\User Shell Folders`**
