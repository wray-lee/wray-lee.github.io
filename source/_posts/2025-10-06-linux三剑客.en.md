```bash
sed -e '1p'	# 打印第一行
```

### Merge Multiple Lines into One Line

```bash
sed ':a;N;$!ba;s/\n/ /g' file
# :a设定一个指令标签 标记当前位置，N读取下一行，$!判断如果不是最后一行 ，ba返回a标签，指令循环执行
# $!不是最后一行，$!=100不是第100行
```

### Delete Empty Lines

```bash
sed -e '/^$/d'
```

### Built-in Functions

- BEGIN pattern: means awk will immediately execute the action specified in BEGIN before reading any input lines. `BEGIN{}`
- END pattern: means awk will execute the action specified in END before it formally exits. `END{}`

#### awk String Built-in Functions

Note that in awk, **functions involving character indexes all start counting index positions from 1**, unlike other languages that start from 0.

##### Basic Functions

- `sprintf(format, expression1, ...)`: Returns the formatted string; see [sprintf](https://www.junmajinlong.com/shell/awk/awk_builtin_function1/index.html#sprintf)

    - `a=sprintf("%s\n","abc")`

- `length()`: Returns the number of characters in a string, the number of array elements, or the number of characters after a numeric value is converted to a string

    ```
    PLAINTEXT
    awk '
        BEGIN{
            print length(1.23)     # 4   # CONVFMT %.6g
    
            print 1.234567         # 1.23457
            print length(1.234567) # 7 
            print length(122341223432.1213241234)  # 11
        }'
    ```

- `strtonum(str)`: Converts a string to a decimal numeric value

    - If str starts with 0, it is recognized as octal
    - If str starts with 0x or 0X, it is recognized as hexadecimal

- `tolower(str)`: Converts to lowercase

- `toupper(str)`: Converts to uppercase

- `index(str,substr)`: Searches str for substr (substring), returns the found index position (index starts from 1), and returns 0 if not found

###### awk substr()

- `substr(string,start[,length])`: Extracts a substring from string

start is the starting index position of the extraction (index positions start from 1 rather than 0), and length indicates the length of the extracted substring. If length is omitted, it means extracting all remaining characters starting from start.

```
PLAINTEXT
awk '
    BEGIN{
        str="abcdefgh"
        print substr(str,3)   # cdefgh
        print substr(str,3,3) # cde
    }
'
```

If the value of start is less than 1, it is treated as 1; if start is greater than the length of the string, an empty string is returned.

If length is less than or equal to 0, an empty string is returned.

###### awk split() and patsplit()

- `split(string, array [, fieldsep [, seps ] ])`: Splits a string and saves the result into array, with array indexes stored starting from 1. Returns the number of elements obtained from the split.

Here fieldsep specifies the delimiter, which can be in the form of a regular expression. If this parameter is not specified, FS is used as the delimiter by default, and the default value of FS is a space.

seps is an array that saves the delimiter used for each split.

For example:

```
PLAINTEXT
split("abc-def-gho-pq",arr,"-",seps)
```

Its return value is 4. The resulting arrays a and seps are:

```
PLAINTEXT
arr[1] = "abc"
arr[2] = "def"
arr[3] = "gho"
arr[4] = "pq"

seps[1] = "-"
seps[2] = "-"
seps[3] = "-"
```

When split starts working, it first clears the array, so setting split's string parameter to empty can be used to clear the array.

```
PLAINTEXT
awk 'BEGIN{arr[1]=1;split("",arr);print length(arr)}'  # 0
```

If the delimiter cannot match the string, the entire string is saved as one array element in array.

```
PLAINTEXT
awk 'BEGIN{split("abcde",arr,"-");print arr[1]}' # abcde
```

- `patsplit(string, array [, fieldpat [, seps ] ])`: Uses the regular expression fieldpat to match the string string, and saves all successfully matched parts into array, with array indexes stored starting from 1. The return value is the number of elements in array, i.e. how many times the match succeeded.

If fieldpat is omitted, the value of the predefined variable FPAT is used by default.

```
PLAINTEXT
awk '
    BEGIN{
        patsplit("abcde",arr,"[a-z]")
        print arr[1]   # a
        print arr[2]   # b
        print arr[3]   # c
        print arr[4]   # d
        print arr[5]   # e
    }
'
```

###### awk match()

- `match(string,reg[,arr])`: Uses reg to match string, returns the index position of the successful match (counting from 1), and returns 0 if the match fails. If the arr parameter is specified, arr[0] stores the successfully matched string, and arr[1], arr[2], ... store the content captured by each group.

When match matches, it also sets two predefined variables: RSTART and RLENGTH

- When the match succeeds:
    - RSTART is assigned the index position of the successful match, counting from 1
    - RLENGTH is assigned the character length of the successful match
- When the match fails:
    - RSTART is assigned 0
    - RLENGTH is assigned -1

For example:

```
PLAINTEXT
awk '
    BEGIN{
        where = match("foooobazbarrrr","(fo+).*(bar*)",arr)
        print where   # 1
        print arr[0]  # foooobazbarrrr
        print arr[1]  # foooo
        print arr[2]  # barrrr
        print RSTART  # 1
        print RLENGTH # 14
    }
'
```

Because match() returns a non-zero value when the match succeeds and returns 0 when the match fails, it can be used directly as a condition:

```
PLAINTEXT
awk '
  {
    if(match($0,/A[a-z]+/,arr)){
      print NR " : " arr[0]
    }
  }
' a.txt
```

###### awk sub() and gsub()

- `sub(regexp, replacement [, target])`
- `gsub(regexp, replacement [, target])`: the global mode of sub()

sub() performs regular expression matching in the string target, and uses replacement to replace the first successfully matched part, saving the replacement back into target. It returns the number of successful replacements, i.e. 0 or 1.

target must be an assignable variable name, $N, or array element name so that it can be used to save the result after a successful replacement. It cannot be a string literal because it cannot save data.

If target is omitted, `$0` is used by default.

Note that if target is omitted, or target is `$N`, then after a successful replacement, OFS will be used to recalculate `$0`.

```
PLAINTEXT
awk '
    BEGIN{
        str="water water everywhere"
        #how_many = sub(/at/, "ith", str)
        how_many = gsub(/at/, "ith", str)
        print how_many   # 1
        print str        # wither water everywhere
    }
'
```

In the replacement parameter, a special symbol `&` can be used to refer to the successfully matched part. Note that sub() and gsub() cannot use backreferences `\N` in replacement.

```
PLAINTEXT
awk '
    BEGIN{
        str = "daabaaa"
        gsub(/a+/,"C&C",str)
        print str  # dCaaCbaaa
    }
'
```

If you want to use a literal `&` character in replacement, just escape it.

```
PLAINTEXT
sub(/a+/,"C\\&C",str)
```

> Two backslashes:
> Because when awk starts working with regular expressions, it first scans all awk code and then compiles it into awk's internal format. During scanning, backslash escapes are parsed, making `\\` become a single backslash. When it actually starts running, sub() parses again; only then does `\&` mean escaping &.
> The code scanning phase is called the lexical parsing phase, and the parsing phase during execution is called the runtime parsing phase.

###### awk gensub()

gensub(), supported by gawk, can completely replace sub() and gsub().

- `gensub(regexp, replacement, how [, target])`:

Can replace sub() and gsub().

how specifies which match to replace; for example, specifying 1 means replacing only the first match. In addition, it can also be specified as a string starting with `g` or `G`, indicating global replacement.

gensub() returns the result after replacement, while target remains unchanged; if the match fails, it returns target. This differs from sub() and gsub(), which return the number of successful replacements.

In the replacement part of gensub(), `\N` can be used to reference the result of group matching, whereas sub() and gsub() do not allow backreferences. Moreover, in the replacement part of gensub(), `&` or `\0` can also be used to represent the entire match result.

```
PLAINTEXT
awk 'BEGIN{
    a = "abc def"
    b = gensub(/(.+) (.*)/, "\\2 \\1, \\0 , &", "g", a)
    print b  # def abc, abc def , abc def
}'
```

###### awk asort() and asorti()

- `asort(src,[dest [,how]])`
- `asorti(src,[dest [,how]])`

asort sorts the values of the array src, then changes the indexes of the sorted values to the sequence 1, 2, 3, 4, .... It returns the number of elements in src, which can be treated as the maximum index after sorting.

asorti sorts the indexes of the array src, then changes the indexes of the sorted index values to the sequence 1, 2, 3, 4, .... It returns the number of elements in src, which can be treated as the maximum index after sorting.

```
PLAINTEXT
arr["last"] = "de"
arr["first"] = "sac"
arr["middle"] = "cul"
```

asort(arr) yields:

```
PLAINTEXT
arr[1] = "cul"
arr[2] = "de"
arr[3] = "sac"
```

asorti(arr) yields:

```
PLAINTEXT
arr[1] = "first"
arr[2] = "last"
arr[3] = "middle"
```

If dest is specified, the original array src is backed up to dest, then dest is sorted, while src remains unchanged.

The how parameter is used to specify the sorting method, and its value specification is the same as `PROCINFO["sorted_in"]`: it can be a predefined sorting function or a user-defined sorting function. See [Specify Array Traversal Order](https://www.junmajinlong.com/shell/awk/awk_builtin_function1/index.html#arrsort)。
