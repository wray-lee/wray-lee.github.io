# Waylandで中国語を入力できない

## Electron

```bash
#/usr/share/applications/typora.desktop
Exec=typora --ozone-platform-hint=auto --enable-wayland-ime --wayland-text-input-version=3 %U

#/usr/share/applications/code.desktop
Exec=/usr/bin/code --ozone-platform-hint=auto --enable-wayland-ime --wayland-text-input-version=3 %F
```



## Xwayland

```bash
env GTK_IM_MODULE=fcitx QT_IM_MODULE=fcitx XMODIFIERS=@im=fcitx /usr/bin/wechat

#/usr/share/applications/steam.desktop
Exec=env LANG=zh_CN.UTF-8 GTK_IM_MODULE=xim QT_IM_MODULE=xim XMODIFIERS=@im=fcitx /usr/bin/steam-runtime %U
```
