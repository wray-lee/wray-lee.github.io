## Operators

```

>>`	输出追加重定向，右右移，将左边语句的输出添加到右边文件末尾，相当于`** | tee -a some_text.txt
```

`<`	input redirection	`command < file`	read from a file

`<<`	input here-document redirection	`command << EOF`	read subsequent input until `EOF`	(can be used to add an exit condition to a command)

```shell

 2
 3
 EOF
 
 #则tmp中为

 3
```



`|`	pipe, uses the output of the left statement as the input of the right statement

`||`	OR OR, executes the right statement only if the left statement fails

`&`	AND, the right statement is executed regardless of whether the left statement fails; all statements joined by it will be executed.	When placed at the end, it makes the program run in the background

`&&`	AND AND, if the left statement fails, the right statement will not be executed; if it succeeds, the right statement is executed

`!` 	negation of a conditional expression



`>&`	file operation symbol,	e.g.: `2>&1`, `2>1` will redirect error output to a file named 1; `&` is used to define that the following `1` is a file descriptor

## Permissions

The Linux security system is SELinux (Security-Enhanced Linux), which can manage file permissions.

### `ls -lZht`

```bash
-rw-r--r--.  1 user group unconfined_u:object_r:user_home_t:s0 4096 Sep 27 10:30 file.txt
```

`unconfined_u:object_r:user_home_t:s0` is the security context of files and directories. It contains information about the user, role, object class, and security level to which the file or directory belongs.

1. `unconfined_u`: indicates the SELinux user to which the file or directory belongs. `unconfined_u` is a special user identifier, indicating an unrestricted user, i.e., one not subject to strict SELinux policy restrictions.
2. `object_r`: indicates the SELinux object role to which the file or directory belongs. The object role defines the set of roles in the SELinux policy that are allowed to operate on the object.
3. `user_home_t`: indicates the SELinux object type of the file or directory. The object type defines the purpose of the file or directory and the allowed operations. `user_home_t` is a common object type used to represent a user's home directory.
4. `s0`: indicates the SELinux security level of the file or directory. The security level is used to control access permissions to the object and restrict it according to access rules.

e.g.:

`systemd_unit_file_t` is an object type in SELinux, used to represent the security context of systemd unit files.



#### Change SELinux File Permissions `chcon`

1. Change the security context of a file:

    ```bash
    chcon unconfined_u:object_r:user_home_t:s0 file.txt
    ```

2. Recursively change the security context of a directory and all its subdirectories and files:

    ```bash
    chcon -R unconfined_u:object_r:user_home_t:s0 directory/
    ```

3. Change the security context of a symbolic link:

    ```bash
    chcon -h unconfined_u:object_r:user_home_t:s0 symlink
    ```

4. Set the target security context type:

    ```bash
    chcon -t httpd_sys_content_t index.html
    ```



##### Difference from chown

`chown` is used to change basic file `所有者:组` permissions; these are basic filesystem permissions.

`chcon` changes file permissions on SELinux.

### Regular Expressions

> During execution, only one character can be matched at a time (like a queue); matching/searching proceeds in order and cannot skip.

#### Operator Precedence (decreasing from top to bottom)

> Escape is highest, parentheses second, qualifiers (operators) third, position symbols fourth, and OR is lowest.

```bash
\ 				转义符
() []			括号
* + {x,y}		限定符
^ $ \字符       定位点
|				或
```



`&` means no content and is not processed (actually & is the pattern space, i.e., the currently processed line/matched line, i.e., the content itself)

```bash
^								# 标记内容开头，必须放在匹配内容首
$								# 标记内容结尾，必须放在匹配内容尾

# 限制符  只作用于前面的相邻的一个内容
.*	{0,}						# 匹配所有内容 0次或多次	（用于匹配所有内容）
.+ .{1,}						# 匹配所有内容 1次或多次
.? .{0,1}						# 匹配所有内容 0次或1次
.{0,3}  						# 匹配所有内容 0到3次
##

?								# 放在限制符后匹配模式为非贪婪(决定于限制符)
# eg:对于"oooo" 
# o+	匹配所有o	oooo
# o+?	匹配一个o	o

(?)								# 用作条件判断
(?=)							# 正向肯定预查
(?:)							# 正向或预查    不进行存储，使用后即销毁
(?!)							# 正向否定预查

(?<=)							# 反向肯定预查
(?<:)							# 反向或预查
(?<!)							# 反向否定预查
{
	[windows(?=xp|10|11)]	# 匹配windowsxp windows10 windows11
	[(?<=xp|10|11)windows]	# 匹配xpwindows 10windows 11windows
# 根据与字符绑定情况的位置不同
}



[0-9] 							# 表示所有数字
[a-z]							# 表示所有小写字母
[A-Za-z]						# 表示所有英文字母
\p{L}							# 匹配任何字母（使用unicode字母字符类）
[[:alpha:]] 任意字母
[[:upper:]] 任意大写字母
[[:lower:]] 任意小写字母

[[:digit:]] 任意数字
[[:xdigit:]] 任意16进制数字

[[:alnum:]]	任意字母和数字

[[:punct:]] 任意标点符号
[[:space:]] 任意空格



[x|y]							# 匹配x或y
[xx|xy] [x(?:x|y)]				# 匹配xx或xy
[x]								# 匹配x
[^x] 							# 匹配不包含x的
```
