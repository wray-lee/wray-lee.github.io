# Markdown syntax

## Heading syntax

` # 一级标题`

`## 二级标题`

`### 三级标题`

and so on

## Emphasis syntax

` ~~内容~~`strikethrough

`*内容*`italic

`**内容**`bold

`***内容***`bold italic

## List syntax

### Ordered list

```markdown
1. 内容
2. 会自动生成（记得空格）
```

### Unordered list

```markdown
- 内容
+ 内容
* 内容
```

All can generate an unordered list

## Markdown can embed HTML

```html
<p></p>
<font color=></font>
<u></u>
<tr></tr>
<td></td>
..............
```

## Horizontal rule

```markdown
---				减号
\*\*\*			星号
\_\_\_			下划线
```

All work

## Code syntax

````markdown
`your_codes`


```select_language
your codes
```
````



## Annotations

### Superscript

`[^标注内容]`

Hello[^1]

`html内嵌`

<sup>1</sup>

### Subscript

`~标注内容~`

Hello~1~

## Line styles

### Strikethrough

`~~内容~~`

### Underline

`html内嵌语法：<u>内容</u>`
