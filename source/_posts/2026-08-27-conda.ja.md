## RuntimeError

OpenSSL 3.0's legacy provider failed to load

```bash
export CRYPTOGRAPHY_OPENSSL_NO_LEGACY=1  #add to the environment config
conda install cryptography
```

## AttributeError: module 'cryptography.hazmat.backends' has no attribute 'openssl'

```bash
cd /opt/miniconda3/bin
./pip uninstall cryptography pyOpenSSL
./pip install cryptography pyOpenSSL
```
