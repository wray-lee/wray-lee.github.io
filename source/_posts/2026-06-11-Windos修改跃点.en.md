# Windows Modify Metric

## IPv4&6 Properties

Modify the network adapter metric. If a static address is configured, you may also need to change the route metric; otherwise, at the routing layer, the priority may still not take effect due to the metric.

## Registry

Same as DHCP; after DHCP is modified, the registry is automatically modified.

`HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces\{网卡GUID}`

`DWORD(32bit): InterfaceMetric = 50`

## command

```pwsh
route add 0.0.0.0 mask 0.0.0.0 <网关地址> metric 50 if <无线网卡接口号> -p
```
