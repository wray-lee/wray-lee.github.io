# Curl詳解

## `curl -kfsSL`

- `-k/--insecure` 証明書なしでSSLサイトにアクセスすることを許可する
- `-f/--fail`    接続失敗時にHTTPエラーを表示しない。サーバーエラー時に、エラー原因を示すHTMLページが返されるのを阻止し、代わりにcurlコマンドがエラーコード22を返してエラーを通知する（HTMLが返るとデバッグしにくいのを避ける）
- `-s/--silent`    サイレントモード。何も出力しない。エラーと進捗情報を出力しない。
- `-S/--show-error`    エラーを表示する。エラー情報のみを出力するよう指定し、通常は`-s`と一緒に使用する。
- `-L/--location`    HTTPリクエストにサーバーのリダイレクトを追従させる。curlはデフォルトではリダイレクトを追従しない。

curl -fsSL は、curlコマンドでファイルをダウンロードする際に、進捗とエラー情報を表示せず、ダウンロードに失敗した場合は直ちに停止し、自動的にリダイレクトを追従することを示す。これは通常、ファイルをダウンロードする際の静かで安全かつ安定した方法である。

## 区別

- `-l/--list-only`    ftpディレクトリ下のファイル名を一覧表示する
- `-F `   パラメータはサーバーにバイナリファイルをアップロードするために使用する。

## その他のコマンド

`-o`		パラメータはサーバーの応答をファイルとして保存する。`wget`コマンドと同じ。

`curl -o example.html https://www.example.com`



`-O`		パラメータはサーバーの応答をファイルとして保存し、URLの最後の部分をファイル名として扱う。(名前を付ける必要なし)

`curl -O https://www.example.com/foo/bar.html`



`--limit-rate`はHTTPリクエストとレスポンスの帯域幅を制限し、遅いネットワーク環境をシミュレートするために使用する。

`curl --limit-rate 200k https://google.com`

# curl の使い方ガイド

作者： [阮一峰](https://www.ruanyifeng.com/)

日付： [2019年9月5日](https://www.ruanyifeng.com/blog/2019/09/)

## はじめに

curl はよく使われるコマンドラインツールで、Webサーバーにリクエストを送るために使用する。その名前はクライアント（client）の URL ツールという意味である。

その機能は非常に強力で、コマンドライン引数は数十種類に及ぶ。習熟すれば、Postman のようなGUIツールを完全に置き換えることができる。

![img](https://www.wangbase.com/blogimg/asset/201909/bg2019090501.jpg)

本文では、日常的な参照や確認に便利なように、その主なコマンドライン引数を紹介する。内容は主に[《curl cookbook》](https://catonmat.net/cookbooks/curl)。为了节约篇幅，下面的例子不包括运行时的输出，初学者可以先看我以前写的[《curl 初心者チュートリアル》](https://www.ruanyifeng.com/blog/2011/09/curl.html)。 から翻訳している。

パラメータを何も指定しない場合、curl は GET リクエストを送信する。

> 
>
> ```bash
> $ curl https://www.example.com
> ```

上記のコマンドは`www.example.com`に GET リクエストを送信し、サーバーが返した内容がコマンドラインに出力される。

## **-A**

`-A`パラメータはクライアントのユーザーエージェントヘッダー、すなわち`User-Agent`を指定する。curl のデフォルトのユーザーエージェント文字列は`curl/[version]`である。

> ```bash
> $ curl -A 'Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/76.0.3809.100 Safari/537.36' https://google.com
> ```

上記のコマンドは`User-Agent`を Chrome ブラウザに変更する。

> ```bash
> $ curl -A '' https://google.com
> ```

上記のコマンドは`User-Agent`ヘッダーを削除する。

`-H`パラメータで直接ヘッダーを指定し、`User-Agent`を変更することもできる。

> ```bash
> $ curl -H 'User-Agent: php/1.0' https://google.com
> ```

## **-b**

`-b`パラメータはサーバーに Cookie を送信するために使用する。

> ```bash
> $ curl -b 'foo=bar' https://google.com
> ```

上記のコマンドはヘッダー`Cookie: foo=bar`を生成し、`foo`という名前で値が`bar`の Cookie をサーバーに送信する。

> ```bash
> $ curl -b 'foo1=bar;foo2=bar2' https://google.com
> ```

上記のコマンドは 2 つの Cookie を送信する。

> ```bash
> $ curl -b cookies.txt https://www.google.com
> ```

上記のコマンドはローカルファイル`cookies.txt`を読み取り、その中にあるサーバーが設定した Cookie（`-c`パラメータを参照）をサーバーに送信する。

## **-c**

`-c`パラメータはサーバーが設定した Cookie をファイルに書き込む。

> ```bash
> $ curl -c cookies.txt https://www.google.com
> ```

上記のコマンドはサーバーの HTTP レスポンスによって設定された Cookie をテキストファイル`cookies.txt`に書き込む。

## **-d**

`-d`パラメータは POST リクエストのデータ本体を送信するために使用する。

> ```bash
> $ curl -d'login=emma＆password=123'-X POST https://google.com/login
> # 或者
> $ curl -d 'login=emma' -d 'password=123' -X POST  https://google.com/login
> ```

`-d`パラメータを使用すると、HTTP リクエストに自動的にヘッダー`Content-Type : application/x-www-form-urlencoded`が追加される。また、リクエストは自動的に POST メソッドに変換されるため、`-X POST`を省略できる。

`-d`パラメータはローカルのテキストファイルのデータを読み取り、サーバーに送信できる。

> ```bash
> $ curl -d '@data.txt' https://google.com/login
> ```

上記のコマンドは`data.txt`ファイルの内容を読み取り、データ本体としてサーバーに送信する。

## **--data-urlencode**

`--data-urlencode`パラメータは`-d`と同等で、POST リクエストのデータ本体を送信するが、送信するデータを自動的に URL エンコードする点が異なる。

> ```bash
> $ curl --data-urlencode 'comment=hello world' https://google.com/login
> ```

上記のコードでは、送信するデータ`hello world`の間にスペースがあり、URL エンコードが必要である。

## **-e**

`-e`パラメータは HTTP のヘッダー`Referer`を設定するために使用し、リクエストの参照元を表す。

> ```bash
> curl -e 'https://google.com?q=example' https://www.example.com
> ```

上記のコマンドは`Referer`ヘッダーを`https://google.com?q=example`に設定する。

`-H`パラメータは、ヘッダー`Referer`を直接追加することで同じ効果を得られる。

> ```bash
> curl -H 'Referer: https://google.com?q=example' https://www.example.com
> ```

## **-F**

`-F`パラメータはサーバーにバイナリファイルをアップロードするために使用する。

> ```bash
> $ curl -F 'file=@photo.png' https://google.com/profile
> ```

上記のコマンドは HTTP リクエストにヘッダー`Content-Type: multipart/form-data`を追加し、ファイル`photo.png`を`file`フィールドとしてアップロードする。

`-F`パラメータで MIME タイプを指定できる。

> ```bash
> $ curl -F 'file=@photo.png;type=image/png' https://google.com/profile
> ```

上記のコマンドは MIME タイプを`image/png`に指定する。そうでなければ curl は MIME タイプを`application/octet-stream`に設定する。

`-F`パラメータでもファイル名を指定できる。

> ```bash
> $ curl -F 'file=@photo.png;filename=me.png' https://google.com/profile
> ```

上記のコマンドでは、元のファイル名は`photo.png`であるが、サーバーが受け取るファイル名は`me.png`である。

## **-G**

`-G`パラメータは URL のクエリ文字列を構築するために使用する。

> ```bash
> $ curl -G -d 'q=kitties' -d 'count=20' https://google.com/search
> ```

上記のコマンドは GET リクエストを送信し、実際にリクエストされる URL は`https://google.com/search?q=kitties&count=20`である。`--G`を省略すると、POST リクエストを送信する。

データを URL エンコードする必要がある場合は、`--data--urlencode`パラメータと組み合わせることができる。

> ```bash
> $ curl -G --data-urlencode 'comment=hello world' https://www.example.com
> ```

## **-H**

`-H`パラメータは HTTP リクエストのヘッダーを追加する。

> ```bash
> $ curl -H 'Accept-Language: en-US' https://google.com
> ```

上記のコマンドは HTTP ヘッダー`Accept-Language: en-US`を追加する。

> ```bash
> $ curl -H 'Accept-Language: en-US' -H 'Secret-Message: xyzzy' https://google.com
> ```

上記のコマンドは 2 つの HTTP ヘッダーを追加する。

> ```bash
> $ curl -d '{"login": "emma", "pass": "123"}' -H 'Content-Type: application/json' https://google.com/login
> ```

上記のコマンドは HTTP リクエストのヘッダーとして`Content-Type: application/json`を追加し、次に`-d`パラメータで JSON データを送信する。

## **-i**

`-i`パラメータはサーバーが応答した HTTP ヘッダーを出力する。

> ```bash
> $ curl -i https://www.example.com
> ```

上記のコマンドはサーバーの応答を受け取った後、まずサーバーが応答したヘッダーを出力し、次に 1 行空けて、その後に Web ページのソースコードを出力する。

## **-I**

`-I`パラメータはサーバーに HEAD リクエストを送信し、その後サーバーが返す HTTP ヘッダーを出力する。

> ```bash
> $ curl -I https://www.example.com
> ```

上記のコマンドは HEAD リクエストに対するサーバーの応答を出力する。

`--head`パラメータは`-I`と同等である。

> ```bash
> $ curl --head https://www.example.com
> ```

## **-k**

`-k`パラメータは SSL 検査をスキップするよう指定する。

> ```bash
> $ curl -k https://www.example.com
> ```

上記のコマンドはサーバーの SSL 証明書が正しいかどうかを検査しない。

## **-L**

`-L`パラメータは HTTP リクエストにサーバーのリダイレクトを追従させる。curl はデフォルトではリダイレクトを追従しない。

> ```bash
> $ curl -L -d 'tweet=hi' https://api.twitter.com/tweet
> ```

## **--limit-rate**

`--limit-rate`は HTTP リクエストとレスポンスの帯域幅を制限し、遅いネットワーク環境をシミュレートするために使用する。

> ```bash
> $ curl --limit-rate 200k https://google.com
> ```

上記のコマンドは帯域幅を毎秒 200K バイトに制限する。

## **-o**

`-o`パラメータはサーバーの応答をファイルとして保存する。`wget`コマンドと同じである。

> ```bash
> $ curl -o example.html https://www.example.com
> ```

上記のコマンドは`www.example.com`を`example.html`として保存する。

## **-O**

`-O`パラメータはサーバーの応答をファイルとして保存し、URL の最後の部分をファイル名として扱う。

> ```bash
> $ curl -O https://www.example.com/foo/bar.html
> ```

上記のコマンドはサーバーの応答をファイルとして保存し、ファイル名は`bar.html`である。

## **-s**

`-s`パラメータはエラーと進捗情報を出力しない。

> ```bash
> $ curl -s https://www.example.com
> ```

上記のコマンドはエラーが発生してもエラーメッセージを表示しない。エラーが発生しなければ、実行結果を通常どおり表示する。

curl に何も出力させたくない場合は、次のコマンドを使用できる。

> ```bash
> $ curl -s -o /dev/null https://google.com
> ```

## **-S**

`-S`パラメータはエラー情報のみを出力するよう指定し、通常は`-s`と一緒に使用する。

> ```bash
> $ curl -s -o /dev/null https://google.com
> ```

上記のコマンドはエラーが発生しない限り、何も出力しない。

## **-u**

`-u`パラメータはサーバー認証のユーザー名とパスワードを設定するために使用する。

> ```bash
> $ curl -u 'bob:12345' https://google.com/login
> ```

上記のコマンドはユーザー名を`bob`、パスワードを`12345`に設定し、それを HTTP ヘッダー`Authorization: Basic Ym9iOjEyMzQ1`に変換する。

curl は URL 内のユーザー名とパスワードを認識できる。

> ```bash
> $ curl https://bob:12345@google.com/login
> ```

上記のコマンドは URL 内のユーザー名とパスワードを認識し、それを前の例の HTTP ヘッダーに変換する。

> ```bash
> $ curl -u 'bob' https://google.com/login
> ```

上記のコマンドはユーザー名のみを設定しており、実行後、curl はユーザーにパスワード入力を促す。

## **-v**

`-v`パラメータは通信の全過程を出力し、デバッグに使用する。

> ```bash
> $ curl -v https://www.example.com
> ```

`--trace`パラメータもデバッグに使用でき、生のバイナリデータも出力する。

> ```bash
> $ curl --trace - https://www.example.com
> ```

## **-x**

`-x`パラメータは HTTP リクエストのプロキシを指定する。

> ```bash
> $ curl -x socks5://james:cats@myproxy.com:8080 https://www.example.com
> ```

上記のコマンドは HTTP リクエストを`myproxy.com:8080`の socks5 プロキシ経由で送信するよう指定する。

プロキシプロトコルを指定しない場合、デフォルトは HTTP である。

> ```bash
> $ curl -x james:cats@myproxy.com:8080 https://www.example.com
> ```

上記のコマンドでは、リクエストのプロキシは HTTP プロトコルを使用する。

## **-X**

`-X`パラメータは HTTP リクエストのメソッドを指定する。

> ```bash
> $ curl -X POST https://www.example.com
> ```

上記のコマンドは`https://www.example.com`に POST リクエストを送信する。
