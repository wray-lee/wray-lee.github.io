# Windowsの言語変更

```powershell
Set-WinSystemLocale -SystemLocale zh-CN
Set-WinUserLanguageList -LanguageList zh-CN -Force
Set-SystemPreferredUILanguage zh-CN
```





```
HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Nls\Language


Default 和 InstallLanguage。
0409（代表英文）修改为 0804（代表中文简体）

```

`lpksetup` 新しい言語をインストール



```powershell
#Install-Language zh-CN
DISM /Online /Add-Capability /CapabilityName:Language.Basic~~~zh-CN~0.0.1.0
```





Microsoft Storeで簡体字中国語の言語を更新



電卓をアンインストールして再インストール
