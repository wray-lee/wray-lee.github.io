# Synology 自前コンパイルモジュール

カーネルソースとコンパイルツールをダウンロード

```bash
wget https://global.synologydownload.com/download/ToolChain/Synology%20NAS%20GPL%20Source/7.2-72806/epyc7002/linux-5.10.x.txz
wget https://global.synologydownload.com/download/ToolChain/toolchain/7.2-72806/AMD%20x86%20Linux%20Linux%205.10.55%20%28epyc7002%29/epyc7002-gcc1220_glibc236_x86_64-GPL.txz

tar xJvf
```

コンパイルするモジュールを選択

```bash
cd linux-5.10.x
make mrproper
make clean
make menuconfig

# 关闭CONFIG_MODVERSIONS
# 打开amdgpu radeon 相关（包括 AMD IOMMU）
# FW_LOADER
# DRM_KMS_HELPER
# DRM_SCHED
# DRM_TTM
# POWER_SUPPLY
# HWMON
# BACKLIGHT_CLASS_DEVICE
# INTERVAL_TREE
```


Synology へのインストール

```bash
cp *.ko /lib/modules
sudo depmod -a
sudo modprobe drm_kms_helper
sudo modprobe gpu-sched
sudo modprobe ttm
sudo modprobe drm
sudo modprobe amdgpu
sudo modprobe radeon
```
