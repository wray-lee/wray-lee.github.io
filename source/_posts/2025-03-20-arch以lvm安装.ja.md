# Arch インストール

> `rfkilll unblock wifi`

`rfkilll unblock all`

cfdisk パーティション分割

```bash
1G /efi
剩余 /
4G /swap
```



論理ボリュームの作成

実際の手順は次のとおり

1. デバイス`pvcreate /dev/sda2`を登録、sda2 パーティションタイプを Linux LVM に設定
2. ボリュームグループ（ハードディスクプール）の作成
3. ボリューム（実際のパーティション）の作成

```bash
lvmdiskscan
pvcreate /dev/sda2
pvcreate /dev/sdb
vgcreate vgroup /dev/sda2 /dev/sdb
#lvcreate -L [大小] [卷组名] -n [卷名]

mkfs.btrfs /dev/mapper/vgroup-lv
mkfs.fat -F32 /dev/efi_system_partition
```



インストール

```bash
mount /dev/mapper/vgroup-lv /mnt
mount /dev/sda1 /mnt/boot
pacman -Syu archlinux-keyring
pacstrap -K /mnt base linux linux-firmware vim amd-ucode git iwd #必须先挂载/boot再安装，否则无法生成引导
genfstab -U /mnt > /mnt/etc/fstab
arch-chroot /mnt
ln -sf /usr/share/zoneinfo/Region（地区名）/City（城市名） /etc/localtime
hwclock --systohc
passwd
```

LVM 設定

```bash
pacman -S lvm2
#/etc/mkinitcpio.conf
Hook=(...lvm2)

---

mkinitcpio -P
```

>   後からハードディスクを追加
>
>   ```bash
>   fdisk -l -> /dev/sdx
>   pvcreate /dev/sdx
>   pvdisplay
>   vgdisplay -> {vgroupName}
>   # ${vgroupName}=wray-debian-vg
>   vgextend wray-debian-vg /dev/sdx
>   lvresize -l +100%FREE wray-debian-vg/root
>   resize2fs /dev/wray-debian-vg/root
>   ```

GRUB ブート

```bash
grub-install --target=x86_64-efi --efi-directory=/boot --bootloader-id='Arch Linux' --modules="tpm" --disable-shim-lock
#兼容性(如果重启无启动项)
#grub-install --target=x86_64-efi --efi-directory=/boot/grub --bootloader-id=GRUB --modules="tpm" --disable-shim-lock --removable
grub-mkconfig -o /boot/grub/grub.cfg
```
