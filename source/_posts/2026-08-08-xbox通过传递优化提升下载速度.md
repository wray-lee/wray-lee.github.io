```reg
Windows Registry Editor Version 5.00

[HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\Windows\DeliveryOptimization]
"DODownloadMode"=dword:00000003
"DOPercentageMaxForegroundBandwidth"=dword:00000000
"DOPercentageMaxBackgroundBandwidth"=dword:00000000
"DOAbsoluteMaxCacheSize"=dword:00000064
"DOMinFileSizeToCache"=dword:00000001
```



```bash
net stop DoSvc
net start DoSvc
```
