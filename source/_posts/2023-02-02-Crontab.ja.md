# Crontab

```
*    *    *    *    *
-    -    -    -    -
|    |    |    |    |
|    |    |    |    +----- 星期中星期几 (0 - 6) (星期天 为0)
|    |    |    +---------- 月份 (1 - 12) 
|    |    +--------------- 一个月中的第几天 (1 - 31)
|    +-------------------- 小时 (0 - 23)
+------------------------- 分钟 (0 - 59)
```

- ここで f1 は分、f2 は時、f3 は 1 か月のうちの日、f4 は月、f5 は曜日を表します。program は実行するプログラムを表します。
- f1 が * のときは毎分 program を実行することを表し、f2 が * のときは毎時 program を実行することを表し、以下同様です。
- f1 が a-b のときは第 a 分から第 b 分までの期間に実行することを表し、f2 が a-b のときは第 a 時から第 b 時まで実行することを表し、以下同様です。
- f1 が */n のときは n 分ごとに 1 回実行することを表し、f2 が */n のときは n 時間ごとに 1 回実行することを表し、以下同様です。
- f1 が a, b, c,... のときは第 a, b, c,... 分に実行することを表し、f2 が a, b, c,... のときは第 a, b, c... 時に実行することを表し、以下同様です。

| 特殊記号    | 意味                                                         |
| ----------- | ------------------------------------------------------------ |
| *（アスタリスク）   | 任意の時間を表します。たとえば最初の「*」は、1 時間のうち毎分 1 回実行するという意味を表します。 |
| ,（カンマ）   | 不連続な時間を表します。たとえば「0 8，12，16***コマンド」は、毎日の 8 時 0 分、12 時 0 分、16 時 0 分にコマンドを 1 回実行することを表します。 |
| -（ハイフン）   | 連続した時間範囲を表します。たとえば「0 5 ** 1-6コマンド」は、月曜日から土曜日の午前 5 時 0 分にコマンドを実行することを表します。 |
| /（スラッシュ） | どのくらいの間隔で実行するかを表します。たとえば「*/10****コマンド」は、10 分ごとにコマンドを 1 回実行することを表します。 |



---

`/` を使用して各設定を行う場合は、正時にコマンドが何度も重複するのを避けるため、各設定の先頭位置をゼロにする必要があります。
