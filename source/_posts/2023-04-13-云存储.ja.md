## Linux

### WebDAV での起動時自動マウントを実現する

通常のマウント後、再起動すると WebDAV 経由でマウントしたディスクが消えていることに気づきます。つまり Linux システムを再起動するたびに再マウントが必要になります。このとき、いくつかの設定を変更して起動時の自動マウントを実現する必要があります。

**ステップ1、davfs2.conf 設定ファイルを編集し、use_locks の 1 を 0 に変更する**

```shell
vim /etc/davfs2/davfs2.conf 
```

![image-20211012153936525](https://cdn.lincloud.pro/blog/images/202110121401.jpg)

**ステップ2、secrets ファイルを変更し、アカウント情報を追加する**

```shell
vim /etc/davfs2/secrets
```

下部にアカウント情報を追加します。例：

```shell
https://pan.cloud.com/dav user password
```

**ステップ3、起動時マウントコマンドを追加する**

```shell
vim /etc/rc.local
```

----

##### arch

起動スクリプトを書く前に、service を作成する必要があります：

1. まずユーザーを root に切り替え、次に /etc/systemd/system ディレクトリへ移動します

2. .service ファイルを作成します。名前は任意です。この例では **AutoExec.service** とします

3. 権限を設定します：

   ```
   chmod 644 AutoExec.service
   ```

4. 以下を AutoExec.service に追加します

```
[Unit]
Description=AutoExec
[Service]
ExecStart=/root/AutoExec.sh
[Install]
WantedBy=multi-user.target
```

1. 上記の ExecStart=/root/AutoExec.sh は、起動時に /root/AutoExec.sh を実行することを示します。したがって、コマンドはこの中に書けばよいです。
   もちろん、ファイルは任意に指定でき、/etc/rc.local などに変更しても問題ありません。

2. multi-user.target.wants にリンクします：
   ln -s AutoExec.service multi-user.target.wants/
   （注：この手順は、このサービスを起動時に自動起動させるためのもので、効果は systemctl enable AutoExec.service と同等です）

3. /root/AutoExec.sh を作成し、その中に起動時に実行したいコマンドを書きます。

そして権限を設定します：

```
chmod 744 /root/AutoExec.sh
```



（ファイルパスとファイル名は自由に変更できますが、必ず実行権限を追加してください）

以上で設定は完了です。**systemctl start AutoExec.service** とすると、**AutoExec.sh** 内のコマンドが実行されるのが確認できます。もちろん、毎回の起動時にも自動実行されます。

#### /etc/fstab

### Using fstab

To define how the webdav resource should be mounted into the filesystem, [append](https://wiki.archlinux.org/title/Append) a [fstab](https://wiki.archlinux.org/title/Fstab) entry under the following format:

```
/etc/fstab
https://webdav.example/path /mnt/webdav davfs rw,user,uid=username,noauto 0 0
```

where *username* is the owner of the mounted file system. It may be a numeric ID or a user name and only *root* can mount a uid different from the mounting user. `_netdev` mount option could be used to automount network drives.

---

末尾にマウントコマンドを追加します。USB メモリをマウントするのと同じです

```shell
mount -t davfs https://pan.cloud.com/dav /cloud
```

再起動すれば自動マウントされます。

` df -h` を入力して、成功したか確認します

## Windows

alist と winfsp、sshfs、rclone をインストールします

### rclone の容量サイズ表示

もし総サイズを表示するためだけであれば、rClone のマウント時に `--vfs-disk-space-total-size` で総サイズを手動設定し、`--vfs-used-is-size` で rClone に使用済み領域サイズを能動的に計算させることができます。しかし、これは表示を便利にするだけです。WebDAV サーバー側が rClone の about に必要な attribute を能動的に実装しない場合、マウント時に使用済み容量や総ファイル数などの情報を知ることはできません。rClone の Union backend と連携させたい場合でも、残り容量や使用済み容量に基づいて remote を選択する方法はありません。

### スクリプトの作成

環境変数を追加した後、プロセスを作成するために vbs スクリプトを作成します

```vbscript
' start_alist.vbs
Dim ws
Set ws = Wscript.CreateObject("Wscript.Shell")
ws.run "alist server",vbhide
```



```vbscript
' stop_alist.vbs
Dim ws
Set ws = Wscript.CreateObject("Wscript.Shell")
ws.run "taskkill /f /im alist.exe",0
Wscript.quit
```



``` vbscript
' mount.vbs
dim alist
set alist = Wscript.CreateObject("Wscript.Shell")
alist.run "rclone mount alist:/  G: --cache-dir D:\OneDriveTemp --vfs-cache-mode writes",vhide
```



```vbscript
' unmount.vbs
dim alist
set alist = Wscript.CreateObject("Wscript.Shell")
alist.run "taskkill /f /im rclone.exe",vhide
```
