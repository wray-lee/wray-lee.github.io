# Batsh基本文法

## コメント

1. 1行コメント `rem blabla`
`@REM blabla`
`:: blabla`
2. 行末または1行コメント	`%blabla%`

 コマンドの後に > nul を追加すると、命令の実行内容を表示しないようにできます

# 文法

### ヘッダー

通常、先頭に`@echo off`を入力します

echoはエコー命令で、coutに相当しますが、自身も表示します
@echo offを使用するとechoを表示しないようにできます
@の役割は、このコマンドのechoも表示しないようにすることです

### 遅延命令

`timeout -t <font color=Gainsboro>*time* </font>`

`sleep()`に相当します

### ディレクトリ構造

`%~dp0 `	はファイルが現在あるディレクトリです

#### `Dir`関数

`DIR *.* /B >list.txt` 			現在のディレクトリ下のすべてのファイル名をlist.txtに抽出します

そのまま走査に使用できます



##### forで使用するdir

` for /f "delims= ,token= " in ('dir /a-d /b') do{}`

---

delims はディレクトリ下の要素を分割するために使用します：
{“第1行第1列 第1行第2列 第1行第3列”， //最初の要素

“第2行第1列 第2行第2列 第2行第3列”， //2番目の要素

“第3行第1列 第3行第2列 第3行第3列”}   //3番目の要素

->

第1行第1列
第2行第1列
第3行第1列

---

token は delims で分割した後の該当部分を取り出すために使用します

`for /f "tokens=2 delims= " %%i in (a.txt) do echo %%i`

実行結果：

第1行第2列
第2行第2列
第3行第2列

---

##### 識別子

`/R %%i` は現在のディレクトリを走査するために使用します

##### 演算子

- `%%~`

```shell
~n 取得文件名。 ~x 取得扩展名。 ~nx 取得全名，包括扩展名。 ~s 取得目录及全名。 ~p 取得路径。 ~dp 取得绝对路径。

运算符放在变量名字前，写成%%~ni	Linux中${.*var} 同样如此
```



### サービス

`sc` はサービスのみに使用します

`net` はサービスだけでなく、ネットワーク、ユーザー、ログインの大部分のシナリオにも使用できます



`sc` はコマンドラインでは実行できませんが、batスクリプトでは正常に実行できます

`net` にはそのような問題はありません



`sc` はサービスのみに使用し、エコーは詳細に表示されます

### 権限昇格

- ショートカットは管理者として実行を使用
- runasコマンド
- powershellのStart-Processコマンド
- vbsでShell.ApplicationオブジェクトのShellExecuteを呼び出す

```shell
runas命令是一个Windows内置的命令，它可以让你以指定的用户身份运行一个程序或命令。它的语法是：runas /user:<user> <program>，其中<user>是你要使用的用户账户，<program>是你要运行的程序或命令。例如，如果你要以管理员身份运行bat脚本，你可以这样写：runas /user:Administrator myscript.bat。但是这样会提示你输入管理员密码，如果你不想输入密码，你可以使用/savecred参数来保存凭据，但是这样可能会有安全风险。

Start-Process命令是一个PowerShell内置的命令，它可以让你启动一个或多个进程，并设置一些选项，比如工作目录、窗口样式、重定向输出等。它的语法是：Start-Process -FilePath <file> [-ArgumentList <args>] [-Verb RunAs] [-WindowStyle <style>] [-Wait]，其中<file>是你要运行的文件，<args>是你要传递给文件的参数，-Verb RunAs是指定以管理员身份运行，-WindowStyle <style>是指定窗口样式，比如Normal, Hidden, Minimized, or Maximized，-Wait是指定等待进程结束再继续执行。例如，如果你要以管理员身份运行bat脚本，并等待它结束，你可以这样写：Start-Process -FilePath myscript.bat -Verb RunAs -Wait。但是这样会弹出UAC确认对话框，如果你不想弹出对话框，你可以使用vbs脚本来调用Shell.Application对象的ShellExecute方法。
```



```bash
cd /d "%~dp0" && ( if exist "%temp%\getadmin.vbs" del "%temp%\getadmin.vbs" ) && fsutil dirty query %systemdrive% >nul 2>&1 || (  echo Set UAC = CreateObject^("Shell.Application"^) : UAC.ShellExecute "cmd.exe", "/k cd ""%~dp0"" && ""%~s0"" !params!", "", "runas", 1 >> "%temp%\getadmin.vbs" && "%temp%\getadmin.vbs" && exit /B )
```
