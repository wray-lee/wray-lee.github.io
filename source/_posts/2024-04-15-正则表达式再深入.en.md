# Regular Expressions in More Depth

## Parentheses

> (?i): case-insensitive

Parentheses () have two functions:

- Grouping

Grouping allows the subpattern inside the parentheses to use quantifiers.

- Capturing

When there are nested parentheses in a pattern, variable numbering proceeds sequentially according to the position where the opening parenthesis appears.

```shell
([A-Za-z](\d{2}))((-)\d{2})匹配”A22-33”时，匹配情况如下：

Group 1:  A22

Group 2:  22

Group 3:  -33

Group 4:  -
```

- Non-capturing parentheses:

**Generally used when nesting**

.NET and JavaScript both provide non-capturing parentheses, i.e., the content of the parentheses is not treated as a capture target. When the content in the parentheses is not the object you want to capture, using non-capturing parentheses can improve matching efficiency. (That is, the captured content is not stored and is destroyed after the generated return value is called.) The syntax is:

    (?:the-non-captured-content)
    
    (\w(?:\d{2}))((?:-)\d{2}) matches " A22-33" as follows:
    
    Group 1:  A22
    
    Group 2:  -33
    
    Note: The "22" matched by \d{2} is not captured.

- Backreferences

Syntax: In .NET and JavaScript, the variable representing the first matched group is specified as "\1"

```javascript
let reg = /^([dtn])a\1/
let result = reg.test('da')    // false
let result = reg.test('ta')    // false
let result = reg.test('na')    // false
let result = reg.test('nata')    // false
let result = reg.test('dada')    // true
```

^ indicates the beginning, () indicates group matching, [] indicates choosing one of d, t, or n, and \1 indicates equality; this equality is for the characters in (), in this example it refers to the character before a. At this point, the character before a is d, so \1 refers to d.

Let the string to be matched be S; \1 indicates a match only if it is equal to S.
