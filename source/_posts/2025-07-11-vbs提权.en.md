# VBS Privilege Escalation

```vb
If WScript.Arguments.Named.Exists("elevate") = False Then
  CreateObject("Shell.Application").ShellExecute "wscript.exe", """" & WScript.ScriptFullName & """ /elevate", "", "runas", 1
  WScript.Quit
End If

' 此时会更改路径，需要重新获取工作路径

Dim fso
Set fso = CreateObject("Scripting.FileSystemObject")

Dim scriptPath
scriptPath = fso.GetParentFolderName(WScript.ScriptFullName)

Dim clash
Set clash = Wscript.CreateObject("Wscript.Shell")
clash.CurrentDirectory = scriptPath


clash.run "clash.exe -d ./config", 0, False
Wscript.quit
```

## Syntax

### Strings

#### Declaration

Strings in VB need to be declared using `"{content}"`, i.e., double quotation marks. To express a normal double quotation mark, use `"""`: the outer double quotation marks are for declaration, and the inner one is the actual expression.

#### Concatenation

Strings are concatenated using `&`.

To express "hello world", it is:

```vb
""hello world""

""hello" & " " & "world""
```
