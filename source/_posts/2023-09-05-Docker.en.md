## Registry

**Login**: `docker login`

**Logout**: `docker logout`

**Search images**: `docker search [镜像名]`

## Images

**View images**: `docker images`

**Create a container using an image**: `docker run [镜像名]`

```bash
#docker run 参数
-v [主机路径]:[容器路径]	#将容器路径挂载到主机
-P #容器内部端口随机映射到主机端口
-p [主机端口]:[容器端口]	#将特定容器端口映射到特定主机端口
--name [容器名字]	#容器命名
```

**Delete image**: `docker rmi [镜像名]`

## Containers

**View containers**: `docker ps -a`

**Delete container**: `docker rm [容器名]`

**Enter container**: `docker exec -it [容器序号/容器名字] /bin/bash` / `docker exec -it [容器序号] /bin/sh`

```bash
-i:interact 交互操作
-t:terminal 终端
-d:down 后台运行
```

**Start existing container**: `docker restart [container]`

**Stop existing container**: `docker stop [container]`		`sudo aa-remove-unknown(遇到permission denied)`

## Container linking (container networking)

### Network creation and joining

**Create network**:

- `docker network create -d bridge [网络桥名字]`
- `docker network create -d overlay [网络隧道名]`

**Join network**:

- When creating a container:

`docker run -itd --name [容器名] --network [网络名] [镜像名] [/bin/bash(终端环境)]`

- Join when the container already exists:

`docker network connect [network_name] [container_name] `

### Network DNS configuration

The host's `/etc/docker/daemon.json` can configure the container's default DNS configuration

**View container DNS**:

`docker run -it --rm  [container]  cat etc/resolv.conf`

**Manually specify container DNS**:

`docker run -it --rm -h [容器主机名]  --dns=[dns_ip] --dns-search=test.com [container]`

---

Parameters:

```bash
--rm：容器退出时自动清理容器内部的文件系统。

-h HOSTNAME 或者 --hostname=HOSTNAME： 设定容器的主机名，它会被写到容器内的 /etc/hostname 和 /etc/hosts。

--dns=IP_ADDRESS： 添加 DNS 服务器到容器的 /etc/resolv.conf 中，让容器用这个服务器来解析所有不在 /etc/hosts 中的主机名。

--dns-search=DOMAIN： 设定容器的搜索域，当设定搜索域为 .example.com 时，在搜索一个名为 host 的主机时，DNS 不仅搜索 host，还会搜索 host.example.com。
```
