# Stream

## Live

Live streaming protocols

- Http-Flv	Uses FLV to continuously transmit segmented video
- Hls            By first providing a primary index file that points to several secondary index files (enabling quality-level differentiation), the secondary index files point to different TS segmented video files

### Catcher

- Flv

In Inspect Element, select fetch to find the file with the highest bandwidth usage (.flv); its URL is the live stream link.

- Hls (YouTube is the only platform where the .m3u8 link can be found directly in the source code)

noncode: In Inspect Element, select media to find the .m3u8 link.

primary-encode (with token added): In Inspect Element, select fetch to find the .m3u8 link.

encode: JS decryption / obtain the real link on mobile, then use the desktop key to watch.
