### 1. 核心与对象系统 (Core & UObject System)
这些函数用于获取游戏世界实例、判断对象类型以及获取类模板。

| 函数名                         | 代码中的用法                           | 说明                                                         |
| :----------------------------- | :------------------------------------- | :----------------------------------------------------------- |
| **`UWorld::GetWorld()`**       | `UWorld::GetWorld()`                   | 获取当前的全局世界指针（`UWorld*`），是一切逻辑的入口。      |
| **`AActor::IsA(...)`**         | `Actor->IsA(...)`                      | 判断一个 Actor 是否属于某个特定的类（如判断是否为怪物或玩家）。 |
| **`UClass::StaticClass()`**    | `APlayer_char_main_C::StaticClass()`   | 获取某个类的反射对象（UClass*），常配合 `IsA` 使用。         |
| **`UObject::GetDefaultObj()`** | `APlayer_char_main_C::GetDefaultObj()` | 获取某个类的**默认对象（CDO）**。代码中用它来读取默认的移动速度和基础数值，以便计算倍率。 |

### 2. 坐标与空间 (Actor & Spatial)
这些函数用于获取或设置物体在游戏世界中的位置、距离。

| 函数名                                              | 代码中的用法                                    | 说明                                                         |
| :-------------------------------------------------- | :---------------------------------------------- | :----------------------------------------------------------- |
| **`AActor::K2_GetActorLocation()`**                 | `Actor->K2_GetActorLocation()`                  | 获取 Actor 当前的世界坐标（`FVector`）。<br>*注：带 `K2_` 前缀通常是暴露给蓝图的版本，C++原生是 `GetActorLocation()`，SDK中常用 K2 版本。* |
| **`AActor::K2_SetActorLocation(...)`**              | `Actor->K2_SetActorLocation(TargetLoc, ...)`    | 瞬移 Actor 到指定坐标。代码中用于**魔法子弹**（把子弹瞬移到敌人头上）。 |
| **`AActor::GetDistanceTo(...)`**                    | `MyChar->GetDistanceTo(Actor)`                  | 计算两个 Actor 之间的 3D 距离（单位通常是厘米）。            |
| **`USceneComponent::K2_GetComponentLocation()`**    | `Monster->see_Scene->K2_GetComponentLocation()` | 获取组件（如怪物的视野组件）的世界坐标。                     |
| **`USkinnedMeshComponent::GetSocketLocation(...)`** | `Monster->Mesh->GetSocketLocation(...)`         | 获取骨骼网格体上指定**骨骼或插槽（Socket）**的世界坐标。代码中用于获取怪物头部骨骼 `bone_head` 的位置。 |

### 3. 控制器与摄像机 (Controller & Camera)
这些函数涉及玩家视角的控制以及 3D 世界到 2D 屏幕的转换。

| 函数名                                                     | 代码中的用法                                   | 说明                                                         |
| :--------------------------------------------------------- | :--------------------------------------------- | :----------------------------------------------------------- |
| **`APlayerController::ProjectWorldLocationToScreen(...)`** | `PC->ProjectWorldLocationToScreen(...)`        | **世界转屏幕（W2S）**。将 3D 坐标转换为屏幕 2D 坐标，是绘制 ESP 和自瞄准星的核心函数。 |
| **`APlayerCameraManager::GetCameraLocation()`**            | `PC->PlayerCameraManager->GetCameraLocation()` | 获取摄像机当前的绝对世界坐标（用于计算自瞄角度的起点）。     |
| **`AController::GetControlRotation()`**                    | `PC->GetControlRotation()`                     | 获取玩家当前的视角旋转角度（Aim Angles）。                   |
| **`AController::SetControlRotation(...)`**                 | `PC->SetControlRotation(FinalRot)`             | 设置玩家的视角旋转角度。代码中用于**自瞄**（强制改变视角朝向敌人）。 |

### 4. 数学库 (Kismet Math Library)
使用了 UE 封装好的数学库来进行复杂的向量和角度计算，替代了手写的数学函数。

| 函数名                                            | 代码中的用法                                             | 说明                                                         |
| :------------------------------------------------ | :------------------------------------------------------- | :----------------------------------------------------------- |
| **`UKismetMathLibrary::FindLookAtRotation(...)`** | `UKismetMathLibrary::FindLookAtRotation(Start, Target)`  | 计算从起点看向终点所需的旋转角度（Rotator）。代码中用于计算自瞄的理想角度。 |
| **`UKismetMathLibrary::RLerp(...)`**              | `UKismetMathLibrary::RLerp(Current, Target, Alpha, ...)` | **旋转插值**。用于平滑自瞄，让准星不是瞬间锁死，而是平滑过渡到目标角度。 |



## Unity

如果我们将目标从 Unreal Engine (UE) 转向 **Unity**，底层的编程范式会从 **C++ (UE SDK)** 变为 **C# (Unity API / Mono)**。

虽然逻辑核心（如计算距离、自瞄角度）是一样的，但**API 名称**、**对象结构**和**坐标系**会有很大不同。

以下是你代码中用到的 UE 函数在 Unity 中的对应关系总结：

### 1. 核心系统与对象获取 (Core & Object)

UE 是基于 `UWorld` -> `Level` -> `Actor` 的层级，而 Unity 是基于 `Scene` -> `GameObject` -> `Component`。

| UE 原生函数 (C++)                 | Unity 对应 API (C#)                                          | 说明                                                         |
| :-------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `UWorld::GetWorld()`              | `SceneManager.GetActiveScene()`                              | Unity 没有单一的 World 指针，通常通过场景管理器访问。        |
| `UWorld->PersistentLevel->Actors` | `Object.FindObjectsOfType<T>()`<br>或 `GameObject.FindGameObjectsWithTag()` | **这是最大的区别**。Unity 也就是所谓“遍历GObjectList”。通常需要遍历所有对象列表来找敌人。 |
| `Actor->IsA(Class)`               | `obj is EnemyClass`<br>或 `obj.GetComponent<EnemyClass>() != null` | C# 的类型判断更直观，直接用 `is` 关键字，或者判断是否挂载了某个脚本组件。 |
| `GetDefaultObj()` (CDO)           | `Prefab` (预制体)                                            | Unity 没有 CDO 概念。通常直接读取 Prefab 资源或者硬编码基础数值。 |
| `Actor`                           | `GameObject`                                                 | 游戏中的实体基类。                                           |
| `APlayerController`               | 无严格对应，通常分散在 `Update()`                            | 玩家输入逻辑通常写在挂在主角身上的 `MonoBehaviour` 脚本里。  |

### 2. 坐标与空间 (Transform & Spatial)

**注意坐标系差异**：UE 是 **Z轴向上** (Right-handed/Left-handed 混用)，Unity 是 **Y轴向上** (Left-handed)。

| UE 原生函数                   | Unity 对应 API                                            | 说明                                                         |
| :---------------------------- | :-------------------------------------------------------- | :----------------------------------------------------------- |
| `FVector`                     | `Vector3`                                                 | 基础向量结构体 (x, y, z)。                                   |
| `K2_GetActorLocation()`       | `transform.position`                                      | 获取世界坐标。                                               |
| `K2_SetActorLocation(...)`    | `transform.position = newPos`                             | 设置世界坐标（实现瞬移/Magic Bullet）。                      |
| `GetDistanceTo(Actor)`        | `Vector3.Distance(posA, posB)`                            | 计算两点间距离。                                             |
| `GetSocketLocation(BoneName)` | `animator.GetBoneTransform(HumanBodyBones.Head).position` | **骨骼获取**。如果不是标准人型，则是通过 `transform.Find("Root/Spine/Head")` 遍历子物体找到头部节点。 |
| `K2_GetComponentLocation()`   | `component.transform.position`                            | 组件也是依附于 GameObject 的，直接取其 transform。           |

### 3. 摄像机与屏幕转换 (Camera & W2S)

这是做 ESP 和自瞄最关键的部分。

| UE 原生函数                    | Unity 对应 API                                               | 说明                                                         |
| :----------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `ProjectWorldLocationToScreen` | `Camera.main.WorldToScreenPoint(pos)`                        | **W2S 核心**。注意：Unity 屏幕原点 `(0,0)` 在**左下角**，而 ImGui/绘制库原点通常在**左上角**。**需要手动计算 Y 轴翻转**：`screen.y = Screen.height - screen.y`。 |
| `GetCameraLocation()`          | `Camera.main.transform.position`                             | 获取主摄像机位置。                                           |
| `GetControlRotation()`         | `Camera.main.transform.eulerAngles`<br>或 `transform.localEulerAngles` | Unity 没有强制的“控制器旋转”。通常直接读取摄像机的欧拉角。   |
| `SetControlRotation()`         | `transform.eulerAngles = new Vector3(...)`                   | 设置摄像机角度（实现自瞄）。                                 |

### 4. 数学与自瞄计算 (Math & Aimbot)

Unity 内部使用**四元数 (Quaternion)** 处理旋转，但为了方便通常对外暴露**欧拉角 (Euler Angles/Vector3)**。

| UE 原生函数                      | Unity 对应 API                                               | 说明                                                         |
| :------------------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `FRotator`                       | `Quaternion` (内部) / `Vector3` (外部)                       | UE 的 Rotator 是 (Pitch, Yaw, Roll)，Unity 的 Vector3 是 (x, y, z) 对应 (Pitch, Yaw, Roll)。 |
| `FindLookAtRotation(Start, End)` | `Quaternion.LookRotation(Target - Start)`<br>或 `transform.LookAt(Target)` | 计算朝向目标的旋转四元数。                                   |
| `RLerp` / `RInterpTo`            | `Quaternion.Slerp(curr, target, t)`<br>或 `Quaternion.RotateTowards(...)` | **平滑自瞄**。Slerp 是球形插值，比 Lerp 更适合旋转。         |
| `ClampAngles` (自定义)           | `Mathf.Clamp` / `Mathf.DeltaAngle`                           | Unity 的 `Mathf.DeltaAngle` 自动处理 -180 到 180 的角度差问题，非常方便，不用手写那堆 `while > 180` 的逻辑。 |

### 代码迁移示例 (C++ UE -> C# Unity)

假设你要实现一个简单的 **自瞄 (Aimbot)** 逻辑，代码风格的变化如下：

#### UE (C++)
```cpp
FVector CamLoc = PC->PlayerCameraManager->GetCameraLocation();
FVector TargetLoc = EnemyHeadPos;

// 计算角度
FRotator TargetRot = UKismetMathLibrary::FindLookAtRotation(CamLoc, TargetLoc);

// 设置角度
PC->SetControlRotation(TargetRot);
```

#### Unity (C#)
```csharp
Vector3 CamLoc = Camera.main.transform.position;
Vector3 TargetLoc = EnemyHeadPos; // 获取方式见下文

// 计算方向向量
Vector3 Direction = TargetLoc - CamLoc;

// 计算目标旋转 (四元数)
Quaternion TargetRot = Quaternion.LookRotation(Direction);

// 设置角度 (通常设置摄像机或玩家身体的欧拉角)
// Unity 中 Pitch 是 X轴, Yaw 是 Y轴
Camera.main.transform.rotation = TargetRot; 

// 或者如果只想要平滑移动：
Camera.main.transform.rotation = Quaternion.Slerp(Camera.main.transform.rotation, TargetRot, Time.deltaTime * SmoothSpeed);
```

### 总结 Unity Hook 的不同点

1.  **骨骼位置 (Head Position)**:
    *   **UE**: 通过 `Mesh->GetSocketLocation("head")`。
    *   **Unity**: 骨骼就是普通的 GameObject。你需要遍历层级找到名为 "Head" 的子物体，或者如果用了 `Animator`，可以用 `animator.GetBoneTransform(HumanBodyBones.Head)`。

2.  **世界转屏幕 (W2S) 的坑**:
    *   Unity 的 `WorldToScreenPoint` 返回的 Z 轴是深度。
    *   **必须判断 `result.z > 0`** 才是摄像机前方的物体（这点和 UE 的 return bool 类似）。
    *   **必须翻转 Y 轴**：如果你用 ImGui 绘制，Unity 的 `y` 是从底部开始算的，ImGui 是从顶部开始算的。
    *   代码：`screenPos.y = Screen.height - screenPos.y;`

3.  **查找列表**:
    *   UE 逆向通常是找 `GWorld` -> `Level` -> `ActorArray` 的偏移。
    *   Unity 逆向 (Mono) 通常是找 `BaseEntity` 类的静态链表，或者直接 Hook `GameObject` 的特定函数来收集对象列表。

````cpp
bool bAimbot = false;
bool bMagicBullet = false;
float fAimbotFOV = 150.0f;  // 自瞄范围
float fAimbotSmooth = 1.0f; // 平滑度 (1.0 = 锁死)
bool bDrawFOV = true;       // 绘制 FOV 圈

auto MyController = GetPlayerController();
//通过for循环遍历附近敌人
if (bAimbot || bMagicBullet)
{
   for (AActor *Actor : Actors)
   {
       if (!Actor || Actor == MyChar)
           continue;

       // 筛选: 必须是怪物类型
       if (GetActorType(Actor) != EActorType::Enemy)
           continue;

       auto Monster = static_cast<AMG_AI_actor_master_C *>(Actor);
       if (Monster->is_death || Monster->HP_current <= 0)
           continue;

       // 获取头部位置
       FVector HeadPos = GetEnemyHeadPos(Actor);
       FVector2D ScreenPos;

       // 转换并判断是否在 FOV 内
       if (PC->ProjectWorldLocationToScreen(HeadPos, &ScreenPos, true))
       {
           float Dist = Math::GetDistance2D(ScreenCenter, ScreenPos);
           if (Dist < BestDist)
           {
               BestDist = Dist;
               BestTarget = Actor;
           }
       }
   }
   CurrentTarget = BestTarget; // 更新全局目标
}
// 如果没有目标，后续都不执行
if (!CurrentTarget) return;
FVector TargetLoc = GetEnemyHeadPos(CurrentTarget);
//获取相机与敌人坐标
FVector CamLoc = MyController->PlayerCameraManager->GetCameraLocation();
FRotator CurrentRot = MyController->GetControlRotation();

FRotator TargetRot = UKismetMathLibrary::FindLookAtRotation(CamLoc, TargetLoc);
FRotator FinalRot = UKismetMathLibrary::RLerp(CurrentRot, TargetRot, fAimbotSmooth, true);
````

## noclip

```markdown
// --- 定义在 namespace menu 里或者 Loop 外面的静态变量 ---
    static bool bNoclip = false;       // 开关
    static float fNoclipSpeed = 20.0f; // 飞行速度 (根据游戏单位调整，通常 10-50 之间)
    
    // ==========================================
    // 将以下代码放入 Loop() 函数内部
    // ==========================================

    if (bNoclip)
    {
        // 1. 关闭碰撞 (穿墙的关键)
        // 如果 SDK 没有生成 SetActorEnableCollision，你需要手动修改内存或用 ProcessEvent
        // 绝大多数 Dumper-7 SDK 都有这个函数
        MyChar->SetActorEnableCollision(false);

        // 2. 获取当前数据
        // 获取相机的旋转角度（你看向哪里）
        FRotator CameraRot = MyController->GetControlRotation(); 
        // 获取当前坐标
        FVector CurrentPos = MyChar->K2_GetActorLocation();
        
        FVector NextPos = CurrentPos;

        // 3. 计算方向向量
        FVector ForwardVec = GetForwardVector(CameraRot); // 准星方向
        FVector RightVec = GetRightVector(CameraRot);     // 侧身方向

        // 4. 处理按键输入 (W/A/S/D/Space/Ctrl)
        bool bIsMoving = false;

        // W: 向准星方向飞
        if (GetAsyncKeyState('W') & 0x8000) {
            NextPos.X += ForwardVec.X * fNoclipSpeed;
            NextPos.Y += ForwardVec.Y * fNoclipSpeed;
            NextPos.Z += ForwardVec.Z * fNoclipSpeed;
            bIsMoving = true;
        }
        // S: 向后退
        if (GetAsyncKeyState('S') & 0x8000) {
            NextPos.X -= ForwardVec.X * fNoclipSpeed;
            NextPos.Y -= ForwardVec.Y * fNoclipSpeed;
            NextPos.Z -= ForwardVec.Z * fNoclipSpeed;
            bIsMoving = true;
        }
        // D: 向右飞
        if (GetAsyncKeyState('D') & 0x8000) {
            NextPos.X += RightVec.X * fNoclipSpeed;
            NextPos.Y += RightVec.Y * fNoclipSpeed;
            NextPos.Z += RightVec.Z * fNoclipSpeed; // 加上Z轴分量可以倾斜飞行，如果不加就是水平横移
            bIsMoving = true;
        }
        // A: 向左飞
        if (GetAsyncKeyState('A') & 0x8000) {
            NextPos.X -= RightVec.X * fNoclipSpeed;
            NextPos.Y -= RightVec.Y * fNoclipSpeed;
            NextPos.Z -= RightVec.Z * fNoclipSpeed;
            bIsMoving = true;
        }

        // Space: 垂直上升 (可选，方便调整高度)
        if (GetAsyncKeyState(VK_SPACE) & 0x8000) {
            NextPos.Z += fNoclipSpeed;
            bIsMoving = true;
        }
        // Ctrl: 垂直下降
        if (GetAsyncKeyState(VK_CONTROL) & 0x8000) {
            NextPos.Z -= fNoclipSpeed;
            bIsMoving = true;
        }

        // 5. 应用新坐标
        if (bIsMoving) {
            // 参数2: bSweep (是否检测碰撞)，设为 false
            // 参数3: SweepHitResult，设为 nullptr
            // 参数4: bTeleport，设为 true (告诉物理引擎这是瞬移，不要计算速度/动量)
            MyChar->K2_SetActorLocation(NextPos, false, nullptr, true);
        }
    }
    else
    {
        // 6. 关闭 Noclip 时，恢复碰撞
        // 使用静态变量确保只执行一次恢复操作，避免每帧重复调用消耗性能
        static bool last_bNoclipState = false;
        if (last_bNoclipState != bNoclip) {
            if (!bNoclip) {
                MyChar->SetActorEnableCollision(true);
                // 可选：如果关掉时卡在墙里，可能会被弹飞，这是正常物理现象
            }
            last_bNoclipState = bNoclip;
        }
    }
```

## esp

```cpp
void Esp()
{
    // 自瞄绘制
    if (bAimbot && bDrawFOV)
    {
        auto io = ImGui::GetIO();
        ImGui::GetBackgroundDrawList()->AddCircle(
            ImVec2(io.DisplaySize.x / 2, io.DisplaySize.y / 2),
            fAimbotFOV,
            ImColor(255, 255, 255, 60),
            64);
    }
    if (!bEspEnable)
        return;

    APlayerController *PC = GetPlayerController();
    APlayer_char_main_C *MyChar = GetLocalPlayerChar();
    UWorld *World = UWorld::GetWorld();

    if (!PC || !MyChar || !World || !World->PersistentLevel)
        return;

    TArray<AActor *> Actors = World->PersistentLevel->Actors;

    for (int i = 0; i < Actors.Num(); i++)
    {
        AActor *Actor = Actors[i];
        if (!Actor || Actor == MyChar)
            continue;

        // 距离计算 (UE单位通常是厘米，/100 换算成米)
        float Distance = MyChar->GetDistanceTo(Actor) / 100.0f;
        // if (Distance > 400.0f) continue; // 400米外不显示

        FVector Pos = Actor->K2_GetActorLocation();

        // --- 核心：使用 switch 进行分流 ---
        switch (GetActorType(Actor))
        {
        case EActorType::Player:
        {
            if (!bEspPlayer)
                break; // 开关判断

            auto Player = static_cast<APlayer_char_main_C *>(Actor);
            // if (Player->Is_death_ || Player->Is_down_) break; // 死了不画

            char Buf[64];
            sprintf_s(Buf, "Player [%.0fm]\nHP: %d", Distance, (int)Player->HP_current);

            // 绿色显示
            DrawText3D(PC, Pos + FVector(0, 0, 100), Buf, col_Player);
            break;
        }

        case EActorType::Enemy:
        {
            if (!bEspMonster)
                break;

            auto Monster = static_cast<AMG_AI_actor_master_C *>(Actor);
            if (Monster->is_death)
                break; // 死了不画

            char Buf[64];
            // 可以在这里根据 Monster->monster_type 进一步 switch 显示不同怪名字
            sprintf_s(Buf, "Enemy [%.0fm]\nHP: %d", Distance, (int)Monster->HP_current);

            // 红色显示
            DrawText3D(PC, Pos + FVector(0, 0, 100), Buf, col_Monster);
            break;
        }

        case EActorType::Chest:
        {
            if (!bEspLT)
                break; // 假设 LT 也是控制掉落的

            char Buf[64];
            sprintf_s(Buf, "Item [%.0fm]", Distance);

            // 黄色显示
            DrawText3D(PC, Pos, Buf, col_Loot);
            break;
        }

        case EActorType::Unknown:
        default:
            // 未知类型直接跳过
            break;
        }
    }
}
```

# Math库（用于没有引擎原生函数）

```cpp
namespace Math
{
    float GetDistance2D(FVector2D A, FVector2D B)
    {
        return sqrt(pow(A.X - B.X, 2) + pow(A.Y - B.Y, 2));
    }

    FRotator VectorToRotator(FVector Start, FVector Target)
    {
        FVector Delta = Target - Start;
        float Hyp = sqrt(Delta.X * Delta.X + Delta.Y * Delta.Y);
        FRotator Rot;
        Rot.Yaw = atan2(Delta.Y, Delta.X) * (180.0f / M_PI);
        // ue中pitch相反
        Rot.Pitch = -atan2(Delta.Z, Hyp) * (180.0f / M_PI);
        Rot.Roll = 0.0f;
        return Rot;
    }

    // 将角度标准化到 -180 ~ 180
    // 有引擎原生 FRotator Delta = UKismetMathLibrary::NormalizedDeltaRotator(Target, Current);
    // Result.Normalize();
    FRotator ClampAngles(FRotator Rot)
    {
        // 1. 先处理 Yaw 的归一化
        while (Rot.Yaw > 180.0f)
            Rot.Yaw -= 360.0f;
        while (Rot.Yaw < -180.0f)
            Rot.Yaw += 360.0f;

        // 2. 先处理 Pitch 的归一化，再进行 Clamp
        // 如果不加这个，当 Delta 超过 180 度时（比如 360），会被错误地截断成 89
        while (Rot.Pitch > 180.0f)
            Rot.Pitch -= 360.0f;
        while (Rot.Pitch < -180.0f)
            Rot.Pitch += 360.0f;

        // 3. 最后再限制俯仰角在合法范围内
        if (Rot.Pitch > 89.0f)
            Rot.Pitch = 89.0f;
        if (Rot.Pitch < -89.0f)
            Rot.Pitch = -89.0f;

        Rot.Roll = 0.0f;
        return Rot;
    }

    // 平滑插值
    FRotator SmoothAngle(FRotator Current, FRotator Target, float Smooth)
    {
        FRotator Delta = Target - Current;
        Delta = ClampAngles(Delta);
        return ClampAngles(Current + Delta * Smooth);
    }
    // noclip

    FVector GetCameraForward(FRotator Rot)
    {
        float sp = sin(DEG2RAD(Rot.Pitch));
        float cp = cos(DEG2RAD(Rot.Pitch));
        float sy = sin(DEG2RAD(Rot.Yaw));
        float cy = cos(DEG2RAD(Rot.Yaw));
        return {cp * cy, cp * sy, sp};
    }

    FVector GetCameraRight(FRotator Rot)
    {
        float sy = sin(DEG2RAD(Rot.Yaw));
        float cy = cos(DEG2RAD(Rot.Yaw));
        return {-sy, cy, 0.0f};
    }
}
```

# Source

**起源引擎 (Source Engine)** 是 Valve 开发的引擎（代表作：CS:GO/CS2, Apex Legends, L4D2, TF2）。

从 Unreal Engine 转向 Source Engine，你会发现最大的区别在于：UE 高度依赖 **反射系统 (UObject/Reflection)**，而 Source Engine 高度依赖 **虚函数接口 (Virtual Interfaces)** 和 **网络变量 (Netvars)**。

以下是你用到的功能在 Source Engine 中的对应方式：

### 1. 核心系统与对象获取 (Interfaces vs UWorld)
UE 有一个全局的 `UWorld`，里面存着所有 Actor。
Source Engine 使用 **接口模式 (Interface Pattern)**。你需要获取引擎暴露出的全局接口指针。

| UE 原生函数               | Source Engine 对应接口/方法                                  | 说明                                                         |
| :------------------------ | :----------------------------------------------------------- | :----------------------------------------------------------- |
| `UWorld::GetWorld()`      | 无单一入口，通常获取 **`IClientEntityList`** 和 **`IVEngineClient`** | 你需要通过 `CreateInterface` 导出函数来获取这些全局接口。    |
| `PersistentLevel->Actors` | **`IClientEntityList::GetClientEntity(index)`**              | Source 的实体存放在一个索引数组中。Index 0 是世界，1~64 是玩家，64+ 是实体/武器。你需要写个 `for` 循环遍历 0 到 `GetHighestEntityIndex()`。 |
| `Actor`                   | **`C_BaseEntity`** / `IClientEntity`                         | 所有物体的基类。                                             |
| `IsA(...)`                | `GetClientClass()->m_pNetworkName`                           | Source 通过 `ClientClass` 链表判断类型。通常比较 ClassID（如 `CCSPlayer`）。 |
| `APlayerController`       | `C_BasePlayer` (Local)                                       | 本地玩家通常通过 `GetClientEntity(GetLocalPlayerIndex())` 获取。 |

### 2. 坐标与空间 (Vectors & Netvars)
UE 的属性（如 HP, Pos）通常是类成员变量。
Source Engine 的属性通常是 **Netvars (网络变量)**，通过读取内存偏移（Offset）或 RecvTable 获取。

| UE 原生函数                     | Source Engine 对应                    | 说明                                                         |
| :------------------------------ | :------------------------------------ | :----------------------------------------------------------- |
| `FVector` (X, Y, Z)             | **`Vector`** (x, y, z)                | 也是 Z 轴向上。                                              |
| `FRotator` (Pitch, Yaw, Roll)   | **`QAngle`** (Pitch, Yaw, Roll)       | 专门用于角度的结构体。                                       |
| `K2_GetActorLocation()`         | `GetAbsOrigin()` 或读取 `m_vecOrigin` | 获取坐标。                                                   |
| `K2_SetActorLocation(...)`      | 无法直接 Set。                        | Source 是强服务器验证。修改本地坐标通常会被拉回。瞬移通常靠利用漏洞（如 L4D2 的 warp）或发送特定数据包。 |
| `GetSocketLocation(...)` (骨骼) | **`SetupBones`** + `m_dwBoneMatrix`   | **这是难点**。Source 需要调用 `SetupBones` 更新骨骼矩阵，然后从矩阵数组中通过骨骼索引（如 8=Head）读取坐标。 |
| `HP_current` (成员变量)         | `m_iHealth` (Netvar)                  | 需要通过 Netvar Manager 扫描 `DT_BasePlayer` 表找到 `m_iHealth` 的偏移。 |

### 3. 摄像机与输入 (CreateMove vs SetControlRotation)
这是 Source Engine Hook 的精髓所在。
在 UE 中，你直接改 Controller 的 Rotation。
在 Source 中，通常 Hook **`CreateMove`** 函数。

| UE 原生函数          | Source Engine 对应              | 说明                                                         |
| :------------------- | :------------------------------ | :----------------------------------------------------------- |
| `SetControlRotation` | **`CUserCmd::viewangles`**      | 在 `CreateMove` 中，每一帧客户端都会生成一个 `CUserCmd` 发给服务器。直接修改 `cmd->viewangles` 即可实现自瞄。 |
| `GetControlRotation` | `IVEngineClient::GetViewAngles` | 获取当前视角。                                               |
| **优势**             | **Silent Aim (静默自瞄)**       | 在 Source 中，你可以修改发送给服务器的 `viewangles` 但**不修改**本地摄像机的角度。结果是：你看着前方，子弹却飞向侧面的敌人。UE 很难做到这一点（通常需要改 Bone Transform）。 |

### 4. 世界转屏幕 (W2S)
Source Engine 的 W2S 需要依赖 **ViewMatrix (视图矩阵)**。

| UE 原生函数                    | Source Engine 对应         | 说明                                                         |
| :----------------------------- | :------------------------- | :----------------------------------------------------------- |
| `ProjectWorldLocationToScreen` | **`WorldToScreen` (手写)** | 你需要从 `IVEngineClient` 或渲染器中找到 **ViewMatrix** (4x4 矩阵)。然后进行标准的矩阵乘法运算将 3D 转 2D。 |
| Debug 绘制                     | `ISurface` 接口            | Source 提供了一个 `ISurface` 接口，可以画线、画字、画矩形，比 ImGui 更原生（但在现代作弊中 ImGui 更流行）。 |

### 5. 射线检测 (RayCast / Visibility)
判断敌人是否在墙后。

| UE 原生函数       | Source Engine 对应           | 说明                                                         |
| :---------------- | :--------------------------- | :----------------------------------------------------------- |
| `LineTraceSingle` | **`IEngineTrace::TraceRay`** | 这是一个非常强大的接口。你需要构建 `Ray_t` 和 `CTraceFilter`，然后调用引擎的 TraceRay 来检测可见性。 |

```cpp
// 这里的 pCmd 控制着这一帧所有的输入（鼠标移动、按键、视角）

Vector localPos = localPlayer->GetEyePosition();
Vector enemyHead = enemy->GetBonePos(8); // 8 is usually head
```

### 总结 Source Engine Hook 的特点

1.  **更“底层”**: 没有 UE 那么多封装好的 `K2_` 函数，很多时候要操作矩阵和向量。
2.  **Netvars (网络变量)**: 必须理解 RecvTable，所有游戏数据都是通过网络表同步的，逆向时主要是 dump 这些表的偏移。
3.  **CreateMove**: 这是 Source 辅助的核心，所有的 连跳(Bhop)、自瞄(Aimbot)、假身(Anti-Aim)、自动扳机(Triggerbot) 都在这里实现。
4.  **Dormant (休眠)**: Source 为了优化网络，不会发送远处的敌人数据给客户端。如果 `IsDormant() == true`，你甚至无法知道敌人在哪（这是防透视的天然屏障，而 UE 默认通常会把所有 Actor 发送过来，除非开启了 Relevancy 优化）。
