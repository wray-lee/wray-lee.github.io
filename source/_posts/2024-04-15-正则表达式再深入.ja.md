# 正規表現をさらに深く

## 丸括弧

> (?i): 大文字と小文字を区別しない

丸括弧()には2つの機能があります：

- グループ化

グループ化により、丸括弧内の部分に量指定子を使用できます

- キャプチャ

パターン内にネストした丸括弧がある場合、変数の番号は開き丸括弧が現れる位置に従って順に付けられます。

```shell
([A-Za-z](\d{2}))((-)\d{2})匹配”A22-33”时，匹配情况如下：

Group 1:  A22

Group 2:  22

Group 3:  -33

Group 4:  -
```

- 非キャプチャの丸括弧：

**通常はネスト時に使用します**

.NET と JavaScript はどちらも非キャプチャ丸括弧の機能を提供しています。つまり、丸括弧の内容はキャプチャ対象になりません。丸括弧内の内容がキャプチャしたい対象でない場合、非キャプチャ丸括弧を使うとマッチ効率を高められます。（つまり、キャプチャした内容を保存せず、呼び出して戻り値を生成した後に破棄されます）構文は次のとおりです：

    (?:the-non-captured-content)
    
    (\w(?:\d{2}))((?:-)\d{2}) が ” A22-33” にマッチする場合、以下のとおりです：
    
    グループ 1:  A22
    
    グループ 2:  -33
    
    注：\d{2} がマッチする ”22” はキャプチャされていません

- 後方参照(backreferences)

構文：.NET と JavaScript では、最初のグループにマッチしたものを表す変数は ”\1” として指定されます

```javascript
let reg = /^([dtn])a\1/
let result = reg.test('da')    // false
let result = reg.test('ta')    // false
let result = reg.test('na')    // false
let result = reg.test('nata')    // false
let result = reg.test('dada')    // true
```

^ は先頭を表し、() はグループマッチを表し、[] は dtn の3つから1つを選ぶことを表し、\1 は等しいことを表します。この等しさは () 内の文字を対象としており、この例では a の前の文字を指します。このとき a の前の文字が d なら、\1 は d を指します

マッチ対象の文字列を S とすると、\1 は S と等しい場合にのみマッチすることを表します
