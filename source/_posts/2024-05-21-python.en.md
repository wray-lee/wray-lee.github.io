### Nesting

> Allows passing an argument when calling the decorator.

```python
def log(text):
    def decorator(func):
        def wrapper(*args, **kw):
            print('%s %s():' % (text, func.__name__))
            return func(*args, **kw)
        return wrapper
    return decorator


@log('execute')
def now():
    print('2015-3-25')
```

Return value:

```python
execute now():
2015-3-25
```



Each function under @decorator corresponds to being passed to the decorator individually, meaning the decorator can only accept one function at a time.
