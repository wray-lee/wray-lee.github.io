# Operating System Username Settings

Neither Windows nor Linux is case-sensitive for usernames, so usernames are set with the first letter capitalized

Device names should match accordingly for the same reason



# Windows

Underscores _ have poor compatibility, so use hyphens - instead as much as possible

# Linux

Both are fine; for compatibility, - can be used
