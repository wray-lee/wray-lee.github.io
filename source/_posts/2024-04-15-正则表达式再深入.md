# 正则表达式再深入

## 小括号

> (?i): 不区分大小写

小括号()有两种功能：

- 分组

分组可以让小括号内的字段使用限定符

- 捕获

当模式中有嵌套的圆括号时，变量的编号会按照圆开括号出现的位置一次进行。

```shell
([A-Za-z](\d{2}))((-)\d{2})匹配”A22-33”时，匹配情况如下：

Group 1:  A22

Group 2:  22

Group 3:  -33

Group 4:  -
```

- 非捕获的圆括号：

**一般在嵌套时使用**

.NET和JavaScript都提供了非捕获圆括号的功能，即圆括号的内容不作为捕获对象，当圆括号中的内容不是想捕获的对象时，采用非捕获圆括号可以提高匹配效率。（即不会存储捕获的内容，调用生成返回值后即销毁）语法为：

    (?:the-non-captured-content)
    
    (\w(?:\d{2}))((?:-)\d{2})匹配” A22-33”情况如下：
    
    Group 1:  A22
    
    Group 2:  -33
    
    注：\d{2}匹配的”22”没有被捕获

- 反向引用(backreferences)

语法：.NET和JavaScript中，表示匹配第一组的变量被指定为”\1”

```javascript
let reg = /^([dtn])a\1/
let result = reg.test('da')    // false
let result = reg.test('ta')    // false
let result = reg.test('na')    // false
let result = reg.test('nata')    // false
let result = reg.test('dada')    // true
```

^表示开头，()表示分组匹配，[]表示dtn三者选其一，\1是表示相等，这个相等针对的是()中的字符，本例中指a前面的字符，此时a前面的字符是d，那么\1就指代d

将待匹配的字符串记为S，\1表示与S相等才进行匹配
