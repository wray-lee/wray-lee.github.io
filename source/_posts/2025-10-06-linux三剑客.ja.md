# Linux三銃士

## sed

`-i 写入文件`

`-i.bak 写入文件并备份`

### 出力

```bash
sed -e '1p'	# 打印第一行
sed -e '1,3p' # 打印1-3行
sed -e '1,+3p' # 从第1行向下打印3行
```



### 複数行を1行に結合

```bash
sed ':a;N;$!ba;s/\n/ /g' file
# :a设定一个指令标签 标记当前位置，N读取下一行，$!判断如果不是最后一行 ，ba返回a标签，指令循环执行
# $!不是最后一行，$!=100不是第100行
```

### 空行の削除

```bash
sed -e '/^$/d'
```

### 自動出力の抑制

> sedはマッチ/置換を行うたびに処理対象の行を出力します。-n を指定すると、マッチした行だけを出力します。

```bash
sed -n 
```

## awk

> パターンとアクションで構成され、1つのパターンには必ず1つのアクションが必要です。

`awk 'length ($0) > 1 {} /^w/ {print $NF}'`

`awk 'length ($0) > 1 && /^w/ {print $NF}'`

### 区切り文字の指定

`awk -F '[分隔符]'`

### print

####   複数のprintで改行しない

`awk '{printf "%s %s %s\n", $1, $6, $7}'`

`awk 'BEGIN{ORS=""}{print $1, $6, $7, "\n"}'`

> \n の原因は awk に出力バッファがあり、\n に遭遇したときのみ内容が出力されるためです。

### grepの代替

`awk '/ZvpKA/ || /dkXfJ/ {printf "%s %s %s\n", $1, $6, $7}'`

### よく使う用法

まず不可視文字を削除する必要があります

`sed -i '1s/^\xef\xbb\xbf//' /var/log/nginx/drive.log`

$1の重複を除外

```bash
awk '{data[$1] = $6 " " $7} END {for (ip in data) print ip, data[ip]}' # 改变内容

awk '!seen[$1]++ {print $1, $6, $7}' # 只打印第一次的内容

awk '{print $1, $6, $7}' | sort -u -k1,1 # -k1指定开头，1指定结尾，-u输出为一行
```

## スクリプトからawkを読み込んで実行

`awk [选项参数] -f [.awk] var=value file(s)`

```bash
#!/bin/awk -f
#运行前
BEGIN {
    math = 0
    english = 0
    computer = 0
 
    printf "NAME    NO.   MATH  ENGLISH  COMPUTER   TOTAL\n"
    printf "---------------------------------------------\n"
}
#运行中
{
    math+=$3
    english+=$4
    computer+=$5
    printf "%-6s %-6s %4d %8d %8d %8d\n", $1, $2, $3,$4,$5, $3+$4+$5
}
#运行后
END {
    printf "---------------------------------------------\n"
    printf "  TOTAL:%10d %8d %8d \n", math, english, computer
    printf "AVERAGE:%10.2f %8.2f %8.2f\n", math/NR, english/NR, computer/NR
}
```



### 組み込み関数

- BEGIN パターン：awk が入力行を読み込む前に、BEGIN で指定されたアクションを即座に実行することを指します。`BEGIN{}`
- END パターン：awk が正式に終了する前に、END で指定されたアクションを実行することを指します。`END{}`

#### awkの数値系組み込み関数

```
PLAINTEXT
int(expr)     截断为整数：int(123.45)和int("123abc")都返回123，int("a123")返回0
sqrt(expr)    返回平方根
rand()        返回[0,1)之间的随机数，默认使用srand(1)作为种子值
```

#### awkの文字列系組み込み関数

注意してください。awk では **文字インデックスを扱う関数のインデックス位置はすべて1から計算されます**。他の言語の0から始まるのとは異なります。

##### 基本関数

- `sprintf(format, expression1, ...)`：フォーマットされた文字列を返します。[sprintf](https://www.junmajinlong.com/shell/awk/awk_builtin_function1/index.html#sprintf) を参照してください。

    - `a=sprintf("%s\n","abc")`

- `length()`：文字列の文字数、配列要素数、または数値を文字列に変換した後の文字数を返します。

    ```
    PLAINTEXT
    awk '
        BEGIN{
            print length(1.23)     # 4   # CONVFMT %.6g
    
            print 1.234567         # 1.23457
            print length(1.234567) # 7 
            print length(122341223432.1213241234)  # 11
        }'
    ```

- `strtonum(str)`：文字列を10進数値に変換します。

    - str が 0 で始まる場合、8進数として認識します
    - str が 0x または 0X で始まる場合、16進数として認識します

- `tolower(str)`：小文字に変換

- `toupper(str)`：大文字に変換

- `index(str,substr)`：str から substr（部分文字列）を検索し、検索されたインデックス位置（インデックスは1から開始）を返し、見つからなければ0を返します

###### awk substr()

- `substr(string,start[,length])`：string から部分文字列を切り出します

start は切り出しの開始インデックス位置（インデックス位置は0ではなく1から開始）、length は切り出す部分文字列の長さを表します。length を省略した場合、start から残りのすべての文字を切り出すことを意味します。

```
PLAINTEXT
awk '
    BEGIN{
        str="abcdefgh"
        print substr(str,3)   # cdefgh
        print substr(str,3,3) # cde
    }
'
```

start の値が1より小さい場合、1として扱われ、start が文字列の長さより大きい場合、空文字列を返します。

length が0以下の場合、空文字列を返します。

###### awk split() と patsplit()

- `split(string, array [, fieldsep [, seps ] ])`：文字列を分割して配列 array に保存し、配列インデックスは1から格納されます。分割して得られた要素数を返します。

ここで fieldsep は区切り文字を指定し、正規表現方式にすることもできます。この引数を指定しない場合、デフォルトで FS が区切り文字として使用され、FS のデフォルト値は空白です。

seps は配列で、分割のたびに使用された区切り文字を保存します。

例：

```
PLAINTEXT
split("abc-def-gho-pq",arr,"-",seps)
```

戻り値は4です。同時に得られる配列 a と seps は次のとおりです：

```
PLAINTEXT
arr[1] = "abc"
arr[2] = "def"
arr[3] = "gho"
arr[4] = "pq"

seps[1] = "-"
seps[2] = "-"
seps[3] = "-"
```

split は処理開始時にまず配列を空にします。そのため、split の string 引数を空に設定すると、配列を空にするために使用できます。

```
PLAINTEXT
awk 'BEGIN{arr[1]=1;split("",arr);print length(arr)}'  # 0
```

区切り文字が文字列にマッチできない場合、文字列全体が1つの配列要素として配列 array に保存されます。

```
PLAINTEXT
awk 'BEGIN{split("abcde",arr,"-");print arr[1]}' # abcde
```

- `patsplit(string, array [, fieldpat [, seps ] ])`：正規表現 fieldpat で文字列 string をマッチし、マッチに成功したすべての部分を配列 array に保存し、配列インデックスは1から格納されます。戻り値は array の要素数、つまり何回マッチに成功したかです。

fieldpat を省略した場合、デフォルトで事前定義変数 FPAT の値が採用されます。

```
PLAINTEXT
awk '
    BEGIN{
        patsplit("abcde",arr,"[a-z]")
        print arr[1]   # a
        print arr[2]   # b
        print arr[3]   # c
        print arr[4]   # d
        print arr[5]   # e
    }
'
```

###### awk match()

- `match(string,reg[,arr])`：reg を使用して string をマッチし、マッチに成功したインデックス位置（1から数える）を返し、マッチに失敗した場合は0を返します。arr 引数を指定した場合、arr[0] にはマッチに成功した文字列が保存され、arr[1]、arr[2]、… には各グループでキャプチャされた内容が保存されます。

match のマッチ時には、同時に2つの事前定義変数 RSTART と RLENGTH が設定されます。

- マッチ成功時：
    - RSTART にはマッチに成功したインデックス位置が代入され、1から数えます
    - RLENGTH にはマッチに成功した文字長が代入されます
- マッチ失敗時：
    - RSTART には0が代入されます
    - RLENGTH には-1が代入されます

例：

```
PLAINTEXT
awk '
    BEGIN{
        where = match("foooobazbarrrr","(fo+).*(bar*)",arr)
        print where   # 1
        print arr[0]  # foooobazbarrrr
        print arr[1]  # foooo
        print arr[2]  # barrrr
        print RSTART  # 1
        print RLENGTH # 14
    }
'
```

match() はマッチ成功時に戻り値が非0で、マッチ失敗時に戻り値が0であるため、そのまま条件判定として使用できます：

```
PLAINTEXT
awk '
  {
    if(match($0,/A[a-z]+/,arr)){
      print NR " : " arr[0]
    }
  }
' a.txt
```

###### awk sub() と gsub()

- `sub(regexp, replacement [, target])`
- `gsub(regexp, replacement [, target])`：sub() のグローバルモード

sub() は文字列 target から正規表現マッチを行い、replacement を使用して最初にマッチに成功した部分を置換し、置換後は target に保存し直します。置換に成功した回数、つまり0または1を返します。

target は代入可能な変数名、$N、または配列要素名でなければならず、置換成功後の結果を保存するために使用されます。文字列リテラルにすることはできません。データを保存できないためです。

target を省略した場合、デフォルトで `$0` が使用されます。

注意が必要なのは、target を省略した場合、または target が `$N` の場合、置換成功後に OFS を使用して `$0` が再計算されることです。

```
PLAINTEXT
awk '
    BEGIN{
        str="water water everywhere"
        #how_many = sub(/at/, "ith", str)
        how_many = gsub(/at/, "ith", str)
        print how_many   # 1
        print str        # wither water everywhere
    }
'
```

replacement 引数では、特殊な記号 `&` を使用してマッチに成功した部分を参照できます。注意してください。sub() と gsub() は replacement で後方参照 `\N` を使用できません。

```
PLAINTEXT
awk '
    BEGIN{
        str = "daabaaa"
        gsub(/a+/,"C&C",str)
        print str  # dCaaCbaaa
    }
'
```

replacement で `&` の純粋な文字を使用したい場合は、エスケープすればよいです。

```
PLAINTEXT
sub(/a+/,"C\\&C",str)
```

> 2本のバックスラッシュ：
> awk は正規表現の処理を開始するとき、まずすべての awk コードをスキャンしてから awk の内部形式にコンパイルします。スキャン中にバックスラッシュエスケープを解析し、`\\` が1本のバックスラッシュになります。実際に実行が始まると、sub() がさらに解析するため、このとき `\&` が & をエスケープすることを表します。
> コードをスキャンする段階は字句解析段階と呼ばれ、実行時解析段階はランタイム解析段階と呼ばれます。

###### awk gensub()

gawk がサポートする gensub() は、sub() と gsub() を完全に置き換えることができます。

- `gensub(regexp, replacement, how [, target])`：

sub() と gsub() の代わりに使用できます。

how は何番目のマッチを置換するかを指定します。たとえば1を指定すると最初のマッチだけを置換することを表します。さらに、`g` または `G` で始まる文字列を指定して、グローバル置換を表すこともできます。

gensub() は置換後に得られた結果を返し、target は変わりません。マッチに失敗した場合は target を返します。これは sub()、gsub() とは異なります。sub()、gsub() は置換に成功した回数を返します。

gensub() の replacement 部分では `\N` を使用してグループマッチの結果を参照できますが、sub()、gsub() では後方参照を使用できません。また、gensub() は replacement 部分で `&` または `\0` を使用してマッチした結果全体を表すこともできます。

```
PLAINTEXT
awk 'BEGIN{
    a = "abc def"
    b = gensub(/(.+) (.*)/, "\\2 \\1, \\0 , &", "g", a)
    print b  # def abc, abc def , abc def
}'
```

###### awk asort() と asorti()

- `asort(src,[dest [,how]])`
- `asorti(src,[dest [,how]])`

asort は配列 src の値をソートし、ソート後の値のインデックスを1、2、3、4…のシーケンスに変更します。src 内の要素数を返し、これはソート後のインデックス最大値として扱えます。

asorti は配列 src のインデックスをソートし、ソート後のインデックス値のインデックスを1、2、3、4…のシーケンスに変更します。src 内の要素数を返し、これはソート後のインデックス最大値として扱えます。

```
PLAINTEXT
arr["last"] = "de"
arr["first"] = "sac"
arr["middle"] = "cul"
```

asort(arr) の結果：

```
PLAINTEXT
arr[1] = "cul"
arr[2] = "de"
arr[3] = "sac"
```

asorti(arr) の結果：

```
PLAINTEXT
arr[1] = "first"
arr[2] = "last"
arr[3] = "middle"
```

dest を指定した場合、元の配列 src を dest にバックアップし、その後 dest をソートし、src は変更されません。

how 引数はソート時の方式を指定するために使用され、その値の指定方法は `PROCINFO["sorted_in"]` と同じです。事前定義のソート関数でも、ユーザー定義のソート関数でもかまいません。[配列の走査順序の指定](https://www.junmajinlong.com/shell/awk/awk_builtin_function1/index.html#arrsort) を参照してください。
