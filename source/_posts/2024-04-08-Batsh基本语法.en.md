# Batsh Basic Syntax

## Comments

1. Single-line comment `rem blabla`
`@REM blabla`
`:: blabla`
2. End-of-line or single-line comment	`%blabla%`

 Adding > nul after a command can hide the command output.

# Syntax

### Header

Usually `@echo off` is entered at the beginning

echo is an echo command, equivalent to cout, but it displays itself
Using @echo off can prevent echo from being displayed
@ makes the echo of this command not displayed either

### Delay Command

`timeout -t <font color=Gainsboro>*time* </font>`

Equivalent to `sleep()`

### Directory Structure

`%~dp0 `	is the current directory where the file is located

#### `Dir` Function

`DIR *.* /B >list.txt` 			Extracts all file names in the current directory to list.txt

Can be used directly for iteration



##### dir Used with for

` for /f "delims= ,token= " in ('dir /a-d /b') do{}`

---

delims is used to split elements under a directory:
{“Row 1 Column 1 Row 1 Column 2 Row 1 Column 3”, // first element

“Row 2 Column 1 Row 2 Column 2 Row 2 Column 3”, // second element

“Row 3 Column 1 Row 3 Column 2 Row 3 Column 3”}   // third element

->

Row 1 Column 1
Row 2 Column 1
Row 3 Column 1

---

token is used to take the part after delims splitting

`for /f "tokens=2 delims= " %%i in (a.txt) do echo %%i`

Execution result:

Row 1 Column 2
Row 2 Column 2
Row 3 Column 2

---

##### Identifier

`/R %%i` is used to traverse the current directory

##### Operators

运算符放在变量名字前，写成%%~ni	Linux中${.*var} 同样如此

### Privilege Escalation

- Run shortcuts as administrator
- runas command
- Start-Process command in PowerShell
- VBS calls ShellExecute of the Shell.Application object

```shell
runas命令是一个Windows内置的命令，它可以让你以指定的用户身份运行一个程序或命令。它的语法是：runas /user:<user> <program>，其中<user>是你要使用的用户账户，<program>是你要运行的程序或命令。例如，如果你要以管理员身份运行bat脚本，你可以这样写：runas /user:Administrator myscript.bat。但是这样会提示你输入管理员密码，如果你不想输入密码，你可以使用/savecred参数来保存凭据，但是这样可能会有安全风险。

Start-Process命令是一个PowerShell内置的命令，它可以让你启动一个或多个进程，并设置一些选项，比如工作目录、窗口样式、重定向输出等。它的语法是：Start-Process -FilePath <file> [-ArgumentList <args>] [-Verb RunAs] [-WindowStyle <style>] [-Wait]，其中<file>是你要运行的文件，<args>是你要传递给文件的参数，-Verb RunAs是指定以管理员身份运行，-WindowStyle <style>是指定窗口样式，比如Normal, Hidden, Minimized, or Maximized，-Wait是指定等待进程结束再继续执行。例如，如果你要以管理员身份运行bat脚本，并等待它结束，你可以这样写：Start-Process -FilePath myscript.bat -Verb RunAs -Wait。但是这样会弹出UAC确认对话框，如果你不想弹出对话框，你可以使用vbs脚本来调用Shell.Application对象的ShellExecute方法。
```



```bash
cd /d "%~dp0" && ( if exist "%temp%\getadmin.vbs" del "%temp%\getadmin.vbs" ) && fsutil dirty query %systemdrive% >nul 2>&1 || (  echo Set UAC = CreateObject^("Shell.Application"^) : UAC.ShellExecute "cmd.exe", "/k cd ""%~dp0"" && ""%~s0"" !params!", "", "runas", 1 >> "%temp%\getadmin.vbs" && "%temp%\getadmin.vbs" && exit /B )
```
