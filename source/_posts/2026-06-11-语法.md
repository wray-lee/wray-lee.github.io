> powershell 中利用 `&` 来调用可执行文件

```shell
function openconda {
	If (Test-Path "F:\conda\Scripts\conda.exe") {
    (& "F:\conda\Scripts\conda.exe" "shell.powershell" "hook") | Out-String | ?{$_} | Invoke-Expression
}

检测目录存在后利用 `&` 调用可执行文件 		# `&`功能用于正确解析传参语法
可执行文件传出 shell.powershell hook 两个参数		# conda中定义了传出两个参数的接口
`Out-String`	将两个参数输出后	`?{$_}`	去除空行（筛选非空字符串）	# `?` 符号表示 Where-																	Object 命令的简写形																	式，而 `$_` 表示当前																	正在处理的对象(当前对																	   象的占位符）
去除空行后 利用Invoke-Expression执行字符串中的命令



```





## `?{$_}`

> 用于筛选输入的内容

1. 条件筛选：
    - `?{$_ -gt 10}`：筛选大于 10 的元素。
    - `?{$_ -like "*abc*"}`：筛选包含 "abc" 的元素。
    - `?{$_ -eq "value"}`：筛选等于 "value" 的元素。
2. 转换操作：
    - `ForEach-Object { $_.ToUpper() }`：将当前对象转换为大写形式。
    - `ForEach-Object { $_ + 1 }`：对当前对象执行加一操作。
3. 迭代操作：
    - `ForEach-Object { Write-Host $_ }`：迭代并输出当前对象。
    - `ForEach-Object { $_.Property }`：访问当前对象的属性。

## 提权

```powershell
$currentPrincipal = New-Object Security.Principal.WindowsPrincipal([Security.Principal.WindowsIdentity]::GetCurrent())
if (-not $currentPrincipal.IsInRole([Security.Principal.WindowsBuiltInRole]::Administrator)) {
    # 如果不是管理员，重新以管理员身份启动本脚本
    $processInfo = New-Object System.Diagnostics.ProcessStartInfo
    $processInfo.FileName = "powershell.exe"
    # 注意：这里使用 $PSCommandPath 获取当前脚本的绝对路径
    $processInfo.Arguments = "-NoProfile -ExecutionPolicy Bypass -File `"$PSCommandPath`""
    $processInfo.Verb = "RunAs"
    [System.Diagnostics.Process]::Start($processInfo) | Out-Null
    Exit # 退出当前的普通权限进程
}
```

### 打包exe

```powershell
Install-Module -Name ps2exe
Invoke-PS2EXE -InputFile "Start.ps1" -OutputFile "Launcher.exe" -NoConsole -m
```

```powershell
# ==========================================
# 1. 获取真实所在的目录 (兼容 PS1 和 EXE)
# ==========================================
if ($MyInvocation.MyCommand.CommandType -eq "ExternalScript") {
    # 如果是直接运行 .ps1 脚本，使用 PSScriptRoot
    $RealRoot = $PSScriptRoot
}
else {
    # 如果是打包成的 .exe，通过进程信息获取 EXE 所在的真实路径
    $RealRoot = [System.IO.Path]::GetDirectoryName([System.Diagnostics.Process]::GetCurrentProcess().MainModule.FileName)
}

# ==========================================
# 2. 你的启动逻辑 (把 $PSScriptRoot 替换为 $RealRoot)
# ==========================================
$p = New-Object System.Diagnostics.ProcessStartInfo

# 拼接路径
$ClashPath = Join-Path -Path $RealRoot -ChildPath "clash.exe"
$ConfigPath = Join-Path -Path $RealRoot -ChildPath "config"

$p.FileName = $ClashPath
$p.Arguments = "-d `"$ConfigPath`"" 
$p.WorkingDirectory = $RealRoot

# 样式设置
$p.WindowStyle = "Hidden"
$p.CreateNoWindow = $true

# 根据之前的讨论，如果是系统服务/最高权限，建议保持 UseShellExecute = $false
# 如果是普通双击运行且不想依赖输出流，也可以改成 $true
$p.UseShellExecute = $false 

# 防止 UseShellExecute = $false 时崩溃的保险措施
$p.RedirectStandardOutput = $true
$p.RedirectStandardError = $true

# 启动
try {
    [System.Diagnostics.Process]::Start($p) | Out-Null
}
catch {
    # 这里的错误很难被看见，但在 EXE 模式下至少不会弹窗报错
}
```
