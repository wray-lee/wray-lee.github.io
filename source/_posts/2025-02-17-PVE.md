### Nas

`kernel panic`

- 网络设备e1000 改成 virio

- 群晖系统盘设置Async Io 设置为threads。

- 修改 `/etc/default/grub` 文件，找到 GRUB_CMDLINE_LINUX_DEFAULT 项目，再最后增加 `noxsave` 指令

    然后执行 `update-grub` 更新引导

```bash
# /etc/pve/qemu-server/[nas_id].conf
cpu: host,-fma,-xsave,-avx,-avx2,-xsaveopt,-xsavec,-xgetbv1,+xsaveerptr
```



# ESXI

## 定时重启

```bash
/bin/kill $(cat /var/run/crond.pid)

/bin/echo '1 22 * * * /sbin/reboot' >> /var/spool/cron/crontabs/root

/usr/lib/vmware/busybox/bin/busybox crond

exit 0
```

## 屏蔽核显

```bash
#!/bin/bash

read -p 'y or n:' word

if [ "$word" == 'n' ]; then
    esxcli system settings kernel set -s vga -v FALSE
elif [ "$word" == 'y' ]; then
    esxcli system settings kernel set -s vga -v TRUE
else
    echo 'Invalid input'
fi
```



`SataPortMap`	060102 	第1个控制器有6个接口第2个1个第3个2个

`DiskIdxMap` 	 按顺序从左到右每两位数为一个控制器的盘序数(磁盘从哪一位置开始识别)	000607  第一个控制器从0开始 第二个从6开始 第三个从7开始

> 如果0506 则第一个控制器的6个盘不会被识别（盘序号是从00开始的）
