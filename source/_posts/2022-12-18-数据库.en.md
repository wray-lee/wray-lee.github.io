# Database

- Relational: similar to tables, MySQL, Oracle, Microsoft SQL Server, Access
- Non-relational: distributed, does not guarantee adherence to ACID principles, MongoDB, Redis, HBase

## Constraint Types

1. Primary key constraint (primary key): ensures the field is non-null and unique; a table can have only one primary key; the primary key is the unique identifier of a field in the table
2. Not null constraint (not null): ensures the field is not null
3. Unique constraint (unique): ensures the field is unique, but it can be null
4. Foreign key constraint (foreign key): a primary key or unique key of another table that is present in a table becomes the foreign key of this table
5. Default constraint (default): ensures the field has a default value

## UNION

The union keyword is a union query; it combines two select statements into one statement, displayed as one result.

In a union query, the two selects must have the same number of fields (union requires that the number of columns and field types of the queried tables are consistent).



`union all` merges all data directly together

`union` deduplicates the merged data
