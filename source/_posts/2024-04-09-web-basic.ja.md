#### 要素

- ブロック要素： ページレイアウト<div> <p> <h1>… <h6> <ul> <ol> <dl> <li> <table> <form>, **一定のサイズを占め、手動でサイズ設定（デフォルトでは1行を占める）、複数行に並ぶ**
- インライン要素： Web ページ内容<span> <a> <strong> <em><br> <input>, **内容に応じてサイズが決まり、同じ行に並ぶ**
- インラインブロック要素（インライン要素に属し、横並びだがサイズ設定可能）: <img>, **サイズを設定でき、同じ行に並ぶ**

#### &lt;!DOCTYPE&gt;宣言

大文字小文字を区別しない

```markup

```

#### &lt;head&gt;

ヘッド。<title>, <style>, <meta>, <link>, <script>, <noscript> および <base> を追加できる

- <title>	ドキュメントのタイトル
- <base>      リンクタグのデフォルトリンクを設定

```markup
<head>
<base href="http://www.runoob.com/images/" target="_blank">
</head>
```

- <link>	ドキュメントと外部リソースの関係をマークし、CSS のリンク参照によく使われる

```markup
<head>
<link rel="stylesheet" type="text/css" href="mystyle.css">
</head>
```

- <style>	CSS で直接 HTML をレンダリングできる。この方法は**インラインスタイル**

```markup
<head>
    <style type="text/css">
    body{
    	background-color:yellow;
    }
    p {
    	color:blue
    }
    </style>
</head>
```

- <meta>	基本的なメタデータを定義し、解析されるがレンダリング表示はされない

```markup
<meta name="keywords" contents="">
<meta name="description" content="">
<meta name="author" content="">
<meta http-equiv="refresh" content="30">	#每30s刷新网页，可定义基本行为
<meta name="viewport" content="width=device-width, initial-scale=1.0"> #设定缩放比率
```

- <h1>-<h6>	見出し
- <p></p>	    段落
- <a href=”” target=”{_self, _blank, _top, _parent}” ></a> リンク
- <img src=”” width=”” height=”” alt=”图片未加载时的替代文本”>   画像

## Css

内部スタイル（タグ内 style=）、インラインスタイル（HTML に CSS コードを書き込む）、外部スタイル（外部リンクの CSS コード）

優先度：内部 > インライン > 外部

- 内部

```markup
<p style="color: red;font-size: 16px;">
```

- インライン

```markup
<style>
    p {
    	color: red;
    	font-size: 16px;
    }
</style>
```
- 外部

```markup
<link rel="stylesheet" type="text/css" href="./css/style.css">
```

```css
#./css/style.css
p {
    	color: red;
    	font-size: 16px;
}
```

フロートのクリアで解決

```css
/* 伪元素解决 */
.father::after {
	clear:both;    /* 对不想被浮动影响的内容使用 */
}

/* 父元素内解决 */
.father {
    overflow: hidden;
}
```

    align-items: stretch|center|flex-start（排列起点）|flex-end（排列终点）|baseline（主轴）|initial|inherit;
    align-content: stretch|center|flex-start（排列起点）|flex-end（排列终点）|baseline|initial|inherit;(相比items为整体)
}

justify-content: center;     /* 居中排列 */

justify-content: flex-end;   /* 从行尾位置开始排列 */
justify-content: left;       /* 一个挨一个在对齐容器得左边缘 */
justify-content: right;      /* 元素以容器右边缘为基准，一个挨着一个对齐, */

justify-content: space-between;  /* 均匀排列每个元素
                                   首个元素放置于起点，末尾元素放置于终点 */
justify-content: space-around;  /* 均匀排列每个元素
                                   每个元素周围分配相同的空间，两侧都有空间属于当前元素 */
justify-content: space-evenly;  /* 均匀排列每个元素
                                   每个元素之间的间隔相等 */
justify-content: stretch;       /* 均匀排列每个元素
                                   'auto'-sized 的元素会被拉伸以适应容器的大小 */
