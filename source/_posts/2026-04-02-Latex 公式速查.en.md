# Latex Formula Quick Reference

This article records some commonly used Latex characters corresponding to mathematical formulas, for quickly finding the needed characters.



All character formulas used in Latex need to be placed between `\(` and `\)`, `$` and `$`, `\begin{math}` and `\end{math}`.

For relatively large mathematical formulas, such as formulas that need a separate paragraph, you need to use `\[` and `\]` or `\begin{displaymath}` and `\end{displaymath}` to write the formula.

## Inline and Display

```latex
行内(limits)： \sum\limits^n_{i = 1}
行间(nolimits)：\sum\nolimits^n_{i = 1}
```


$$
Inline (limits): \sum\limits^n_{i = 1}	\\
Display (nolimits):\sum\nolimits^n_{i = 1}	\\
$$


## Formula Numbering

Manual numbering method. The manual numbering method can be used in this formula `$$x^n+y^n=z^n$$`, add `\eqno{(1)}` for numbering. The 1 here is the formula number; try entering it yourself and you'll see.

```csharp
$$x^n+y^n=z^n \eqno{(1)}$$
```

Automatic numbering requires using equation

```csharp
\begin{equation}
x^n+y^n=z^n
\end{equation}
```

When referencing a formula, you can reference it by using the manual number, such as `$$a^2+b^2=c^2 /eqno (**)$$`; when referencing, write it like this `由公式($**$)即可得到结论`



For referencing automatic formulas, you need to add a label to the formula before you can reference it. For example, there is the following formula:

```csharp
\begin{equation} \label{eq:eps}
\epsilon > 0
\end{equation}

```

The reference method requires using `\ref`, `从公式 (\ref{eq:eps}), 我们可以知道的德熙是逗比`

Try pasting the following code into Latex and then compiling

```csharp
\documentclass{article}
\usepackage[utf8]{inputenc}

\title{lindexi.oschina.io}
\author{lindexi }
\date{May 2016}

\begin{document}

\begin{equation} \label{lindexi}
\epsilon > 0
\end{equation}

Form (\ref{lindexi}), we can know lindexi is doubi

\end{document}
```

## Superscripts and Subscripts

Use `^` for superscripts and `_` for subscripts.

```csharp

```

![](http://cdn.lindexi.site/lindexi%2F20185251731516956.jpg)

$a^{x+y}+L_{dexi} = doubi$

## Square Roots

The input command is: `\sqrt`; for an n-th root, it is correspondingly: `\sqrt[n]`; if you only need the symbol, use `\surd`.

```csharp
\sqrt{a^2}-\sqrt[5]{a}=\surd{a}
```

$\sqrt{a^2}-\sqrt[5]{a}=\surd{a}$
