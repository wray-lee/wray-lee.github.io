# ffmpeg&ffprobe

`-an`	音声チャンネルを抽出しない

`-vn`	映像チャンネルを抽出しない

## 一括変換

windows

```bat
@echo off

for /R %%v IN (*.mp4) do ( 
::转码视频	
	ffmpeg -i %%v -c:v nvenc_hevc "result\%%~nv.mp4"
::压缩视频
::ffmpeg -i 输入文件名 -c:v libx265 -x265-params crf=18:preset=placebo output/输出文件名.mp4	
::ffmpeg -i 输入文件名 -c:v hevc_nvenc -x265-params crf=18:preset=placebo output/输出文件名.mp4	
::ffmpeg -i 输入文件名 -c:v h264_nvenc -x264-params crf=18:preset=placebo output/输出文件名.mp4	
)
```

Linux
```bat
for file in ./*.mp4
do
	$name=$(echo $file | cut -d . -f1) 
	ffmpeg -i $file -c:v nvenc_hevc "result\$name.mp4"
done
```

### 音声変換

`ffmpeg -i .\videoplayback.weba -ab 154k -ar 48k video.mp3`

> -b はビットレート、   -r はサンプリングレート

## 映像と音声を結合

`ffmpeg -i out.mp4 -i out.aac -vcodec copy -acodec copy new.mp4`

## 音声を抽出

`ffmpeg -i input.mp4 -acodec copy -vn out.aac`

## 映像を抽出

`ffmpeg -i input.mp4 -vcodec copy -an out.mp4`
