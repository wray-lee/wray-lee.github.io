## Full Cone NAT

Unconditional forwarding

## Restricted Cone NAT (Address-Restricted Cone NAT)

Only external hosts that have communicated with the internal network can be NATed.

## Port Restricted Cone NAT

On the basis of the former, add the external host port: data sent from a specific port of an external host that has communicated can be NATed.

## Symmetric NAT

No forwarding.

> client(192.168.0.3, 100) and server(1.1.1.1, 1111) have established a mapping relationship on the router. At this time, if the router (8.8.8.8) receives data on port 800 from another server (2.2.2.2, 2222), should it forward it to (192.168.0.3, 100)?
>
>
>
>
> There are four cases:
>
>
>
>
> 1. Forward unconditionally to (192.168.0.3, 100). This is Full Cone NAT.
>
>
>
>
> 2. If (192.168.0.3, 100) has previously sent data to (2.2.2.2), then forward. This is Restricted Cone NAT.
>
>
>
>
> 3. If (192.168.0.3, 100) has previously sent data to (2.2.2.2, 2222), then forward. This is Port Restricted Cone NAT.
>
>
>
>
> 4. Discard the packet and refuse to forward. This is Symmetric NAT.
