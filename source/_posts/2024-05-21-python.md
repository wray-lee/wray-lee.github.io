# Python

## 闭包

一个函数可以访问到它被定义时所在的环境

```python
def outerFunc(a):
    def innerFunc(b):
        return a+b
    retrun innerFunc
    
    
tmp = outerFunc(1)
print(tmp(2))	# 输出3
```

这个例子中，第一次传入的参数1在tmp被调用时仍然存在，并没有因为第一次执行后被销毁

## 装饰器

> 接受函数作为参数，补充函数功能，先于被装饰函数执行

```python
def now():
     print('2015-3-25')
def log(func)
	def wrapper(*args, **kw):
        print('call %s():' % func.__name__)
        return func(*args, **kw)
    rerutn wrapper
    
@log
def now():
    print('2015-3-25')
```

返回值：


```python
call now()：
2015-3-25
```

### 嵌套

> 允许在调用装饰器时候传入一个参数

```python
def log(text):
    def decorator(func):
        def wrapper(*args, **kw):
            print('%s %s():' % (text, func.__name__))
            return func(*args, **kw)
        return wrapper
    return decorator


@log('execute')
def now():
    print('2015-3-25')
```

返回值：

```python
execute now():
2015-3-25
```



@decorator下的每个函数对应传入装饰器，即装饰器一次只能单独接受一个函数传入



## 错误回调

```python
def errorDecorator(f):
    @wraps(f)	# 更新函数基本信息，如__name__，__doc__
    def wrapper(*args, **kwargs):	# *args为位置参数（正常参数name），**kwargs为关键字参数（键值对参数name=wray）
        try:
            return f(*args, **kwargs)
        except Exception as e: # 判断跳出条件并给予变量别名
            print(f"error occurred: {e}")
    return wrapper

@errorDecorator
def riskyFunc():
    raise ValueError("error")

risky_function()
```
