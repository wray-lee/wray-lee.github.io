# 更改安装位置

- `-l 指定安装路径`
- `winget settings`

```shell
{
    "$schema": "https://aka.ms/winget-settings.schema.json",

    // For documentation on these settings, see: https://aka.ms/winget-settings
    // "source": {
    //    "autoUpdateIntervalInMinutes": 5
    // },
	"installBehavior": {
		"portablePackageUserRoot": "D:/Winget/Packages",
		"portablePackageMachineRoot": "D:/Winget/Packages/Portable",
    },
}
```
