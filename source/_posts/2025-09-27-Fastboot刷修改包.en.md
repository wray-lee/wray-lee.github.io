# Fastboot Flashing Modified Package

## Device Manager

> Fix adb, fastboot not recognizing

Install drivers for unrecognized devices
`Universal Serial Bus -> android_winusb`



For non-super partitions, `fastboot reboot fastboot` is needed to enter fastbootd for flashing

## Base Firmware Flashing

Use FastbootFirmwareFlasher (tg) or other fastboot tools to batch flash all partitions



Flash the base firmware first, to avoid having to flash vendor later

```bash
# 刷写vendor
fastboot flash vendor_boot vendor_boot.img
fastboot flash vendor vendor.img
```



## After Having the Base Firmware or Flashing Vendor

```bash
fastboot getvar all # 查看所有分区
```

## Device Tree

First unpack vendor_boot.img

```bash
binwalk dtb
# 找到偏移量0x40, dec为64
dd if=dtb of=dtb.img skip=64 iflag=skip_bytes

dtc -I dtb -O dts -o device.dts dtb.img
```



## A/B Partitions
