```none
*    *    *    *    *
-    -    -    -    -
|    |    |    |    |
|    |    |    |    +----- 星期中星期几 (0 - 6) (星期天 为0)
|    |    |    +---------- 月份 (1 - 12)
|    |    +--------------- 一个月中的第几天 (1 - 31)
|    +-------------------- 小时 (0 - 23)
+------------------------- 分钟 (0 - 59)
```

- ここで、f1 は分、f2 は時、f3 は月内の日、f4 は月、f5 は曜日を表します。program は実行するプログラムを表します。
- f1 が * の場合は毎分 program を実行することを表し、f2 が * の場合は毎時プログラムを実行することを表します。以下同様です。
- f1 が a-b の場合は第 a 分から第 b 分までの期間に実行することを表し、f2 が a-b の場合は第 a 時から第 b 時まで実行することを表します。以下同様です。
- f1 が */n の場合は n 分間隔で 1 回実行することを表し、f2 が */n の場合は n 時間間隔で 1 回実行することを表します。以下同様です。
- f1 が a, b, c,… の場合は第 a, b, c,… 分に実行することを表し、f2 が a, b, c,… の場合は第 a, b, c… 時に実行することを表します。以下同様です。

| 特殊記号 | 意味 |
| --- | --- |
| *（アスタリスク） | 任意の時間を表します。たとえば最初の「*」は、1 時間の中で毎分実行するという意味を表します。 |
| ,（カンマ） | 不連続な時間を表します。たとえば「0 8，12，16***コマンド」は、毎日 8 時 0 分、12 時 0 分、16 時 0 分にコマンドを 1 回実行することを表します。 |
| -（ハイフン） | 連続した時間範囲を表します。たとえば「0 5 ** 1-6コマンド」は、月曜から土曜の午前 5 時 0 分にコマンドを実行することを表します。 |
| &#x2F;（スラッシュ） | どのくらいの間隔で実行するかを表します。たとえば「&#x2F;10***コマンド」は、10 分ごとにコマンドを 1 回実行することを表します。 |

---

`/` を使用して各設定を行う場合、各設定の先頭位置をゼロにする必要があります。これは、正時にコマンドが何度も重複実行されるのを避けるためです。
