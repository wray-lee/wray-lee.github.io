Open Command Prompt,
Enter the command: diskpart——list disk——select disk 0
Explanation:
diskpart, enter the disk operation environment.
list disk, check how many disks your computer has; here it shows my computer has only one disk.
select disk 0, select the disk to operate on.

List detailed information for the selected disk: detail disk
Note: Even if the partition is hidden, its number will still not change.

Then enter the commands in sequence: select partition 5——set id=12
Explanation:
Select partition——set parameter.
id parameter:
id=12 means hide the partition
id=07 means show the partition. (This can restore the hidden partition.)
