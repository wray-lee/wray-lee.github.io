# Markdown Syntax

## Heading Syntax

` # 一级标题`

`## 二级标题`

`### 三级标题`

and so on

## Emphasis Syntax

` ~~内容~~`Strikethrough

`*内容*`Italic

`**内容**`Bold

`***内容***`Bold Italic

## List Syntax

### Ordered List

```markdown
1. 内容
2. 会自动生成（记得空格）
```

### Unordered List

```markdown
- 内容
+ 内容
* 内容
```

All can generate unordered lists

## Markdown can embed HTML

```markup
<p></p>
<font color=></font>
<u></u>
<tr></tr>
<td></td>
..............
```

## Horizontal Rule

```markdown
---				减号
\*\*\*			星号
\_\_\_			下划线
```

All work

## Code Syntax

```markdown
`your_codes`

```select_language
your codes
```
```

## Annotations

### Superscript

`[^标注内容]`

Hello[^1]

`html内嵌`

1

### Subscript

`~标注内容~`

Hello~~1~~

## Text Decoration

### Strikethrough

`~~内容~~`

~~Hello~~

### Underline

`html内嵌语法：<u>内容</u>`
