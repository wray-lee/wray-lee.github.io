### Nas

`kernel panic`

- ネットワークデバイスe1000をvirioに変更

- Synologyのシステムディスク設定でAsync Ioをthreadsに設定。

- `/etc/default/grub` ファイルを修正し、GRUB_CMDLINE_LINUX_DEFAULT 項目を見つけ、最後に `noxsave` 指令を追加する

    その後、`update-grub` を実行してブートローダーを更新する

```bash
# /etc/pve/qemu-server/[nas_id].conf
cpu: host,-fma,-xsave,-avx,-avx2,-xsaveopt,-xsavec,-xgetbv1,+xsaveerptr
```

## 内蔵GPUを無効化

```bash
#!/bin/bash

read -p 'y or n:' word

if [ "$word" == 'n' ]; then
    esxcli system settings kernel set -s vga -v FALSE
elif [ "$word" == 'y' ]; then
    esxcli system settings kernel set -s vga -v TRUE
else
    echo 'Invalid input'
fi
```



`SataPortMap`	060102 	第1のコントローラには6つのインターフェースがあり、第2は1つ、第3は2つ

`DiskIdxMap` 	 左から右へ順に、2桁ごとに1つのコントローラのディスク順序番号（ディスクがどの位置から認識されるか）	000607  第1のコントローラは0から開始、第2は6から開始、第3は7から開始

> 0506の場合、最初のコントローラの6つのディスクは認識されない（ディスク番号は00から始まる）
