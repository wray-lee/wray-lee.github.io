# Git commit specification

- feat: Add/modify features (feature).
- fix: Patch bugs (bug fix).
- docs: Documentation (documentation).
- style: Formatting (changes that do not affect code execution, white-space, formatting, missing semi colons, etc).
- refactor: Refactoring (code changes that neither add features nor patch bugs).
- perf: Improve performance (A code change that improves performance).
- test: Add tests (when adding missing tests).
- chore: Changes to the build process or auxiliary tools (maintain).
- revert: Revert a previous commit, for example: revert: type(scope): subject (revert version: xxxx).
