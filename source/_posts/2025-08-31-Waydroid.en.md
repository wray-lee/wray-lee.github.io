# Waydroid

Install:

```\
waydroid init -s GAPPS -F
```

Start:

```bash
sudo systemctl enable waydroid-container.service --now
waydroid session start && waydroid show-full-ui
```

Upgrade

```bash
waydroid upgrade
```

Stop:

```bash
waydroid session stop
```

Keyboard mapping:

[keymapper](https://github.com/keymapperorg/KeyMapper)

## ARM translation

Use casualsnek's [script](https://github.com/casualsnek/waydroid_script)安装翻译层。

To improve translation performance, it is recommended to use `libndk` on AMD CPUs and `libhoudini` on Intel CPUs. However, some applications only support one translation layer, so when a game does not work or has extremely poor performance, you may need to try both translation layers.

*Install libndk arm translation layer*

```
python3 main.py install libndk 
```

*Install libhoudini arm translation layer*

```
python3 main.py install libhoudini
```
