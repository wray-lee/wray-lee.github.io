# iperf3 テスト

`iperf3 -c 10.7.7.100 -i 1 -n 1G  -P 16 -Z --bidir `



```bash
-u	udp协议指定
-n  发送数据总量
-b  带宽上限
-P	线程数量
--bidri	双向测试
-R	测试下载(默认测试的上传)
-O  忽略前几秒的启动数据
```
