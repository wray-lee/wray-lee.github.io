# Waydroid

インストール：

```\
waydroid init -s GAPPS -F
```



起動：

```bash
sudo systemctl enable waydroid-container.service --now
waydroid session start && waydroid show-full-ui
```



アップグレード

```bash
waydroid upgrade
```



終了:

```bash
waydroid session stop
```





キーマッピング:

[keymapper](https://github.com/keymapperorg/KeyMapper)

## ARM トランスレーション

casualsnek の[スクリプト](https://github.com/casualsnek/waydroid_script)を使用して翻訳レイヤーをインストールします。

翻訳パフォーマンスを向上させるには、AMD CPU では `libndk` を、Intel CPU では `libhoudini` を使用することを推奨します。ただし、一部のアプリは1つの翻訳レイヤーのみをサポートしているため、あるゲームが動作しないか、パフォーマンスが極端に悪い場合は、両方の翻訳レイヤーを試す必要があるかもしれません。

*libndk ARM 翻訳レイヤーをインストール*

```
python3 main.py install libndk 
```

*libhoudini ARM 翻訳レイヤーをインストール*

```
python3 main.py install libhoudini
```
