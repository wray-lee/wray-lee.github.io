# Gitチュートリアル

`hexo clean && hexo g -d && hexo g -d && git push`

gitはソート可能なスタックのようなもので、スタックの先頭は最下部にあり、直近のコミットのみ変更でき、以前のデータを変更するには並べ替えが必要です

すべての操作は switch、checkout を除き、現在の参照位置で行われます

コミット記録自体の名前はハッシュ値です

## commit

`git commit`新しいバージョンを作成する（完全なコピーではなく、差分のみ記録する）

`git commit --amend`コミット記録を修正する

## branch

- ```git branch <branch_name> <branch_position>```

​		branch はある commit を指す

- ```git branch -f main head~3```    ` 	git branch -f main c0`    `git branch -f` はブランチの参照先を変更できる

- `git switch <branch_name>`

​		あるブランチへ切り替える

ブランチを使用して移動すると、ブランチも追随して移動する

## merge/rebase

### merge

プルしてマージ

`git merge 1`

このとき branch が main にあるなら、1 のコードを main にプルし、branch は依然として main にある

### rebase

マージ先へ統合し、コミット記録をコピーする

`git rebase 1`

すると main を 1 の開発ラインへマージし、branch は main にある

rebase は下層のバージョンを移動せず、現在参照しているバージョンのみを移動する

---

`git rebase -i head~3`			head 参照位置を含む 3 つの commit を選択し、GUI で削除・並べ替えを行い、処理後の結果は新しい路線に現れる（基底は head~3）

`-i`現在のバージョンから基底バージョンまでのすべてのバージョンを変更する

`git rebase -参数 基版本	`

## head

つまり現在の参照位置

`git checkout 1`

head を 1 に向ける

head は 1 つのコミット記録 commit を指す

head を参照として使う場合は大文字の HEAD にする

## checkout

`git checkout -b totallyNotMain o/main`

`git checkout -b 选择分支 追踪分支`（ブランチを作成するので、事前に作成しておく必要はない）

```bash
#创建分支后远程提交
git push --set-upstream origin remote_branch(新分支名称)
```

あるブランチをリモートのあるブランチに追跡させることができ、main を置き換えるのに相当する

---

次のものも使用できる

`git branch -u 追踪分支 选择分支`（ブランチを作成しないので、事前に作成しておく必要がある）

## 相対参照

^ は 1 つ上のコミット記録へ移動する

~num は num 個上のコミット記録へ移動する

`git checkout main^`

==コミット記録 commit を表すのにブランチを使用できる==

^2 は 2 番目の親コミットを選択できる

コマンドはチェーン操作をサポートする

`git checkout HEAD~^2~2`

## 変更の取り消し

`git reset`	`git revert`

`git reset head^` は commit を前の記録へ戻し、現在の記録を削除し、参照を前の記録へ変更する

`git revert head^` はこの路線に新しい commit を追加するが、新しい commit は実際には前のものと同じである

==どちらのコマンドも現在の参照位置に対して操作を行う==

## ブランチの整理

`git cherry-pick c2 c4`	c2、c4 を順番に、参照が現在あるブランチの下へコピーする

## Tag（ブランチの移動による混乱を避ける）

`git tag v1 c1`

c1 に v1	tag を追加する

## describe

`git describe <引用>`

output：<tag>\_<numCommits>\_g<hash>

# リモート

## clone

`git clone`リモートリポジトリをコピーする

初回 clone では main と o/main を自動的に同じ位置へ参照させる

## main と o/main

checkout o/main してから commit すると、リモートリポジトリのデータをダウンロードしていないため、HEAD 分離が発生する。つまり o/main は同期時のみ参照先が変化する

リモートブランチ o/main（o/*）は実際にはリモート main ブランチの位置である

## fetch

`git fetch`

main ブランチは更新せず、リモートリポジトリのコードをダウンロードするだけで、o/main 参照を更新する

引数は不要で、自動的に比較してダウンロードする

`git fetch origin <远程选定分支:本地选定分支>`（相対参照を使用できる）

`git fetch origin <:本地分支>` はローカルブランチを作成する

## pull

つまり `fetch+merge`

`git pull`

実際には `git fetch ; git merge o/main` である

コードをプルして自動マージする

現在のブランチでプルを行うため、o/main が現在位置にない場合は同期していないためプルできない

`git pull --rebase` はリベース形式でコードをプルして main ブランチをマージする。この特性を利用すると、ブランチ全体をリベースできる

fetch に似た `git pull <远程分支:本地分支>`		`git pull <:本地分支>` を使用できる

## push

pull とは逆で、コードをアップロードし、自動マージはない。ローカルリポジトリが古い版なら更新してから push する必要がある

`git push origin <选定分支>`

​	HEAD を先頭に位置づけ、選択したブランチを自動追跡してアップロードする

`git push origin <本地选定分支:远程选定分支>`

ローカルで選択したブランチをリモートで選択したブランチへアップロードし、リモートに存在しない場合は作成する

相対参照を使用してブランチ全体をアップロードしない `git push origin <本地选定分支^:远程选定分支>`

​	ローカルで選択した位置より上のみアップロードする

`git push <:远程分支>`

​	リモートブランチを削除する

## ローカルの未コミット commit を破棄するがファイルは保持する

### rebase

1. `touch tmp`
2. `git add .`
3. `git commit -m 'tmp'`
4. `git rm ./tmp`
5. `git commit -m 'commit info'`
6. `git rebase -i 远程分支`
7. 中間のコミットを drop する。最初のコミットを fixup/squash する。最後のコミットを reword し、最後の commit 情報のみを保持する

### reset（大文字小文字の変更時に使用）

```
git reset --soft {seed}
git commit -m
git push --force
```

## ブランチのすべての commit を削除する

`git update-ref -d HEAD`

## ローカルコードを強制上書きする

```bash
git fetch --all
git reset --hard origin/main
git pull
```

## コンフリクトの解決

### テキストの場合

テキストを編集してコンフリクト位置を確認する

### バイナリの場合、または直接適用したい場合

```shell
# 保留本地
git checkout --ours 

# 保留远程
git checkout --theirs
```

## 履歴の解決

### リモート履歴を保持する

```shell
git fetch origin
git reset --hard origin/main
```

### ローカル履歴を保持する

```shell
git pull origin main --allow-unrelated-histories
```

### merge は履歴を継承しない

> commit を生成しない

```shell
git merge dev --squash --allow-unrelated-histories
```

## git clone で指定フォルダ

```bash
git init

git config core.sparseCheckout true
echo "tft" >> .git/info/sparse-checkout
git pull origin master
```
