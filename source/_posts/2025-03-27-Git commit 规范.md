# Git commit 规范

- feat： 新增/修改功能 （feature）。
- fix： 修补 bug （bug fix）。
- docs： 文件 （documentation）。
- style： 格式 （不影响代码运行的变动 white-space， formatting， missing semi colons， etc）。
- refactor： 重构 （既不是新增功能，也不是修补 bug 的代码变动）。
- perf： 改善性能 （A code change that improves performance）。
- test： 增加测试 （when adding missing tests）。
- chore： 构造程序或辅助工具的变动 （maintain）。
- revert： 撤销回复先前的 commit 例如：revert： type（scope）： subject （回复版本：xxxx）。
