#### Elements

- Block elements: page layout<div> <p> <h1>… <h6> <ul> <ol> <dl> <li> <table> <form>, **occupy a certain size, manually set size (by default occupy one line), arranged in multiple lines**
- Inline elements: web content<span> <a> <strong> <em><br> <input>, **size set according to content, arranged on the same line**
- Inline-block elements (belong to inline elements, arranged horizontally but can set size): <img>, **can set size, arranged on the same line**

#### &lt;head&gt;

Head; you can add <title>, <style>, <meta>, <link>, <script>, <noscript> and <base>

- <title>	Document title
- <base>      Sets the default link for link tags

```markup
<head>
<base href="http://www.runoob.com/images/" target="_blank">
</head>
```

- <link>	Marks the relationship between the document and external resources, often used to link and reference CSS

```markup
<head>
<link rel="stylesheet" type="text/css" href="mystyle.css">
</head>
```

- <style>	Can directly render HTML through CSS; this method is **inline style**

```markup
<head>
    <style type="text/css">
    body{
    	background-color:yellow;
    }
    p {
    	color:blue
    }
    </style>
</head>
```

- <meta>	Defines basic metadata; it will be parsed but not rendered or displayed

```markup
<meta name="keywords" contents="">
<meta name="description" content="">
<meta name="author" content="">
<meta http-equiv="refresh" content="30">	#每30s刷新网页，可定义基本行为
<meta name="viewport" content="width=device-width, initial-scale=1.0"> #设定缩放比率
```
