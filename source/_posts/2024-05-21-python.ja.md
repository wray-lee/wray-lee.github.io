# Python

## クロージャ

関数は、それが定義されたときの環境にアクセスできる

```python
def outerFunc(a):
    def innerFunc(b):
        return a+b
    retrun innerFunc
    
    
tmp = outerFunc(1)
print(tmp(2))	# 输出3
```

この例では、最初に渡された引数1は tmp が呼び出される時点でも依然として存在しており、最初の実行後に破棄されたわけではない

## デコレータ

> 関数を引数として受け取り、関数の機能を補い、デコレートされる関数より先に実行される

```python
def now():
     print('2015-3-25')
def log(func)
	def wrapper(*args, **kw):
        print('call %s():' % func.__name__)
        return func(*args, **kw)
    rerutn wrapper
    
@log
def now():
    print('2015-3-25')
```

戻り値：


```python
call now()：
2015-3-25
```

### ネスト

> デコレータを呼び出すときに引数を1つ渡せるようにする

```python
def log(text):
    def decorator(func):
        def wrapper(*args, **kw):
            print('%s %s():' % (text, func.__name__))
            return func(*args, **kw)
        return wrapper
    return decorator


@log('execute')
def now():
    print('2015-3-25')
```

戻り値：

```python
execute now():
2015-3-25
```



@decorator の下にある各関数は、それぞれデコレータへ渡される。つまり、デコレータは一度に1つの関数だけを受け取ることができる



## エラーコールバック

```python
def errorDecorator(f):
    @wraps(f)	# 更新函数基本信息，如__name__，__doc__
    def wrapper(*args, **kwargs):	# *args为位置参数（正常参数name），**kwargs为关键字参数（键值对参数name=wray）
        try:
            return f(*args, **kwargs)
        except Exception as e: # 判断跳出条件并给予变量别名
            print(f"error occurred: {e}")
    return wrapper

@errorDecorator
def riskyFunc():
    raise ValueError("error")

risky_function()
```
