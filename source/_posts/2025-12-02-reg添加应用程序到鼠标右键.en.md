# Add an Application to the Right-Click Menu with reg

## Reg Syntax

### `reg add `

> Add a key; if it already exists, modify it

```bash
# /v : 所选项下套添加的值的名称
# /ve 为注册表像添加空白值名称
# /t : RegKey 数据类型:
REG_SZ
REG_MULTI_SZ
REG_EXPAND_SZ
REG_DWORD
REG_QWORD
REG_BINARY
REG_NONE
# /s : 指定一个在 REG_MULTI_SZ 数据字符串中用作分隔符的字符,日过忽略,则将 “/0” 作为分隔符
# /d : 要分配给添加的注册表 ValueName 的数据
# /f : 不用提示就强行覆盖现有注册表项
# /reg:32 : 指定应该使用 32 位注册表视图访问的注册表项
# /reg:64 : 指定应该使用 64 位注册表视图访问的注册表项

reg add "HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Power\PowerSettings\54533251-82be-4824-96c1-47b60b740d00\93b8b6dc-0698-4d1c-9ee4-0644e900c85d" /t REG_DWORD /v "Attributes" /d "2" /f
```



## `reg delete`

> Delete a key



## How It Works

### Path

```bash
# 直接注册
HKEY_CLASSES_ROOT\*\shell
HKEY_CLASSES_ROOT\Directory\shell
# 通过dll注册
HKEY_CLASSES_ROOT\*\shellex\ContextMenuHandlers
HKEY_CLASSES_ROOT\Directory\shellex\ContextMenuHandlers
```



### Operation



Under

`HKEY_CLASSES_ROOT\*\shell\`

add a new registry key (the application name)



Its default REG_SZ-type data acts like main, carrying out the key's primary function

The default value will be displayed in the right-click menu; clicking the right-click menu item calls the path set in the Icon value to open the selected file



The default value in command is used to specify user parameters, which is `Path "%1"`	In the program, %%1 is needed because running a bat filters out (consumes) one % sign; to add one in the string you need two

```shell
@echo off
set /p VA=按a将*添加到右键，按d删除
echo %VA%
if /l "%VA%"="a" goto Add
if /l "%VA%"="d" goto Del
:Add
reg add "HKEY_CLASSES_ROOT\*\shell\Typora" /t REG_SZ /v "" /d "用 * 打开"   /f
reg add "HKEY_CLASSES_ROOT\*\shell\Typora" /t REG_EXPAND_SZ /v "Icon" /d "%~dp0*.exe" /f
reg add "HKEY_CLASSES_ROOT\*\shell\Typora\command" /t REG_SZ /v "" /d "%~dp0*.exe \"%%1\"" /f

:Del
reg delete "HKEY_CLASSES_ROOT\*\shell\Typora" /f

exit
```
