- When f1 is *, it means program should be executed every minute; when f2 is *, it means the program should be executed every hour, and so on.

| Special symbol | Meaning |
| --- | --- |
| * (asterisk) | Represents any time. For example, the first `*` means execute once every minute in an hour. |
| , (comma) | Represents non-contiguous times. For example, `0 8,12,16 * * *` means execute the command once at 8:00, 12:00, and 16:00 every day. |
| - (hyphen) | Represents a continuous time range. For example, `0 5 * * 1-6` means execute the command at 5:00 AM from Monday to Saturday. |
| / (forward slash) | Represents how often to execute. For example, `*/10 * * * *` means execute the command once every 10 minutes. |
