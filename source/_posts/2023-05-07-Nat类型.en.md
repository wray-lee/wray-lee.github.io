# NAT Types

## Full cone NAT
Unconditional forwarding

## Restricted cone NAT

Only external hosts that have communicated with the internal network can perform NAT

## Port restricted cone NAT

Building on the former, the external host port is added; data sent from a specific port of an external host that has communicated can be NATed

## Symmetric NAT

Does not forward

> After client (192.168.0.3, 100) and server (1.1.1.1, 1111) establish a mapping relationship on the router, if at this time the router (8.8.8.8) receives data on port 800 sent from another server (2.2.2.2, 2222), should it forward it to (192.168.0.3, 100)?
>
> There are four cases:
>
> 1. Forward unconditionally to (192.168.0.3, 100); this is Full Cone NAT.
>
> 2. If (192.168.0.3, 100) has previously sent data to (2.2.2.2), then forward; this is Restricted Cone.
>
> 3. If (192.168.0.3, 100) has previously sent data to (2.2.2.2, 2222), then forward; this is Port Restricted Cone.
>
> 4. Discard the packet and refuse to forward; this is Symmetric NAT.
