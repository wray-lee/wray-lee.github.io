# Cleaning Up Junk in Arch



## Clean Up Installation Package Cache

`sudo pacman -Scc`

## Clean Up Orphaned Packages

`sudo pacman -Rsn $(pacman -Qtdq)`

## Clean Up Logs

> Limit log records to 50M

`journalctl --vacuum-size=50M`

# Clean Up AUR

`yay -Yc`

## Clean Up Cache

`sudo paccache -rk0`

## Clean Up Old Kernels

`mhwd-kernel -li`

## Clean Up Old Configuration Files

`find ~/.config -type f -mtime +365 -exec rm {} \;`
