### Network Address

The network number is reserved, and all the rest are 0; it is the first address allocated (reserved).



### Subnet Mask

The network number and subnet number are all 1, and the remaining host bits are all 0.



Number of IPs

`(BIN)2^n,可用ip (BIN)2^n-2					n=主机号位数`=

`(DEC)2^(32-cidr)	2^(32-cidr)-2										  n=cidr`



Performing an & operation with the IP address can obtain the network address (host bits all 0).

eg:10.0.0.0



Broadcast address (host bits all 1) (the last address allocated, reserved)

eg:10.0.0.255





For every `2^8`, the IP carries one digit, and the last IP address can be calculated.

Given an IP range including the network address, the final IP needs -1.

## Cast

- **UniCast:** The most common communication method, one-to-one connection communication.

- **BroadCast:** By sending packets to the broadcast address `255.255.255.255`, the router/switch sends packets to **all devices** in the area for querying, which causes CPU interrupts (ARP, finding IP).
- **MultiCast:** 
    - Devices in the group listen to a multicast address (`224.0.0.0/4`); users send packets to the multicast address, and a designated device responds. At this point, the listening IP is like a channel (mDNS (all **service devices** listen to the multicast IP, and subsequently provide services via unicast)).
    - Devices in the group listen to a multicast address (`224.0.0.0/4`); users send packets to the multicast address to join the group, and the content server continuously pushes to this multicast address (IPTV (distributes content directly **within the channel**)).
    - Through an RP (Rendezvous Point) server listening to the multicast address, the packets sent by users are distributed to servers in the group.
    - NDP, which replaces ARP under IPv6: a device initially listens to a multicast address `ff02::1:ff` (binding MAC: `33:33:ipv6后缀`), informs the router of the bound device. When a user looks up the MAC of an IPv6 address, it accesses the **multicast address + multicast MAC**, and the device then returns the real NIC MAC of the IPv6 address.
- **AnyCast:** Servers in different geographical locations share one IP. When a user accesses the IP, BGP routing automatically selects the server with the optimal distance to access.
