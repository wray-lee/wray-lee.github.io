# Experiment 1 Protocols and Data of Computer Networks

Experiment series: Cross-major elective course experiment Experiment object: Undergraduate

Related courses and majors: Computer Networks, Information Security Experiment hours (credits): **4** hours

Experiment type: In-class computer lab

Experiment developer: Computer Networks

**【Experiment Objectives】**

Understand and master the basic concepts of protocols and network packets/messages in computer networks, master the interaction process and role of network protocols, and the format and significance of network data packets.

**【Experiment Content】**

By using WireShark software, capture network data packets of protocols such as TCP and FTP transmitted in the network, so as to understand the data structures of various protocols in the TCP/IP protocol stack, the process of session connection establishment and termination, and the change rules of TCP sequence numbers and acknowledgment sequence numbers.

**【Experiment Environment】**

1. Students work in pairs, each with one PC, installed with Windows 7 or Windows XP operating system.

2. A local area network environment networked with switches or hubs.

**【Experiment Equipment】**

2 PCs per group, monitoring software WireShark and FTP server software ServU.

**【Experiment Principles】**

(1) Computer network layered model:

The TCP/IP protocol suite is the foundation of the Internet and the most popular networking form today. TCP/IP is a synonym for a group of protocols, including many other protocols, forming the TCP/IP protocol suite. Among the more important ones are SLIP, PPP, IP, ICMP, ARP, TCP, UDP, FTP, DNS, SMTP, etc. The TCP/IP protocol does not completely conform to the OSI seven-layer reference model. The traditional Open Systems Interconnection reference model is a 7-layer abstract reference model for communication protocols, in which each layer performs a specific task. The purpose of this model is to enable various hardware to communicate with each other at the same layer. The TCP/IP communication protocol adopts a 4-layer hierarchical structure, and each layer calls the network provided by its next layer to fulfill its own needs. Conceptually, it can be mapped to four layers: the network interface layer, which is responsible for transmitting frames on the line and receiving frames from the line; the Internet layer, which includes the IP protocol. The IP protocol generates Internet datagrams and performs necessary routing algorithms. The IP protocol can actually be divided into four parts: ARP, ICMP, IGMP, and IP; above this is the transport layer, which is responsible for managing sessions between computers. This layer includes two protocols, TCP and UDP. Different protocols can be used for communication according to different application requirements; the last layer is the application layer, which includes the familiar FTP, DNS, TELNET, etc.

(2) TCP protocol

The TCP protocol is the Transmission Control Protocol, which provides a reliable [data stream](https://baike.baidu.com/item/%E6%95%B0%E6%8D%AE%E6%B5%81)服务。当传送受差错干扰的数据，或举出[网络故障](https://baike.baidu.com/item/%E7%BD%91%E7%BB%9C%E6%95%85%E9%9A%9C/1391028)，或网络负荷太重而使网际基本传输系统不能正常工作时，就需要通过其他的协议来保证通信的可靠。[TCP](https://baike.baidu.com/item/TCP/33012)就是这样的协议。TCP采用“带重传的肯定确认”技术来实现传输的可靠性，并使用“[滑动窗口](https://baike.baidu.com/item/%E6%BB%91%E5%8A%A8%E7%AA%97%E5%8F%A3)”的[流量控制](https://baike.baidu.com/item/%E6%B5%81%E9%87%8F%E6%8E%A7%E5%88%B6)机制来提高网络的吞吐量。TCP通信建立实现了一种“[虚电路](https://baike.baidu.com/item/%E8%99%9A%E7%94%B5%E8%B7%AF/1609903)”的概念。双方通信之前，先建立一条链接然后双方就可以在其上发送数据流。这种数据交换方式能提高效率，但事先建立连接和事后拆除连接需要开销。

TCP provides a connection-oriented, reliable byte stream service. Connection-oriented means that two applications using TCP (usually a client and a server) must first establish a TCP connection before exchanging data with each other, i.e., the "three-way handshake." This handshake process is very similar to making a phone call: first dial and ring, wait for the other party to pick up and say "hello," and only then say who you are.

(3) FTP (File Transfer Protocol)

FTP is a standard protocol and is the simplest method for exchanging files between computers and networks. Just like the HTTP protocol for transmitting web pages and the SMTP protocol for email, FTP is also an application protocol standard for the TCP/IP protocol. FTP is usually used to upload files from the owner to a server for others to use, and downloading files from a server is also a very common usage. As a user, one can use a very simple DOS command-line interface to use FTP file transfer services, or use a third-party graphical FTP client to update (delete, rename, move, and copy) files on the server. FTP servers generally support anonymous login, allowing users to log in with ANONYMOUS as the username, and usually any password or just pressing Enter can be used.

**【Preparatory Knowledge】**

Computer network layered model, computer network protocol concepts, network monitoring concepts.

**【Experiment Steps】**

In a local area network environment networked with switches or hubs, work in pairs, with two Windows hosts per group.

(1) One Windows host in each group acts as an FTP server, providing file download services. One Windows host acts as a client, using the FTP protocol to connect to the server and perform file download operations.

(2) The host acting as the server installs the FTP server software—ServU, sets the username and password, and related directory access permissions.

(3) The host acting as the client uses FTP client software or a browser to access the server, and installs the network monitoring tool WireShark.

(4) Start the WireShark software tool.

(5) Set filter conditions, including source and destination IP addresses, source and destination port numbers, and protocol type. Including: using the client host's IP address as the source IP address, capture all data packets sent from the student machine, and record the data packet header information. Using the FTP server as the destination IP address, capture all data packets sent to the server. And record the data packet header information. Using UDP and TCP respectively as the protocol type, capture and record the data packet header information. Using destination port number 21, capture and record all FTP control connection packet header information.

(6) On the client host, use a browser or FTP client to log in to the specified FTP server.

(7) According to the information returned by the FTP server, enter the username and password on the client.

(8) Observe and record the password capture situation.
The recorded fields include: IP header, transport layer header data, and data captured at the application layer.

**【Experiment Results】**

(1) Record and analyze the TCP three-way handshake packets.

(2) Explain and analyze the monitored FTP protocol data packets, and find the FTP login account information.

**【Experiment Principles】**

(1) Twisted pair and unshielded twisted pair

Twisted pair is made of a pair of mutually [insulated](https://baike.baidu.com/item/%E7%BB%9D%E7%BC%98/13466698)的[金属](https://baike.baidu.com/item/%E9%87%91%E5%B1%9E)导线绞合而成。采用这种方式，不仅可以抵御一部分来自外界的电磁波干扰,也可以降低多对绞线之间的相互干扰。把两根[绝缘](https://baike.baidu.com/item/%E7%BB%9D%E7%BC%98)的导线互相绞在一起，干扰信号作用在这两根相互绞缠在一起的导线上是一致的（这个干扰信号叫做共模信号），在接收信号的差分电路中可以将共模信号消除，从而提取出有用信号（差模信号）。根据有无屏蔽层，双绞线分为[屏蔽双绞线](https://baike.baidu.com/item/%E5%B1%8F%E8%94%BD%E5%8F%8C%E7%BB%9E%E7%BA%BF)（Shielded Twisted Pair—STP) and [unshielded twisted pair](https://baike.baidu.com/item/%E9%9D%9E%E5%B1%8F%E8%94%BD%E5%8F%8C%E7%BB%9E%E7%BA%BF)（Unshielded Twisted Pair—UTP).

Unshielded twisted pair ([UTP](https://baike.baidu.com/item/UTP)）是一种数据[传输线](https://baike.baidu.com/item/%E4%BC%A0%E8%BE%93%E7%BA%BF)，由四对不同颜色的传输线所组成，广泛用于以太网和[电话线](https://baike.baidu.com/item/%E7%94%B5%E8%AF%9D%E7%BA%BF)中). Unshielded twisted pair cables have the following advantages: 1. No shielding jacket, small diameter, saves occupied space, low cost; 2. Light weight, easy to bend, easy to install; 3. Minimizes or eliminates crosstalk; 4. Flame retardant; 5. Independent and flexible, suitable for [structured cabling](https://baike.baidu.com/item/%E7%BB%93%E6%9E%84%E5%8C%96%E7%BB%BC%E5%90%88%E5%B8%83%E7%BA%BF)。因此，在综合布线系统中，非屏蔽双绞线得到广泛应用。双绞线常见的有三类线，[五类线](https://baike.baidu.com/item/%E4%BA%94%E7%B1%BB%E7%BA%BF)和[超五类线](https://baike.baidu.com/item/%E8%B6%85%E4%BA%94%E7%B1%BB%E7%BA%BF)，以及[六类线](https://baike.baidu.com/item/%E5%85%AD%E7%B1%BB%E7%BA%BF)，类型数字越大、版本越新，技术越先进、带宽也越宽。

(2) Twisted pair wire sequence standards

The most widely used twisted pair wire sequence standards are ANSI/EIA/TIA-568A and ANSI/EIA/TIA-568B. The main difference between these two standards is the different core wire sequence:

The wire sequence definition of EIA/TIA 568A is, in order, green-white, green, orange-white, blue, blue-white, orange, brown-white, brown, with the numbering as shown in the following table:

| Green-white | Green | Orange-white | Blue | Blue-white | Orange | Brown-white | Brown |
|:----:|-----|------|-----|------|-----|------|-----|
|  1   | 2   | 3    | 4   | 5    | 6   | 7    | 8   |

The wire sequence definition of EIA/TIA 568B is, in order, orange-white, orange, green-white, blue, blue-white, green, brown-white, brown, with the numbering as shown in the following table:

| Orange-white | Orange | Green-white | Blue | Blue-white | Green | Brown-white | Brown |
|:----:|-----|------|-----|------|-----|------|-----|
|  1   | 2   | 3    | 4   | 5    | 6   | 7    | 8   |

According to the 568A and 568B standards, [RJ-45](https://baike.baidu.com/item/RJ-45)连接头（俗称水晶头）各触点在网络连接中，对传输信号来说它们所起的作用分别是：1、2用于发送，3、6用于接收，4、5，7、8是双向线；对与其相连接的双绞线来说，为降低相互干扰，标准要求1、2必须是绞缠的一对线，3、6也必须是绞缠的一对线，4、5相互绞缠，7、8相互绞缠。由此可见实际上两个标准568A和568B没有本质的区别，只是连接RJ-45时8根双绞线的线序排列不同，在实际的网络工程施工中较多采用568B标准

(3) Switch

A switch works at the second layer of the OSI reference model, i.e., the [data link layer](https://baike.baidu.com/item/%E6%95%B0%E6%8D%AE%E9%93%BE%E8%B7%AF%E5%B1%82)。交换机内部的CPU会在每个端口成功连接时，通过将MAC地址和端口对应，形成一张MAC表。在今后的通信中，发往该MAC地址的数据包将仅送往其对应的端口，而不是所有的端口。因此，交换机可用于划分数据链路层广播，即冲突域；但它不能划分网络层广播，即广播域。

A switch has a very high [bandwidth](https://baike.baidu.com/item/%E5%B8%A6%E5%AE%BD)的背部[总线](https://baike.baidu.com/item/%E6%80%BB%E7%BA%BF)和内部[交换矩阵](https://baike.baidu.com/item/%E4%BA%A4%E6%8D%A2%E7%9F%A9%E9%98%B5)。交换机的所有的端口都挂接在这条背部总线上，控制电路收到数据包以后，处理端口会查找内存中的地址对照表以确定目的[MAC](https://baike.baidu.com/item/MAC)（[网卡](https://baike.baidu.com/item/%E7%BD%91%E5%8D%A1)的硬件地址）的[NIC](https://baike.baidu.com/item/NIC)（网卡）挂接在哪个端口上，通过内部交换矩阵迅速将数据包传送到目的端口，目的MAC若不存在，广播到所有的端口，接收端口回应后交换机会“学习”新的MAC地址，并把它添加入内部MAC地址表中。使用交换机也可以把网络“分段”，通过对照IP地址表，交换机只允许必要的[网络流量](https://baike.baidu.com/item/%E7%BD%91%E7%BB%9C%E6%B5%81%E9%87%8F)通过交换机。通过交换机的过滤和转发，可以有效的减少冲突域，但它不能划分[网络层](https://baike.baidu.com/item/%E7%BD%91%E7%BB%9C%E5%B1%82)广播，即[广播域](https://baike.baidu.com/item/%E5%B9%BF%E6%92%AD%E5%9F%9F)。

The main functions of a switch include physical addressing, [network topology](https://baike.baidu.com/item/%E7%BD%91%E7%BB%9C%E6%8B%93%E6%89%91%E7%BB%93%E6%9E%84)、错误校验、帧序列以及流控。交换机还具备了一些新的功能，如对VLAN（[虚拟局域网](https://baike.baidu.com/item/%E8%99%9A%E6%8B%9F%E5%B1%80%E5%9F%9F%E7%BD%91)）的支持、对[链路](https://baike.baidu.com/item/%E9%93%BE%E8%B7%AF)汇聚的支持，甚至有的还具有[防火墙](https://baike.baidu.com/item/%E9%98%B2%E7%81%AB%E5%A2%99)的功能。

Learning: [Ethernet switch](https://baike.baidu.com/item/%E4%BB%A5%E5%A4%AA%E7%BD%91%E4%BA%A4%E6%8D%A2%E6%9C%BA)了解每一端口相连设备的MAC地址，并将地址同相应的[端口映射](https://baike.baidu.com/item/%E7%AB%AF%E5%8F%A3%E6%98%A0%E5%B0%84)起来存放在交换机[缓存](https://baike.baidu.com/item/%E7%BC%93%E5%AD%98)中的MAC地址表中。

Forwarding/filtering: When the destination address of a data frame has a mapping in the MAC address table, it is forwarded to the port connected to the destination node rather than all ports (if the data frame is broadcast/[multicast](https://baike.baidu.com/item/%E7%BB%84%E6%92%AD)帧则转发至所有端口）。

Eliminating loops: When a switch includes a [redundant](https://baike.baidu.com/item/%E5%86%97%E4%BD%99)回路时，[以太网交换机](https://baike.baidu.com/item/%E4%BB%A5%E5%A4%AA%E7%BD%91%E4%BA%A4%E6%8D%A2%E6%9C%BA)通过[生成树协议](https://baike.baidu.com/item/%E7%94%9F%E6%88%90%E6%A0%91%E5%8D%8F%E8%AE%AE)避免回路的产生，同时允许存在后备路径。

(4) IP address

An IP address is used to give a computer on the Internet a number. What everyone sees in daily life is that every networked PC needs an IP address to communicate normally. We can compare a "personal computer" to a "telephone," then an "IP address" is equivalent to a "telephone number."

Every host on the Internet has a unique IP address. The IP protocol uses this address to transmit information between hosts. This is the foundation on which the Internet can operate. An IP address is a 32-bit binary number, usually divided into 4 8-bit [binary](https://baike.baidu.com/item/%E4%BA%8C%E8%BF%9B%E5%88%B6)数（也就是4个字节）。IP地址通常用“[点分十进制](https://baike.baidu.com/item/%E7%82%B9%E5%88%86%E5%8D%81%E8%BF%9B%E5%88%B6)”表示成（a.b.c.d）的形式，其中，a,b,c,d都是0~255之间的十进制整数。例：点分十进IP地址（100.4.5.6），实际上是32位二进制数（01100100.00000100.00000101.00000110）。

An IP address can be divided into two parts: a network identification number and a host identification number. Therefore, an IP address consists of two parts: one part is the network address, and the other part is the host address. IP addresses are divided into classes A, B, C, D, and E. The applicable types are respectively: large networks; medium-sized networks; small networks; multicast addresses; reserved. The commonly used ones are classes B and C.

**【Experiment Principles】**

The management methods of switches and routers (hereinafter referred to as devices) are basically divided into two types: in-band management and out-of-band management. Managing a device through the device's Console port belongs to out-of-band management and does not occupy the device's network interface. Its characteristic is that it requires a configuration cable and is configured at close range. When configuring a switch or router for the first time, the Console port must be used for configuration.

The command-line operation modes of switches or routers mainly include: user mode, privileged mode, global configuration mode, port mode, etc.

- User mode: The first operation mode obtained after entering the device. In this mode, you can simply view the device's software and hardware version information and perform simple tests. The user mode prompt is switch\> or router\>

- Privileged mode: The next-level mode entered from user mode. In this mode, you can manage the device's configuration file, view the device's configuration information, and perform network testing and debugging. The privileged mode prompt is switch# or router#

- Global configuration mode: The next-level mode (submode) of privileged mode. In this mode, you can configure the device's global parameters (such as device name, login information, etc.). In this mode, you can enter the next-level configuration mode to configure specific functions of the device. The global configuration mode prompt is switch(config)# or router(config)#

**【Experiment Principles】**

**(1) Use VLAN to implement isolation:**

VLAN (Virtual Local Area Network) refers to logical division within a physical network segment, dividing it into several virtual local area networks. The greatest characteristic of VLAN is that it is not limited by physical location and can be flexibly divided. VLAN has the characteristics of a physical network segment. Hosts in the same VLAN can directly access each other, while hosts in different VLANs must be forwarded through routing devices to access each other. Broadcast data packets can only propagate within the local VLAN and cannot be transmitted to other VLANs.

Port VLAN is one of the ways to implement VLAN. Port VLAN uses switch ports to divide VLANs, and a port can only belong to one VLAN.

Tag VLAN is another type based on switch ports, mainly used to enable hosts in the same VLAN across switches to directly access each other, while isolating hosts in different VLANs. Tag VLAN follows the IEEE802.1q protocol standard. When using an interface configured with Tag VLAN for data transmission, 4 bytes of 802.1q tag information need to be added to the data frame to identify which VLAN the data frame belongs to, so that the peer switch can accurately filter after receiving the data frame.

**【Experiment Principles】**

(1) Basic routing concepts

A router is a network layer device that can select an optimal path based on IP header information and forward data packets. It implements mutual access between hosts in different network segments.

Routers perform route selection and forwarding based on the routing table. The routing table is composed of routing entries. There are generally 3 ways to generate a routing table:

- Directly connected route: Configure an IP address for a router interface, and the router automatically generates route information for the network segment where the interface IP resides.

- Static route: In a network with a simple topology, the network administrator manually configures route information for network segments unknown to the local router, thereby implementing connections between different network segments.

- Routes generated by dynamic routing protocol learning: In large-scale networks or when the network topology is relatively complex, by running dynamic routing protocols on routers, routers automatically learn from each other to generate route information.

(2) Static routes:

Static routes refer to route information manually configured by the user or network administrator, including network address, subnet mask, and next-hop address.

Static routes have different purposes in different network environments:
When the network structure is relatively simple, configuring only static routes can make the network work normally; in complex network environments, configuring static routes can improve network performance and guarantee bandwidth for important applications; static routes can be used in VPN instances, mainly for VPN route management.

Static routes use less bandwidth than dynamic routes and do not consume CPU resources to calculate and analyze routing updates. However, when a network failure occurs or the topology changes, static routes will not automatically update and must be manually reconfigured.

The configuration of static routes mainly involves 5 main parameters: destination address and mask, outbound interface and next hop, and priority.

- Manually configured

- Fixed routing path (unless manually modified)

- Not advertised: will not actively advertise to other routers. However, administrators can introduce static routes into the dynamic routing of the local device and then advertise them using the corresponding dynamic protocol route.

- Unidirectionality: only provides routing for data along the direction of the next hop, and does not provide a reverse route. To enable bidirectional communication between the source node and the target network, a return static route must also be configured.

- Relaying: If the number of hops in the middle of a static route is greater than 1 (the route must pass through 3 or more routing nodes), then static routes to the same destination node or destination network must be configured in sequence on the other routers except the last router.

(2) Role of static routes

The greatest role of static routes is security. Dynamic routing requires frequent exchange of routing tables between routers, and analysis of routing tables can reveal information such as network topology and network addresses. Therefore, networks may also use static routes for security considerations.

(3) Disadvantages of static routes

Large and complex network environments are usually not suitable for static routes. On the one hand, it is difficult for network administrators to fully understand the topology of the entire network; on the other hand, when the network topology and link status change, the static route information in routers needs to be adjusted on a large scale, and the difficulty and complexity of this work are very high.

**【Experiment Principles】**

OSPF (Open Shortest Path First) is an IGP (Interior Gateway Protocol) that was applied earlier and is more commonly used. It is suitable for medium-to-large similar networks and is a typical link-state (Link-State) protocol. The OSPF protocol has become one of the most widely used routing protocols in current Internet WANs and Intranet enterprise networks. The OSPF protocol was proposed by the IETF (Internet Engineering Task Force) IGP working group and is a routing protocol based on the SPF algorithm.

The OSPF routing protocol is generally used within the same routing domain. Here, a routing domain refers to an autonomous system, Autonomous System—AS. In an AS, all OSPF routers maintain the same database describing the structure of this AS. This database stores the state information of the corresponding links in the routing domain. OSPF routers calculate their OSPF routing tables through this database. OSPF transmits link state advertisement (LSA) packets to all routers in a certain area, which is different from distance-vector routing protocols. Routers running distance-vector routing protocols pass part or all of their routing tables to their neighboring routers.

The SPF algorithm (also known as the Dijkstra algorithm) is the foundation of the OSPF routing protocol. The SPF algorithm takes each router as the root (ROOT) to calculate its distance to each destination router. Each router, based on a unified database, calculates the topology diagram of the routing domain. This structure diagram is similar to a tree and is called the shortest path tree in the SPF algorithm.

In the OSPF routing protocol, the trunk length of the shortest path tree, i.e., the distance from an OSPF router to each destination router, is called the OSPF Cost. Its algorithm is: Cost = 100×10<sup>6</sup>/link bandwidth. Here, link bandwidth is expressed in bps. That is, OSPF Cost is inversely proportional to link bandwidth. The higher the bandwidth, the smaller the Cost, indicating that OSPF is closer to the destination. For example, the Cost of FDDI or Fast Ethernet is 1, the Cost of a 2M serial link is 48, and the Cost of 10M Ethernet is 10, etc.
