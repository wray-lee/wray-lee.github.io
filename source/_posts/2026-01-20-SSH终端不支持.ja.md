# SSHターミナルがサポートされていません

`tput: unknown terminal "xterm-kitty"`

## 解決

`infocmp` がローカルの設定をエクスポートし、パイプ経由で `ssh` に渡し、その後リモートサーバーの `tic` コマンドによってコンパイルされ、サーバーのユーザーディレクトリ配下の `~/.terminfo` に保存されます。



```bash
infocmp -a xterm-kitty | ssh user@remote_server tic -x -o \~/.terminfo /dev/stdin
```
